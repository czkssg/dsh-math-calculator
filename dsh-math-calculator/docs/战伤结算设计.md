# 战伤结算设计（2026-11-27）

> 目标：回答「这场仗死多少人」——不是「打多久剩多少」。
> 上游：[完整世界观缺口分析](完整世界观缺口分析.md) 第二节；本轮复核发现该节大半已补，
> 真正的空白是**战后结算**。

## 一、第一性原理：缺的是哪一段

库内已有（本次逐一核实，不是推断）：

| 已有 | 作用 |
|---|---|
| `lanchester_linear` / `lanchester_square` | 交战损耗：双方战斗力怎么衰减 |
| `attrition_rate` | 多轮累计损耗 |
| `march_supply` / `army_supply_days` | 行军与补给能撑几天 |

**它们回答「还剩多少战斗力」，不回答「倒下的人里多少死」。**

一条完整的战场伤亡链应该是：

```
  交战损耗（lanchester）→ 伤亡总数
        ↓ 按伤死比拆分
  阵亡 KIA + 负伤 WIA
        ↓ 伤员里有 DOW（伤后死亡）
  总死亡 = KIA + WIA × DOW 率
        ↓ 个体层面
  这个伤兵还能撑多久（失血时间）→ 能不能送到救护所
```

本轮补的就是后三段。

## 二、开源记录（硬门槛 ①②）

| 渠道 | 结果 | 评估 |
|---|---|---|
| 本库 | 已有 `lanchester_*` 与 `attrition_rate` | 不重复实现交战模型 |
| npm | 搜 `lanchester` 只命中一个无关的 `nearestjs` | 无可用库 |
| GitHub | `umitkaanusta/Jomini`（53★，Python 战役模拟器） | 语言不符，且其模型与我们的「结算层」不重合；只作参考 |
| 文献 | PMC 检索历史「died of wounds」统计，返回的全是现代创伤医学 | **拿不到可信的历史区间** |

**因此本轮刻意只做「能自证」的部分**：生理常数（可算）+ 算术换算（可验）。
凡是要靠「历史经验区间」才能给数的（如某时代 DOW 率），一律**作为参数交给调用方**，
并标注明「这是量级区间，不是预测」——不冒充精确值。

## 三、三条公式

### 3.1 `hemorrhage_survival_time`（失血还能撑多久）

```
t = 体重(kg) × 血容量(ml/kg) × 致死失血比例 / 失血速率(ml/min)
```

- 血容量 70 ml/kg（成人；儿童略高，可覆盖）；
- 致死失血比例默认 0.5：失血 30% 开始失代偿、40% 休克、50% 死亡（ATLS 分级口径）。
- **这是纯生理学，不依赖任何历史数据**：70 kg、100 ml/min → 24.5 分钟。

### 3.2 `casualty_breakdown`（伤亡里多少阵亡）

```
KIA = 伤亡总数 × 阵亡占比
```

阵亡占比默认 0.25（对应伤死比 3:1）。历史区间约 0.2~0.4（冷兵器偏伤多，火力战偏亡多），
**由调用方按时代给**，不用一个"通用值"糊过去。

### 3.3 `deaths_with_dow`（含伤后死亡的总死亡）

```
总死亡 = KIA + WIA × DOW 率
```

DOW 率（伤后死亡）默认 0.15：近代战场约 0.1~0.2，有野战外科后降到 0.05 以下，
无手术条件的古代战场可到 0.3。**同样是"由时代给参数"的量级值。**

## 四、验证方式（不用外部数据也能验）

1. **生理自洽**：失血时间与失血速率成反比（速率翻倍 → 时间减半）；
   体重翻倍 → 时间翻倍；`bleeding_rate = 0` 必须报错而不是给 Infinity。
2. **算术自洽**：KIA + WIA = 伤亡总数；总死亡 ≤ 伤亡总数；
   总死亡 ≥ KIA（DOW 不可能为负）。
3. **与兰彻斯特串联**：`lanchester_square` 给剩余战斗力 → 损耗 = 初始 − 剩余 →
   结算 → 总死亡，整条链能跑通（不新增 operation，只用公式与算术）。

测试：`test-v3/r104-casualty.mjs`。

## 五、明确不做

- 不做「某个时代的具体 DOW 率」——没有可信一手来源，给了就是猜；
- 不做伤情分类（弹片/烧伤/钝伤各有分布）——需要战伤流行病学数据，本项目拿不到；
- 不做「士气崩溃」这类心理量——同上。

## 六、三份一直没人写的配方

旧分析把这三条列为「成本最低、收益最大」，至今仍是 0 份。它们不需要新公式，只用 `recurrence` / `simulate`。

### 6.1 人口年表（逐年）

```json
{ "operation": "recurrence", "recurrence": "P*1.02", "initial": { "P": 10000 }, "periods": 50 }
```

带承载力上限时：`"P*min(1.02, K/P)"`（K 为粮食上限）；要精确年份用 `ode` 的 `at:[50,100]`。

### 6.2 资源枯竭（转折年）

```json
{ "operation": "simulate",
  "stocks": { "资源": { "initial": 1000, "unit": "吨" } },
  "flows":  { "开采": { "to": "资源", "rate": "-40" } },
  "dt": 1, "simSteps": 60 }
```

配上 `tragedy_commons`（可持续采伐上限）就能给出「第几年开始不够」。

### 6.3 债务螺旋

```json
{ "operation": "recurrence", "recurrence": "D*(1+rate)-surplus", "initial": { "D": 100 }, "periods": 30 }
```

`rate` 用 `fiscal_sustainability` 里的 (i−g)；`surplus` 用 `fiscal_balance`。
配合 `primary_balance` 判断「还有没有救」。
