# UI 精简：面向作者 vs 面向 AI

> 用户反馈：**UI 太繁复，要区分「用户需要看的」与「只给 AI 的数据」，降低使用门槛。**

## 一、上一版的问题

照搬方案里的「推演栈六大目录」，做了 **6 组 18 个节点**：

```
1 基础物理法则    1.1 常数表  1.2 公式库  1.3 变更清单  1.4 观测基准
2 物理链路引擎    2.1 分层推演  2.2 依赖图  2.3 接口卡矩阵  2.4 演化时间轴
3 生命生态        3.1 生物物理  3.2 生态热力学
4 宏观文明        4.1 能量  4.2 材料  4.3 交通  4.4 技术树
5 校验分析        5.1 硬约束  5.2 相图  5.3 待定项
6 输出归档        6.1 七张表  6.2 完整性检查  6.3 白皮书
```

**这 18 个是「推演栈的结构」，不是「作者要做什么」。**

更严重的是：作者最想改的**世界参数**（重力、日长、轨道）在界面上根本没有入口，
反而摆着 23 个基础物理常数（光速、普朗克常数…）。

## 二、判断标准

| 问题 | 保留 | 理由 |
|---|---|---|
| 作者会主动改吗？ | ✅ 留 | 改设定是核心动作 |
| 作者会主动看吗？ | ✅ 留 | 看完能指导下一步 |
| 只有 AI 需要？ | ❌ 砍 | AI 自己调工具，不必让作者看懂 |
| 精调才用？ | ⚠️ 降级 | 藏到「我改过什么」下面 |

## 三、精简后：5 组 10 节点

```
这个世界
  基本设定          重力、日长、轨道、大气——作者最常调的四个
  这世界能住人吗      死寂判定与挽救方向

会有什么后果
  生活在这个世界      体感：能长多高、能飞多快、天空什么色
  文明能走多远        能量、材料、交通、技术树

超出物理的设定
  魔法 / 灵能        换算成等价现实量，只提醒不判定
  自创量             现有物理做不出的新量（带量纲）

我要能拿走的东西
  设定文档           白皮书：可直接看、可当设定集
  喂给 AI 的卡片      粘贴到对话，AI 立刻按这套规则写

我改过什么
  版本记录           每次跑留一版，可对比
  常数改动           精调用，一般不用碰
```

**18 → 10，砍掉 8 个纯技术节点。**

## 四、新增：作者能直接改世界参数

这是最关键的一步。之前只能在对话里让 AI 传参，现在有了表单：

```
基本设定                              留空就是默认值（地球）
  行星质量    [   ] 地球 = 1 — 决定重力。2 倍质量 ≈ 2 倍重力
  行星半径    [   ] 地球 = 1 — 和质一起决定重力。半径大则重力小
  一天多长    [   ] 小时 — 地球 24。太短会有超级风暴
  离恒星多远  [   ] AU（地球 = 1）— 宜居带约 0.95—1.67

  [保存]  [恢复成地球]
```

每个字段都有**单位**和**这一项影响什么**。填完保存，右侧「会有什么后果」立刻能看结果。

### 新增两个路由

| 路由 | 作用 |
|---|---|
| `POST /workspaces/save-world` | 保存世界参数（只接受已知字段，垃圾字段自动过滤） |
| `POST /workspaces/reset-world` | 恢复成地球 |

## 五、砍掉的技术页面去哪了

**后端能力一个没砍**，只是不占界面：

```
/derive?sub=graph        依赖图数据    ← 界面不显示，AI 可以调
/derive?sub=heatmap      相图          ← 同上
/derive?sub=cards        接口卡矩阵    ← 同上
/derive?sub=checklist    完整性检查    ← 同上
/derive?sub=sensitivity  敏感性        ← 同上
```

作者想精调时，直接跟 AI 说：「帮我看看这个世界的相图」。
