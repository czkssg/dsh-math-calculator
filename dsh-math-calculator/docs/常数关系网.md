# 常数关系网（改一个，别的怎么办）

> 2026-11-19。给 AI 的指引：公式里的常数可以改（见 [架空常数](架空常数.md)），
> 但**常数之间不是独立的**——改一个，物理上会牵动一片。
> 这份文档说清：谁和谁挂钩、改一个会牵动谁、不想牵动时怎么调和。

## 一、基本关系（现实世界的定义/推导）

| 关系 | 公式 | 含义 |
|---|---|---|
| 光速与电磁常数 | `c = 1/√(μ0·ε0)` | 真空光速由真空磁导率与介电常数决定 |
| 精细结构常数 | `α = e²/(4π·ε0·ħ·c) ≈ 1/137.036` | 电磁力强度；改 e/ħ/c/ε0 都会动它 |
| 约化普朗克 | `ħ = h/(2π)` | 角动量量子 |
| 气体常数 | `R = NA·kB` | 摩尔气体常数 = 阿伏伽德罗 × 玻尔兹曼 |
| 法拉第常数 | `F = NA·e` | 摩尔电荷 |
| 斯特藩-玻尔兹曼 | `σ = π²·kB⁴/(60·ħ³·c²)` | 黑体辐射常数由 h、kB、c 决定 |
| 里德伯常数 | `R∞ = m_e·e⁴/(8·ε0²·h³·c)` | 氢光谱 |
| 玻尔半径 | `a0 = 4π·ε0·ħ²/(m_e·e²)` | 原子尺度 |
| 康普顿波长 | `λ_C = h/(m_e·c)` | 电子尺度 |
| 地表重力 | `g0 = G·M_earth/R_earth²` | 地球标定 |
| 逃逸/环绕速度 | `v_esc = √(2GM/R)`，`v_orb = √(GM/R)` | 天体标定 |
| 太阳质量 | `M_sun = 4π²·AU³/(G·T²)` | T = 1 儒略年 |
| 年与日 | `year = 365.25·day`，`day = 86400 s` | 儒略年/平太阳日 |
| 光子能量 | `E = h·c/λ` | 改 h 或 c，光子能量变 |
| 黑体峰值 | `λ_max = b/T`，`b = h·c/(4.965·kB)` | 维恩位移 |

## 二、改一个会牵动谁（联动表）

| 改这个 | 物理上会跟着变 | 典型后果 |
|---|---|---|
| **c（光速）** | μ0、ε0（乘积）；α；一切相对论/电磁公式；光子能量 | 相对论效应变强/弱；电磁波速变 |
| **G（引力常数）** | 表面重力、逃逸/环绕速度、轨道周期、恒星寿命（若用 M-L 关系） | 星球「更重/更轻」；火箭 Δv 变 |
| **h / ħ（普朗克）** | 光子能量、光电阈值、康普顿、里德伯、斯特藩、黑体峰值 | 量子效应尺度变；光谱整体移动 |
| **e（元电荷）** | α、法拉第常数 F、库仑力、化学键能量 | 电磁力变强/弱；化学与材料性质变 |
| **kB（玻尔兹曼）** | 气体常数 R、热噪声、黑体、热容 | 温度-能量换算变 |
| **NA（阿伏伽德罗）** | 气体常数 R、法拉第 F、摩尔量、裂变能量 | 摩尔尺度的能量/物质量变 |
| **σ（斯特藩）** | 由 h、kB、c 决定；黑体辐射 | 若单独改 σ = 声明黑体定律变了 |
| **μ0 / ε0** | c = 1/√(μ0ε0)；库仑力；电容/电感 | 电磁力与光速耦合 |
| **α（精细结构）** | e、ħ、c、ε0 的组合；原子尺度与光谱 | 化学与材料整体变 |
| **g0（地表重力）** | G、M_earth、R_earth 的组合 | 若固定 g0，改 M/R 组合即可 |
| **Lsun / AU / Rearth** | 天文标定；与 G、M、轨道耦合 | 太阳质量/行星轨道反推值变 |
| **day / year** | 行星自转与轨道周期 | 历法与天文参数要一起改 |

## 三、不想联动时怎么调和（三种办法）

用户原则：**改了 A 但希望 B 不变，要给出「其他理由」并调和**。

### 办法 1：加独立参数（公式级覆盖）

公式里的常数都是参数（默认现实值）——直接在该公式上传一个新值，**不碰全局**：

```jsonc
// 这个世界的普朗克常数翻倍，但只在光电效应里生效
{ "operation": "formula", "formula": "photoelectric_threshold",
  "params": { "work_function": 4.5e-19, "h_planck": 1.32521403e-33 } }
```

适用于：只想改某个现象，不想改整个宇宙的常数。

### 办法 2：声明新常数（拆分原本绑定的量）

如果确实要「光速与电磁常数脱钩」，就**声明这是两个量**，而不是偷偷改：

```
  现实：c = 1/√(μ0·ε0)
  架空：c_light ≠ 1/√(μ0·ε0)，另记 c_em = 1/√(μ0·ε0)
       → 在设定里写清「这个世界的电磁波速与光速不同」，并给两个参数
```

同样可以拆：`g0` 与 `G·M/R²`、`R` 与 `NA·kB`、`σ` 与 `h/kB/c`。

### 办法 3：固定标定量，反推其他（保持「体感」不变）

想让地表重力不变、但改行星大小：

```
  固定 g0 = 9.81，改 R_earth → 由 g0 = GM/R² 反推新的 M
  固定 Lsun = 3.828e26，改恒星类型 → 反推质量/半径
```

这样只需声明「标定量不变」，剩下的由关系式推出来，不会自相矛盾。

## 四、AI 使用顺序

1. 用户说「改光速」→ 先查本表：牵动 μ0/ε0、α、相对论与电磁公式；
2. 问自己：用户要的是「整个宇宙变了」还是「只是这个公式变了」；
3. 整个宇宙：调用时传全局常数（每个公式各自覆盖）；同时把联动量一并改掉，或按办法 2/3 声明；
4. 只是这个公式：只在该次 `params` 里覆盖；
5. 回答时**明确写出改了哪些常数、哪些联动量没改**（不要静默）。

## 五、结构化数据（已经能用）

`operation:"constants"` 背后有一张**依赖图**：23 个基础旋钮 + 20 个派生量。
派生量不能直接设，只能由旋钮算出来——这就是「改一个，其他跟着改」的实现。

| 派生量 | 依赖 |
|---|---|
| hbar | h |
| R | kB、NA |
| mu0 | epsilon0、c |
| kCoulomb | epsilon0 |
| sigma | kB、h、c |
| bWien | h、c、kB |
| alpha_fs | e_charge、epsilon0、hbar、c |
| Ry | me、e_charge、epsilon0、h |
| muB | e_charge、hbar、me |
| year | day |
| ly | c、year |
| pc | AU |
| g | G、Mearth、Rearth |
| Lsun | Rsun、sigma |
| mPlanck / lPlanck / tPlanck | hbar、c、G |
| re | e_charge、epsilon0、me、c |
| F | e_charge、NA |
| alphaG | G、mp、hbar、c |

`operation:"constants"`（不带 constants 参数）会列出每个基础旋钮**反向牵动哪些派生量**：

```
  c   299792458  m/s  真空光速…  → 派生: mu0, sigma, bWien, alpha_fs, ly, re, alphaG
```

改法：`{operation:"constants", "constants":{"c": 1.5e8}}` → 所有派生量自动重算（百分比也列出）。
不想联动：用本页第三节的办法 1（公式级覆盖）或办法 2（声明新常数）。
