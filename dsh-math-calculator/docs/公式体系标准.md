# 公式体系标准

> 2026-11-18 · v3.11.0。公式不是散装清单：**链的每一步是上一个公式的输出 → 下一个公式的输入**。
> 守护测试：`test-v3/r63-chain-flow.mjs`（28 项）；全量 122 套 / 3,006 项全绿。

## 一、编排标准（写链时必须遵守）

1. **步骤顺序 = 物理量流顺序**：先有输入量、再有中间量、最后是判定量；
   `dataFlow.fromStep` 必须小于当前步号（逆序会被 chain-run 明确拒绝）。
2. **一个参数只有一个来源**：显式映射优先于 `initial`，`initial` 优先于公式默认值。
3. **外部输入不硬连**：面积、温差、效率、价格、利率、人口这类「作者要给的设定」不映射；
   它们留在 `initial` 里，由 chain-run 的 `missing_params` 明确列出。
4. **跨链接点不自动跨链**：`note` 里的「接点自 X 链」目前靠手工把数值带过来；
   后续若做跨链，语法是 `{ chain: "sys-x", step: N }`（尚未实现，先别写）。
5. **需要重排就重排**：物理上应先算的量（如自重弯矩）若排在后面，调整 `steps` 顺序，
   而不是允许逆序映射——顺序错了会静默给出错误的传导方向。

## 二、怎么判断一条映射成立

两个条件同时满足才写：

1. **量纲一致**：参数的 `dimension` 与上游输出单位解析出的量纲相同；
2. **语义一致**：参数 `quantity`（或 desc）与上游输出的量名是同一个物理量，
   例如「屈服强度 ← Hall-Petch 屈服强度」「惯性矩 ← 矩形截面惯性矩」。

只有量纲一致不算——`area_ha` 与任何长度、`mtbf` 与停留时间都会撞量纲。

## 三、本轮建立的映射（6 条核心链，15 步）

| 链 | 映射 |
|---|---|
| 材料链 | 第 7 步 Ashby 强度 ← 第 5 步屈服强度；第 9 步许用应力 ← 第 5 步屈服强度；第 10 步弯曲应力.M ← 第 9 步自重弯矩（重排后） |
| 结构链 | 第 5/6/9 步的惯性矩 I ← 第 3 步矩形截面惯性矩 |
| 能源链 | 第 6 步锅炉功率 P ← 第 5 步围护热损；第 6 步锅炉效率 eta ← 第 2 步炉膛效率 |
| 建筑链 | 第 7 步烧砖燃料.brick_count ← 第 6 步砖数 |
| 生物链 | 第 3 步扩散面积 ← 第 1 步体表面积 |
| 食物链 | 入储量 ← 总产；可用粮 ← 存后剩余；剩余率 ← 总产；能量供给 ← 作物总产；熏房节拍 ← 晾干天数；劳力 ← 可养人口 |

材料链重排：`beam_self_weight_moment`（自重弯矩）移到 `beam_bending_stress`（弯曲应力）之前，
这样「弯矩 → 应力」是顺向的物理流，而不是逆序硬接。
