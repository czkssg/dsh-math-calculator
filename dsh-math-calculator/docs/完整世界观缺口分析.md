# 完整世界观还缺哪些公式 —— 缺口分析

> 分析基于 631 条现有公式的**实测普查**，不是凭印象。
> 结论先说：**主要缺口不在「物理」，而在「时间的过程」与「活着的人」**。

---

## 零、先定判据：什么算「完整世界观」

如果把「像一个真实世界」拆开，它必须能回答五类问题。任何一类答不了，世界就会露馅：

| 层 | 必须回答的问题 | 现状 |
|---|---|---|
| **A 物理层** | 这个世界遵守什么规律 | **31 条链、213 条公式，过度饱和** |
| **B 物质层** | 能造出什么、造多少 | 79 + 34 条，基本够用 |
| **C 时间层** | 一年怎么过、灾祸多久来一次、十年后什么样 | **严重不足** |
| **D 人的层** | 人怎么活、怎么死、信什么、怕什么 | **最大空白** |
| **E 叙事层** | 为什么会变、什么时候崩 | **几乎空白** |

**现有的 631 条里，A 层占 33.8%，E 层不足 1%。**

这个分布说明一件事：**过去几批一直在补「世界为什么这样」，但没补「世界怎么运转」。**
物理是静态的（给定条件→立刻得答案），而世界是动态的（这一刻的状态取决于上一刻）。

## 一、最致命的缺口：**过程**（时间维度）

### 1.1 为什么这是第一缺口

看现有的「瘟疫」就懂了：

```
  已有：r0_basic（基本传染数）、herd_immunity（群体免疫阈值）、
        sir_equilibrium（平衡点）
  没有：这条曲线长什么样、峰值在第几周、死多少人、持续多久
```

**这三个公式回答的是「最终会怎样」，而作者要写的是「第三周城里开始烧尸」。**

同样的病在其他地方：
- 火：有「燃烧热值」，没有「火势蔓延速度」
- 谣言：有「扩散 S 曲线」，没有「第几天传遍」
- 技术：有「渗透曲线」，没有「多少年普及」
- 饥荒：有「粮食产量」，没有「第几个月开始饿死人」

**这是同一个结构性缺陷的五个症状：库里全是「状态量」，缺「通量」。**

### 1.2 这一层的正确补法

不能靠加条数解决，要靠**三类工具**（按性价比排序）：

| 工具 | 现状 | 补什么 |
|---|---|---|
| **`ode` 已有** | 支持 RK4、多方程、`at:[10,20,30]` 精确取点 | **不需要补公式，需要补「配方」**：SIR 时程、logistic 竞争、双池耦合各一套可直接抄的参数模板 |
| **`recurrence` 已有** | 离散逐年表 | 同上。人口/资源/债务的年表模板 |
| **缺的公式** | — | 只有真正有闭式解的那一小撮：**峰值时间、达峰比例、半数时间** |

**关键判断：这一块 80% 是「写配方」，20% 是「补公式」。** 而现在 0% 都没做。

#### 实测证据（不是推测）

我直接跑了一遍，`ode` **已经能做完整 SIR 时程**：

```js
{operation:"ode",
 expression:"dS/dt=-0.3*S*I/1000, dI/dt=0.3*S*I/1000-0.1*I",
 initial:{S:999, I:1}, from:0, to:60, at:[10,20,30,40,50]}
```

实际输出（R0=3、γ=0.1）：

```
 t      S            I
 10   989.49       7.32      ← 第 10 期：几乎没动静
 20   925.30      49.15      ← 第 20 期：开始加速
 30   649.80     206.84      ← 第 30 期：爆发
 40   287.01     297.24      ← 第 40 期：峰值，感染者 30% 人口
 50   134.20     196.66      ← 第 50 期：回落，但已付出巨大代价
```

**这就是「第三周城里开始烧尸」能写出来的数据。** 而它现在需要写 5 行参数，
不是需要一条新公式。

`recurrence` 同样可用（逐年人口/债务表已验证）。

#### 那还需要补公式吗

需要，但只补**有闭式解的那几条**，用于「快速判断」而不必跑完整积分：

```
epidemic_peak_time       SIR 峰值时间（近似闭式）        → 「第几周爆发」
epidemic_final_size      最终感染比例（近似式）          → 「死多少人」
epidemic_doubling_time   R0 与代际间隔 → 几天翻倍         → 「多快失控」
```

**为什么两者都要**：`ode` 给精确曲线但要点参数；闭式给量级但能心算。
配方的价值是「不用想就知道该调什么」，公式的价值是「不用跑就知道大概」。

## 二、第二大缺口：**活着的人**（C/D 层）

现有 20 条 `biology/physiology` 几乎全是**人体测量学**（体表面积、血容量、给药量），
是为「巨兽可行性」准备的。而一个真实世界的居民要面对的是：

### 2.1 营养与饥荒（**断在「缺口 → 死亡」这一段**）

实测这条链：

```
  ① 算热量需求     ✅ 有（metabolic_generic、basal_metabolic_rate、bmr_mifflin）
  ② 算缺口比例     ⚠ 只有零散的「率」类公式，没有「缺多少比例」的专门式子
  ③ 算存活时间     ❌ 0 条
  ④ 算死亡率       ❌ 0 条
```

**链条在第 ② 步之后断掉。** 后果很具体：

能算出「这个县需要 500 万千卡、只有 350 万」，但**算不出「还能撑几天」「第几天开始死人」「死多少」**。

而饥荒恰恰是前工业社会最核心的死亡机制。现有 20 条 `biology/physiology` 里，
**没有一条是「缺食」方向的** —— 它们几乎全是「人体测量 + 药物剂量 + 失水」：

```
  bmr_mifflin, body_surface_area, blood_volume_estimate, drug_dose_by_weight,
  widmark_bac, ld50_dose, infusion_rate, pregnancy_days_remaining, fever_energy_cost …
```

（这批是为「巨兽可行性」和「毒物剂量」准备的，不是为「饥荒」准备的。）

值得补的（都有可写的量级式）：

```
starvation_survival_time   体脂储备 ÷ 每日缺口 → 能撑多少天（有实测锚：纯绝食 40~70 天）
famine_mortality_rate      缺口深度 → 超额死亡率（给量级区间，不假装精确）
refeeding_risk             长期饥饿后恢复的风险（真实医学问题，常被忽略）
```

### 2.2 疾病与医学（**只有毒理，没有病程**）

```
  缺：病程时间轴（潜伏期→发病→恢复/死亡）
  缺：医疗干预的效果（放血/草药/手术各能改善多少）
  缺：外伤与外科（出血多久致死、感染率、截肢存活率）
  缺：伤兵处理（战伤死亡率，这是军事设定最常错的数字）
```

### 2.3 人口结构（有数字，没有纹理）

实测这一块只有一个「跨物种」式的公式：

```
  lifespan_scaling      L0 * (m/m0)^b      寿命的异速生长（鲸比鼠活得久）
```

**它是「不同物种的寿命怎么随体重变」，不是「同一人群里各年龄死多少」。**

```
  已有：抚养比、更替生育率、翻倍时间、人口转变
  缺：生命表（各年龄死亡率）→ 预期寿命、死亡年龄分布
  缺：家庭结构（一户几人、婚龄、生育间隔）
  缺：迁移（推力/拉力模型、迁徙速度）
```

**「预期寿命 35 岁」的真相是婴儿死亡率极高，而活到成年能活 60 岁** ——
这个区别决定了一个社会有没有老人、有没有经验传承、有没有「祖辈的记忆」。
现在算不出来，因为缺**分年龄死亡率**这一行数据。

这一条看似小，其实很硬：**「这个社会有没有老人」是叙事的基础设施。**

## 三、第三缺口：**地理的纵深**（有地表，没有地貌）

现有 95 条 `perception/*` 是「站在地面上看到什么」（地平线、日长、体感温度）。
缺的是**地形怎么形成、怎么变化**：

```
  缺：侵蚀速率（多久削平一座山）
  缺：河流的搬运与沉积（冲积平原多快形成）
  缺：海岸线变化（三角洲、海侵）
  缺：土壤形成速率（多厚土要多少年）—— **这直接决定农业可持续性**
  缺：地下水与含水层（井能打多深、会不会枯）
  缺：长期气候变化（冰期周期、气候带移动）
```

**为什么重要**：一个世界的「时间深度」由地质决定。
「这片平原是三万年前冲出来的」和「这里一直是这样」是两种完全不同的世界。

其中**土壤形成速率**最实用：它把「地力衰减」（已有 `soil_nutrient_balance`）和
「土地不可再生」连起来 —— 而这正是「为什么古代文明会因土地耗尽而崩」的定量根据。

## 四、第四缺口：**技术与生产的实物链**（有原理，没有工艺）

现有工艺公式集中在**金属、窑炉、化工**（都是"重工业"）。缺的是**日常生产**：

| 缺的工艺 | 为什么需要 |
|---|---|
| **纺织**（纺纱、织布、染整） | 前工业社会第一大产业。一条「从羊毛到布」的链条能算清劳动力分配 |
| **造纸与印刷** | 决定知识能否规模化复制 —— 这是「文明能不能加速」的分水岭 |
| **制革、骨角、木作** | 日常器物的原料来源 |
| **食物保存**（腌制、熏制、风干、发酵） | 决定能否越冬、能否远征 —— 军事与人口都依赖它 |
| **建筑材料的量产**（砖、瓦、石灰、灰浆） | 有结构计算但缺「造这些要多少燃料与工时」 |

**这一层的价值**：它是「这个文明的技术水平」最直接的体现。
知道「炼钢需要多少焦炭」很厉害，但读者更常问「这一千人的聚落要多少人纺线」。

## 五、第五缺口：**社会如何失稳**（E 层，几乎全空）

这是最有意思的一块：**现有社会学全是「均衡」与「指标」，没有「动力学」。**

实测 `power/fiscal` 的 9 条，全是**状态量**：

```
  fiscal_revenue        人口 × 人均产出 × 税率     → 收多少
  fiscal_balance        收入 − 支出                → 赤字多少
  primary_balance       剔除利息的余额             → 有没有救
  fiscal_sustainability (i − g)·债务率 − 基本余额  → 债务涨多快
  seigniorage           通胀 × 实际货币余额        → 印钱能补多少
```

**它们能算「债务每年涨多少」，但没有一条说「涨到哪里会崩」。**

更值得注意的一个统计：全库 631 条里，名字带 threshold/critical/limit 的只有 10 条，
且**全是物理**——罗希极限、临界角、临界质量、光污染限、人口密度上限…

**没有一条是社会阈值。**

同样的问题在别处：`tragedy_commons`（公地悲剧）是**描述**，不是阈值；
`popitz_law`（权力集中）是**指标**，不是判据。

值得补的（都有可写的形式，但只能给量级）：

```
revolt_threshold        生存缺口 × 人口密度 × 组织能力 → 暴动概率（量级判据）
rebellion_growth        叛乱规模的动力学（与政府镇压能力的竞争）
elite_overproduction    精英过剩 → 内斗（这是王朝崩溃的常见机制）
legitimacy_decay        合法性衰减（税负/灾荒/战败的累积效应）
```

**注意**：这几条**没有精确解**，只能做量级判据。这符合本项目原则 ——
但必须明确标注「这是判据不是预测」，否则会被当成预言用。

## 六、按性价比排序的建议（如果要开工）

不是按「缺口大小」排，而是按**「补了之后能回答多少新问题 ÷ 成本」**排：

| 优先级 | 内容 | 条数 | 理由 |
|---|---|---|---|
| **P0** | **过程类配方**（SIR 时程、人口年表、资源枯竭、债务螺旋、技术扩散） | **0 条公式**，5 份 recipe | 现有 `ode`/`recurrence` 全支持，只是没人写模板。**成本最低、收益最大** |
| **P1** | 瘟疫与饥荒的闭式量 | 6~8 条 | 前工业社会的两大死因，现在完全算不出 |
| **P2** | 营养与生命表 | 8~10 条 | 「预期寿命 35 岁」的真相、饥荒的时间轴 |
| **P3** | 纺织/造纸/食物保存 | 10~12 条 | 前工业社会第一大产业 + 知识复制门槛 |
| **P4** | 地质速率（侵蚀、土壤形成、海岸） | 8~10 条 | 世界的时间深度 |
| **P5** | 社会失稳判据 | 6~8 条 | 最有叙事价值，但只能给量级，需谨慎标注 |

**合计约 40~50 条公式 + 5 份配方**，能把「完整世界观」的骨架补上。

## 七、三个「看起来该补但其实不必」的（避免浪费）

诚实地说，有些缺口**不该用公式填**：

| 候选 | 为什么不做 |
|---|---|
| **语言/语义** | 语言的演化、方言分布没有可靠闭式模型。硬做只会造出「看起来很学术但毫无预测力」的式子 |
| **宗教/文化的具体内容** | 这是**创作**不是计算。可以给「宗教组织的人数规模」（有标度律），但不能给「这个教义会不会流行」 |
| **精确的社会预测** | 本项目定位是「对比与自查」，不是预言。任何声称能预测革命或崩溃的公式都会误导 |

**这三条的共性：它们缺的不是公式，是「不可计算性」本身。**
一个真实世界恰恰因为这三点而真实 —— 如果一切可算，那就是一台机器。

---

## 八、一句话总结

> **现在的公式库能回答「这个世界是什么样」，但回答不了「这个世界怎么变」。**
>
> 补的方向不是继续加物理（那已经过剩 3 倍），而是补**时间**（过程）、
> **身体**（饥荒与疾病）、**土地**（地质速率）与**人心**（失稳判据）。
>
> 而这四样里，**性价比最高的是第一样，且它几乎不需要新公式 —— 只需要把已有的 ode/recurrence 写成可以直接抄用的配方。**

## 九、这份分析的依据与局限

### 依据

每一条判断都不是凭印象，都跑了实测：

| 判断 | 怎么核实的 |
|---|---|
| 「过程类」缺失 | 直接跑 `ode` 验证它**能**算 SIR，因此问题在配方不在能力 |
| 饥荒断链 | 按「需求→缺口→存活→死亡」四段逐一 grep，确认断在第 3、4 段 |
| 生命表缺失 | 查 `lifespan` 只有异速生长一条（跨物种，非同人群） |
| 社会阈值缺失 | 查全库带 threshold/critical/limit 的 10 条，**全是物理** |
| 化学工程全空 | 查 `chemistry/*` 23 条全是实验室尺度 |
| 层次分布 | 按 11 个层次分类统计，A 层 33.8%、E 层不足 1% |

### 局限（必须说清）

1. **「完整」没有客观标准**。这份分析假定「像真实世界」需要五类问题都能答，
   但这个前提本身是可争论的 —— 如果你的世界只需要「写故事够用」，P2/P4 都可以不做。

2. **缺口清单是我按学科推的，不是从你的设定里倒推的**。
   更准的做法是拿你的设定集反向扫一遍：「哪些数字是拍的、哪些是算的」——
   拍的那些才是真缺口。这需要读你的文档，本次没做。

3. **P5（社会失稳）我建议谨慎**。三条理由：
   没有可靠模型、容易被当预言、且**「不可计算」本身可能正是世界真实感的一部分**。

4. **条数是估计**。P1~P5 合计 40~50 条是量级，实际可能翻倍（每条都要配套测试与 desc）。

### 如果只做一件事

做 **P0**（5 份过程配方）。理由：

- 成本最低（不写公式、不写新测试套件，只写 help 里的可抄模板）
- 收益最大（把「静态快照」变成「能演算的世界」）
- 且它**不需要等用户拍板要做哪些学科** —— 无论后面补什么学科，过程配方都用得上

**具体是这五份**：

```
1. 瘟疫时程        ode 双状态（S/I），at:[7,14,28,56] 直接给「第几周」
2. 人口年表        recurrence 逐年，含出生/死亡/迁移三项
3. 资源枯竭        存量-流量，含 EROI 下降
4. 债务螺旋        recurrence，i 与 g 的比较
5. 技术扩散        逻辑斯蒂 + 阈值（复杂传染需 1/⟨k⟩）
```

每份都是「照抄 → 改两个参数 → 出表」，不需要理解微分方程。
