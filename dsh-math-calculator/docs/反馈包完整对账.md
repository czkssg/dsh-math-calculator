## 五、元判断：为什么之前只核了 28 项

```
00_结论与行动清单.md   28 项    ← 我拿这个当全量
01_全量问题清单.md     63 条    ← 正式编号
_issues_raw.json      348 条   ← 真正的最原始层
筛出不符/缺陷          96 条
```

**教训**：核对「有没有漏」必须找到**最原始那一层**。
拿摘要当全集，就会像上一版那样报「漏掉 9 项」而实际是 96 条。

这与项目一贯原则一致——**不能拿推导结论当原始数据**。
