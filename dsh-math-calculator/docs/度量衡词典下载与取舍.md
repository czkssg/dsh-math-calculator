# 度量衡词典：下载、筛选、取舍（2026-11-18）

> 用户要求：下载一个度量衡词典作为关联性依据，**去掉不需要的、只保留需要的**，再按实际需要编辑。

## 二、关键发现：两份词典都**不含中文**

先验证再规划，结果很关键：

```
GNU units 含中文行: 0
pint     含中文行: 0
```

（早先 `grep -c '[一-龥]'` 报 15/48 是编码误判，逐行验证是 0。）

**所以「从词典穷举中文别名」这条路走不通**——它们是英文词典。

有价值的不是中文，而是**关联关系**。

## 三、可提取的东西：名字 ↔ 标准符号的映射

| 词典 | 可提取 | 例 |
|---|---|---|
| GNU units | **809 条**「别名 → 标准名」 | `kilogram → kg`、`meter → m`、`arcminute → arcmin` |
| pint | **49 条** | `a_0 → bohr`、`bohr_radius → bohr`、`cycle → turn` |

这些是真实的**同义写法**，正好补我们缺的英文全称。

## 四、筛选：2368 → 337 → 92 条

| 步骤 | 数量 | 判据 |
|---|---|---|
| GNU 有、我们没有 | 2540 | 原始差集 |
| 去掉前缀/货币/数字词 | 2368 | `yotta-`、`US$`、`one`、`two`… |
| 只留物理量 | **627** | 定义串里有 SI 单位 |
| 去掉维度词与玩笑单位 | 337 | `LENGTH`、`crocodile`、`daraf` |
| **最终合入** | **92** | 只保留真实别名关系 |

**去掉的典型**：

- `crocodile`、`daraf`、`mho` —— 历史玩笑/废弃单位
- `hbar`、`G`、`c` —— 物理常数，不是单位
- `GBP`、`EGP`、`XAU` —— 货币
- `poundbiblepaper`、`poundtagpaper` —— 纸张重量细分（本项目不需要）

## 五、合入后踩的三个坑（都修了）

### 坑 1：`ohm` 与 `Ω` 互为别名 → 循环替换

```
数据表里 Ω / kΩ / MΩ 是独立单位，ohm / kohm / Mohm 也是
→ 两边互为别名 → 归一化互相替换
→ 1 ohm to kohm 变成 1 Ω to kΩ → mathjs 不认 Ω → 报错
```

**修法**：符号（Ω/kΩ/MΩ）只作别名，删除它们作为独立单位的条目；
并规定「**不往 Unicode 符号上映射**」——方向只能是 `Ω → ohm`。

### 坑 2：GNU 把 `degC` 挂在 `K` 上

```
100 °C to °F  →  100 K to degF  →  -279.67   ✗
```

因为 GNU 把摄氏当「温度差」处理（Δ°C = ΔK），而我们要是**绝对温标**。
已从 `K` 摘掉 `degC`/`degcelsius`/`degF` 等。

现在：`100 °C to °F = 212 degF` ✓

### 坑 3：英文别名子串误伤

```
knot → kn 让 knotmodern 变成 knmodern → unknown_symbol
```

**修法**：英文别名要求 **≥5 字符**（中文按字匹配不受影响）。

## 七、验证

- 全库 **113 套 / 2,615+ 项全绿**；`doccheck` / `preflight` 通过；

  这三个套件在改动过程中一度全崩，靠它们抓出了上面三个坑。

## 八、结论：词典的真正价值不是「多」，是「关联」

下载 221 KB 的 GNU 词典，最终只合入 **92 条**。

但每一条都是**真实的同义关系**（`a_0` 确实是玻尔半径的标准符号），
比我随手编的别名可靠——这正是「关联性依据」的意思。
