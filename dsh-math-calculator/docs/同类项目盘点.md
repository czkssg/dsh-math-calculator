> 目的：确认有没有「世界观推演 + 一致性检查」的同类；找可借鉴的功能。

## 二、结论：**没有直接同类**

检索不到「输入设定 → 物理/经济推演 → 一致性校验」的完整开源引擎。
现有项目分两类：

1. **设定管理类**（chronicler / kanka / worldcraft-codex）——存设定、画关系、做 wiki；
2. **写作生成类**（AI-Novel-Writing-Assistant / storycraftr / mythpen）——生成正文，不校验数值。

我们做的事（推演引擎 + 硬边界 + 对账）**在这个生态里是空白**。

## 三、可借鉴的三点（不是代码，是思路）

1. **dmasad/WorldBuilding 的「模型串联」**：它的历史是「人口模型 → 经济模型 → 冲突模型」级联生成。
   我们的 `backtrace` 只拼公式链，还没拼**模型链**（world → 人口 → 财政 → 冲突）。这是下一步可学的结构。
2. **Project_Psychohistory 的「生成式历史学家」**：给一个文明状态，产出历史事件序列。
   我们的 `civilization` 只算上限（能源/材料/交通），不生成事件。若要做「历史推演」，这是参考。
3. **timelines 的交互式时间线**：我们只有`timeline_check`校验。
   但这是 UI 层，本插件定位是工具（无界面），不引。

## 四、判定

| 项 | 判断 |
|---|---|
| 引入 chronicler/kanka | ❌ 是 UI/wiki，我们是工具，重复 |
| 引入 AI-Novel-Writing-Assistant | ❌ 是写作系统（TS/浏览器），定位不同 |
| 借鉴「模型串联」结构 | ✅ 值得（把 backtrace 从公式链升级到模型链） |
| 借鉴「生成式历史」 | ⚠️ 可选（`civilization` 目前只给上限） |
| 引入 timelines UI | ❌ 无界面定位 |
