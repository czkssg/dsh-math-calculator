## 二、已接入：optimize（线性/整数规划）

它补的是**优化**：公式能算「这个配比产出多少」，但算不了「什么配比最优」。

调用形态：

    { "operation":"optimize", "objective":"profit", "opType":"max",
      "constraints":{ "labor":{"max":100}, "steel":{"max":80} },
      "lpVariables":{ "A":{"profit":3,"labor":2,"steel":1}, "B":{"profit":5,"labor":4,"steel":3} } }

实测结果：

- 最大化 profit → 最优 150；A=50、B=0（劳动力是瓶颈）
- 最小化 cost → 最优 50；y=12.5（全用 y，单位成本更低）
- 整数规划 → gold 取整数
- 未声明资源 → 报错（不静默忽略）

用途：资源怎么配产出最大、工厂怎么排产成本最低、军队怎么分兵完成率最高。

## 三、下一块：System Dynamics

scottfr/simulation 是 JS 的 System Dynamics 引擎（存量/流量、反馈回路）——
正好是「人口/资源/经济长期演化」的建模法（World3 用它做《增长的极限》）。

它与我们 history 的分工：

- history：给时间序列，切成纪元；
- System Dynamics：给存量和流量，**自己演化出时间序列**。

若能用，就能回答「这个文明的资源存量 50 年后会怎样崩」——目前唯一缺的长期动态。
