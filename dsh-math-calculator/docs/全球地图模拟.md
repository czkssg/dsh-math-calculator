# 全球地图模拟（2026-11-16）

> 用户要求：中等精度的全球地图全量模拟（地形地质：山川河流平原、地势；大型矿产标注），
> 可编辑（国家边界、地形到海陆分布），用于推演平行宇宙的地球。

## 一、开源选型（先查再写）

| 库 | 版本/许可/体积 | 判断 |
|---|---|---|
| **Azgaar/Fantasy-Map-Generator** | ★6220 / **NOASSERTION** | ❌ **不引代码**（许可非标准宽松）；✅ 只借鉴算法思路（噪声高度场→河流→国家分区） |
| **simplex-noise** | 4.0.3 / MIT / 109KB | ✅ 用（多层噪声高度场） |
| **d3-delaunay** | 6.0.6 / ISC / 141KB | ✅ 用（Voronoi 国家分区） |

## 二、实现的管线

```
多层 simplex 噪声 → 归一化 → 分位阈值（海陆）
  → 地形分类（海洋/海岸/平原/丘陵/山地/高原/河谷）
  → 河流（从高处沿下降方向追踪，入海）
  → 矿产（按地质带：山地金属、高原煤铀稀土、平原煤油气、河谷砂金钻石）
  → 国家（Voronoi 分区）
  → 编辑（edits 覆盖 height/seaLevel/nation）
```

## 三、关键设计：海陆比可精确控制

**seaLevel 的语义是「陆地目标占比」**，不是高度阈值：

```
seaLevel: 0.29 → 实际陆地 29.0%（地球量级）
seaLevel: 0.10 → 实际陆地 10.0%
seaLevel: 0.60 → 实际陆地 60.0%
```

实现方式：归一化高度后按分位数取阈值。这样「编辑海陆分布」是直观的——给 0.1 就是 10% 陆地。

**踩的坑**：第一版直接用 `seaLevel` 当绝对高度阈值，结果 0.29 得到 58.6% 陆地
（噪声分布不是均匀的）。改用分位数后精确。

## 四、可编辑

```jsonc
edits: [
  { x: 10, y: 10, height: 1 },      // 这块抬成高地（陆地）
  { x: 11, y: 10, nation: 99 },     // 这块归给国家 99（可造新国/改边界）
  { x: 7,  y: 5,  seaLevel: 0.5 }   // 改全局海陆比（淹没/抬升）
]
```

## 五、精度边界

- 网格默认 **180×90（16,200 格）**，可到 360×180；
- 能看出山脉走向、河流干流、国家分区；
- **不是**气象/气候模拟粒度——没有温度场、降水场、风带；
- 矿产是「地质带 + 随机」的统计分布，不是真实矿床模型。
## 六、平面 vs 球体（2026-11-16 追加）

> 用户要求：支持平面（天圆地方）与球体（星球），并防止 AI 在星球世界观里
> 「跨大半个地图去很近的地方」。

### 为什么必须分

球体世界里，**地图左边缘与右边缘是同一条经线**。若按平面欧氏算距离，
AI 会认为要跨 359 格；实际只有 1 格。

实测（360×180 网格，x=0 与 x=359、同一纬度）：

| 拓扑 | 距离 | 格数 |
|---|---|---|
| **sphere** | **111 km** | **1.0 格** |
| plane | 39,919 km | 359.0 格 |

### 三种影响

| 环节 | 球体处理 |
|---|---|
| 距离（`mapDistance`） | 大圆（haversine）——经度取环绕最短 |
| 河流下坡邻接 | x 方向环绕（`(x+dx+width)%width`） |
| 国家 Voronoi | 经度差取环绕最短 + 按纬度 `cos(lat)` 收缩 |
| 陆地占比统计 | **面积加权**（高纬格实际面积小） |
| 海陆阈值 | 面积加权分位（否则极地格让占比失真） |

### 调用

```jsonc
{ "operation":"world-map", "worldTopology":"sphere", "mapWidth":360, "mapHeight":180,
  "seed":7, "seaLevel":0.29,
  "mapDistance":{ "from":{"x":0,"y":90}, "to":{"x":359,"y":90} } }
```

返回 `distance:{km, cells, note}`，note 明确写「球体：跨 180° 经线自动取最短」。

### 精度与体积

- 默认 720×360（0.5°），上限 1440×720（0.25°）；
- 超 10 万格输出量化（heights/terrain/nations → base64），1 MB 级。
