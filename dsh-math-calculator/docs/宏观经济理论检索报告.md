# 宏观经济学：国家级/文明级可推导的理论与公式

> 面向「小说世界观中的国家与文明」的宏观层。**明确排除微观经济学** ——
> 理由见第一节：微观不可控，而宏观有可抓的恒等式与守恒约束。
> 只列清单与判据，不含代码；来源全部可核验。

---

## 一、为什么宏观能做、微观不做

你的判断是对的，而且有明确的经济学依据：

| 层 | 可推导性 | 原因 |
|---|---|---|
| **微观**（个体、企业、定价） | **几乎为零** | 偏好、议价、信息差都是**自由意志与局部博弈**，没有守恒约束 |
| **宏观**（产出、增长、财政、货币） | **有结构** | 存在**会计恒等式**（收入=支出）、**存量-流量一致性**、**守恒律**，这些不随个体差异改变 |

所以宏观层的公式有两类，可信度完全不同：

```
  ① 恒等式与守恒  → 必然成立（任何世界观都逃不掉）  例：Y = C + I + G + NX
  ② 行为关系      → 有统计规律但可被打破            例：Phillips 曲线、库兹涅茨曲线
```

**这批公式的价值在于：① 类给出「硬约束」，② 类给出「倾向性」。**
写文明设定时，① 类能立刻否掉荒谬方案，② 类只能作为参考趋势。

## 二、A 组：恒等式与守恒（最硬，任何世界观都成立）

### A1. 支出法 GDP 恒等式

```
  Y = C + I + G + (X − M)
  消费 + 投资 + 政府支出 + 净出口
```

- **性质**：**会计恒等式**，不是理论 —— 它只是「所有产出都被某人用掉了」的记账
- **跨世界照用**：✓ **绝对成立**，因为它是定义而非经验
- **为什么对设定有用**：它能立刻暴露不平衡。比如设定「这个文明年产 100 亿吨粮、
  却要养 50 亿人还要造星舰」，`I`（投资）与 `C`（消费）就会超出 `Y`，
  差额只能来自净进口（`M<X`）或举债。**作者编的数字必须闭合在这四项里**
- 现有库：`gdp_from_labor`（劳力×人均产出）是生产法，**支出法这一侧缺**

### A2. 增长核算（Solow 余量 / TFP）

```
  g_Y = g_A + α·g_K + (1−α)·g_L

  产出增长 = 技术进步 + 资本贡献 + 劳动贡献
```

- 来源：**美国劳工统计局 BLS 的官方 TFP 方法**（明写「based on the growth accounting model
  introduced by Robert Solow」）；Berkeley 讲义《Growth Accounting》完整推导；
  Solow 1957 原始论文；Wikipedia《Solow residual》
- **性质**：由柯布-道格拉斯生产函数取对数后微分得到，**是推导出来的**，不是拟合
- **跨世界照用**：✓（α 可调，代表「资本密集程度」）
- **这是宏观层最有用的式子之一**：它把「增长从哪来」拆成三份。
  作者设定「这个文明靠什么增长」时，`g_A` 就是「技术进步率」，
  而它**可以直接从「有没有科研体系」来设定**
- 现有库：有 `cobb_douglas` 但**没有增长核算的分解形式**

### A3. 索洛稳态与趋同速度

```
  稳态：      s·f(k) = (n + δ + g)·k
  趋同速度：  λ = (1−α)·(n + δ + g)
  收敛解：    ln k(t) − ln k* ≈ e^(−λt)·(ln k(0) − ln k*)
```

- 来源：econometricstutor 的 Solow 推导（明写 `λ = (1−α)(n+δ+g)`）；
  Wikipedia《Solow residual》上下文；R 的 REAT 包 β 收敛函数文档
- **性质**：**由模型推导**（线性化近似），不是经验拟合
- **跨世界照用**：✓（n、δ、g、α 全是设定量）
- **价值**：回答「这个落后文明追赶先进文明要多久」。
  这是**文明级设定里最常问的问题**，而现有库只有 `solow_steady_state`（终点），
  **缺「多久到达」这个速度**
- 注意：这是**条件趋同**（conditional），不是无条件趋同 —— 各国追向各自的稳态

## 三、B 组：财政与债务（文明寿命的核心）

### B1. 债务动态方程 —— 「这个帝国会不会破产」

```
  d_t = (1+i)·d_{t−1} − p_t        （IMF 形式，d 为债务/GDP 比）
  或增量式： Δd = (i − g)·d − p    （i>g 时债务负担自我膨胀）
```

- 来源：**IMF 技术手册 TNM/2010/02《A Practical Guide to Public Debt Dynamics》**
  （明写递归式 `d_t = (1+i)d_{t−1} − p_t`）；**欧洲央行 ECB Economic Bulletin 2019**
  （「i 与名义增长 g 之差是债务动态的关键变量」）；法国 Tresor-Economics No.334；
  Annual Review of Financial Economics 综述
- **性质**：**会计恒等式 + 差分方程**，可严格求解（IMF 手册给了闭式解）
- **跨世界照用**：✓ 完全通用
- **这是宏观里最有戏剧张力的一条**：

```
  i > g  → 即使不借新债，债务/GDP 也在涨（自我恶化）
  i < g  → 通胀与增长会「稀释」旧债务
```

  这解释了为什么古代帝国（`i` 高、`g` 低）债务危机频繁，
  而高增长期（`g` 高）可以「靠增长还债」
- 现有库：**完全没有**（`fiscal_revenue` 只算收入，没有动态）

### B2. 拉弗曲线（税率与税收收入）

```
  R = t · Y(t)        Y 随 t 下降，R 是倒 U 形
  最优税率 t* 使 dR/dt = 0
```

- **性质**：⚠ **理论假设，不是定量律**。拉弗本人当年画在餐巾纸上，
  没有给出可靠的 `t*` 数值；实证争论极大
- **判定**：**不做成公式**（没有可用的系数）。但可以在 help/desc 里作为定性提示
  「税率过高会减少总税收」
- 若要做，只能做**纯形式**（`R = t·Y₀·(1−b·t)`，b 需设定），且必须标 `[仅方向]`

## 四、C 组：货币与价格（有理论但可被打破）

### C1. 货币数量方程（费雪方程）

```
  M · V = P · Y        （或 MV = PT）
  货币量 × 流通速度 = 物价 × 交易量
```

- **性质**：**恒等式**（如果 V 定义为 PY/M），但**作为理论使用时含假设**（V 稳定）
- **跨世界照用**：✓ 恒等式部分通用；⚠「V 稳定」是假设
- **价值**：这是通货膨胀的**结构性解释**。与现有 `inflation_from_money_growth`
  （`通胀 ≈ 货币增速 − 产出增速`）相比，费雪方程给出**更完整的形式**，
  且能把 `V`（货币流通速度）作为一个独立可调量 ——
  **金属货币社会的 V 低，信用货币社会的 V 高**，这是重要的世界观参数
- 现有库：**没有**（只有近似式 `inflation_from_money_growth`）

### C2. 菲利普斯曲线（通胀-失业权衡）

```
  期望增强版： π = π^e − γ(u − u_n)
  π 通胀 ｜ π^e 预期通胀 ｜ u 失业率 ｜ u_n 自然失业率 ｜ γ 敏感度
```

- 来源：**Yale Smith《Econ 116a Lecture 5b》**（明写 `πt − πe_t = −γ(ut − un)`）；
  Mankiw 教材第 14 章；澳洲联储 RBA RDP 2021-09 综述
- **性质**：⚠ **经验关系**，且**已被 1970 年代滞胀部分推翻**（Friedman/Phelps 的
  期望增强版正是为了修补它）
- **跨世界照用**：⚠ **谨慎**。它不是物理律，而是**特定制度下的统计倾向**
  在非市场经济（配给制、计划价格）里通常不成立 —— 而架空设定里这类社会很常见
- **判定**：可做，但 desc 必须写明「成立前提是价格由市场形成」
- **价值**：如果这个世界是市场经济，「通胀换就业」是可以在政策上权衡的；
  如果是配给制，这条不适用 —— 这个区分本身就是有用的设定信息

### C3. 购买力平价（PPP）

```
  绝对 PPP：   S = P_A / P_B              （汇率 = 两国物价之比）
  相对 PPP：   ΔS/S ≈ π_A − π_B          （汇率变动 ≈ 通胀之差）
```

- 来源：**Krugman-Obstfeld-Melitz 教材第 15 章**（明写绝对版 `P$ = PDM × Spot`）；
  NYU Stern《Chap-45》给出两版的符号表；IMF Staff Papers 2002 定义
- **性质**：**由套利逻辑推出**（可贸易品），但现实中因不可贸易品、关税、
  运输成本而长期偏离
- **跨世界照用**：⚠ 有条件 —— 需要「可贸易」与「套利可行」
- **价值**：如果设定里有多个文明/国家做贸易，这条决定**汇率长期锚在哪**
- 现有库：`purchasing_power`（通胀后购买力）是单国口径，**缺双国的汇率关系**

## 五、D 组：结构与发展（文明阶段论）

### D1. 刘易斯二元经济与拐点

```
  传统部门（农业）：劳动边际产出 ≈ 0，存在剩余劳动力
  现代部门（工业）：吸收剩余劳动，工资长期不变
  拐点（Lewis turning point）：剩余劳动耗尽 → 工资开始上涨
```

- 来源：**Lewis 1954 原始论文《Economic Development with Unlimited Supplies of Labour》**（有全文 PDF）；
  **JEP 2014《The Lewis Model: A 60-Year Retrospective》**；英国曼大 Lewis 传记页
- **性质**：**定性模型，无单一公式**。核心是「两个部门 + 拐点」这个结构
- **跨世界照用**：✓ 结构通用（尤其适合写「农业文明 → 工业文明」的转型）
- **判定**：**不做成数学公式**（没有单一的定量式），但值得做成 **help 的一个推演配方**：

```
  给定：农业人口比例、农业剩余率、工业投资率
  推出：还能转移多少剩余劳动、离拐点还有多远
  拐点后：工资上涨 → 通胀压力 → 必须靠技术进步维持增长
```

  这条**能解释「为什么工业化初期能高速增长、后期必须转型」**，是文明叙事的骨架

### D2. 库兹涅茨倒 U 曲线（增长与不平等）

```
  不平等随人均收入先升后降（倒 U）
```

- 来源：Wikipedia《Kuznets curve》（1955 原始假设）；
  **Structural Change & Econ Dynamics 2025《Kuznets at 70》**（70 年后仍在讨论）；
  Applied Econ Letters 的 96 国面板检验
- **性质**：⚠ **假设，实证支持很弱**。Wikipedia 与多篇综述都指出
  「**证据混杂**，且 1980 后许多国家呈 U 形而非倒 U」
- **判定**：**不做成公式**（没有可用的定量形式，且结论不牢）
- 但可作为 **desc 里的定性背景**：「工业化初期不平等上升是常见模式，但非必然」

### D3. 恩格尔系数（食品支出占比）

```
  恩格尔系数 = 食品支出 / 总支出
  越穷越高（>50% 为贫困，<30% 为富裕）
```

- **性质**：✓ **统计规律，相当稳健**（跨国家跨时代都成立）
- **跨世界照用**：✓（只要还有「吃」这个需求）
- **价值**：它是**最便宜的生活水平代理指标**。写「这个城市的人过得怎么样」时，
  一个数就够，不必编一堆价格
- **判定**：**值得做**（成本极低，用处很大）

### D4. 抚养比与人口红利

```
  抚养比 = (少年人口 + 老年人口) / 劳动年龄人口
  红利期 = 抚养比低谷（劳动人口占比最高的几十年）
```

- **性质**：✓ **纯人口学比值**，与经济学无关，是人口结构决定的
- **跨世界照用**：✓ 完全通用
- **价值**：解释「为什么某个时代会突然繁荣」——往往是**人口结构**而非制度
  这是文明叙事里很好用的一条：**红利期只有几十年，过了就变成负担**
- 现有库：`labor_force`（劳力数）**缺抚养比与红利窗口**

## 七、这批公式怎么服务「文明级推演」

### 场景 A：检查设定数字是否闭合

```
设定：这个文明年产 Y = 100 亿吨粮 + 星舰若干
gdp_expenditure：Y = C + I + G + NX
→ 如果 C（养人）+ I（造舰）+ G（军费）> Y，差额只能：
   · NX 为负（大量进口）→ 需要有贸易伙伴，且对方愿意卖
   · 举债 → 触发 debt_dynamics，看 i 与 g 的关系
→ 结论：不闭合的设定会被这条立刻拆穿
```

### 场景 B：推算增长速度的可持续性

```
growth_accounting：g_Y = g_A + α·g_K + (1−α)·g_L
若设定「人口停止增长」（g_L = 0）、「资本已达稳态」（g_K ≈ 0）
→ 则 g_Y ≈ g_A，即**只能靠技术进步**
→ 这是「为什么停滞文明会停滞」的定量答案
```

### 场景 C：帝国财政的死亡螺旋

```
debt_dynamics：Δd = (i − g)·d − p
若 i = 8%（高利贷）、g = 2%（停滞），d = 100% GDP、p = 0：
→ Δd = 6% × 100% = 6% GDP/年 → 债务每年涨 6 个点
→ 十几年就翻倍，且**全靠增长还债的路走不通**（i > g）
→ 唯一出路：削减赤字 p > 0，或提高 g（技术/人口/掠夺）
```

**这是「帝国为什么会崩溃」最标准的经济学答案，而且它是可计算的。**

## 八、两个必须守住的边界

### 边界 1：不要把「行为关系」当「硬约束」

恒等式（A 组）是**任何设定都逃不掉**的；
行为关系（B/C 组）是**特定制度下的统计倾向**，可被设定推翻。

如果混淆，就会出现「工具告诉我这个文明不可能存在」—— 而实际上只是不满足某个
统计倾向。这是**过度断言**，比不给结论更糟。

### 边界 2：宏观公式用的是「加总量」，回到微观会失真

所有宏观公式都在 **aggregate** 层面成立。若作者问「这 50 个人平均收入多少」，
那不是宏观问题，`evaluate` 算就行。**不要用 GDP 公式回答个体问题**。
