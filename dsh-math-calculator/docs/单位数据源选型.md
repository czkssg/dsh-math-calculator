| 源 | 内容 | 许可 | 判断 |

## 二、UCUM 表的最大价值：三套英制

这是本次调研**最重要的发现**。UCUM 明确区分：

```
[IN_I]    国际英寸（254e-2 cm）        ← 1959 国际协定
[IN_US]   美制英寸（1 ft_us/12）       ← 1893 前的美国标准
[IN_BR]   英制英寸（2.539998 cm）      ← 英国 Imperial Standard
```

三者差异极小（1e-6 量级），但**链式定义会放大**：

```
[FT_US] = 1200 m/3937        ← 美制英尺 = 0.304800609601 m
[FT_I]  = 12 [in_i]          ← 国际英尺 = 0.3048 m（精确定义）
```

美制英尺比国际英尺长 **6.1e-7**（0.6 ppm）。单看可忽略，
但在**大地测量**（几百公里）上会累积到米级。

## 三、UCUM 表独有的、我们缺的单位

### 木材与纸（蒸汽朋克货运常用）

```
[BF_I]   板英尺 = 144 in³ = 2.36 L
[CR_I]   考得（柴堆）= 128 ft³ = 3.62 m³
[CML_I]  圆密尔 = π/4 × mil²   ← 电线规格 AWG 的基准
```

### 印刷（蒸汽朋克的书报业）

```
[PNT]      point = 1/12 line
[PCA]      pica = 12 point
[PNT_PR]   Printer's point = 0.013837 in
[DIDOT]    迪多 = 1/6 ligne
[CICERO]   西塞罗 = 12 didot
```

### 药衡（apothecary）

```
[SC_AP]  scruple = 20 grain = 1.296 g     ← 药剂师的最小单位
[DR_AP]  dram = 3 scruple = 3.888 g
[OZ_AP]  ounce = 8 dram = 31.103 g
[LB_AP]  pound = 12 oz = 373.24 g
```

### 六种 BTU 与五种卡路里

```
[BTU_39]  1.05967 kJ   39°F 下的 BTU
[BTU_59]  1.05480 kJ   59°F
[BTU_60]  1.05468 kJ   60°F
[BTU_M]   1.05587 kJ   平均
[BTU_IT]  1.05505585262 kJ  国际表（最常用）
[BTU_TH]  1.054350 kJ  热化学
```

蒸汽朋克写「锅炉 1000 BTU」时，**选哪一种是真有差别的**（差 0.5%）。

### 美制干量（与液量分开）

```
[BU_US]  蒲式耳 = 2150.42 in³ = 35.239 L    ← 谷物
[PK_US]  配克 = 1/4 bu
[DQT_US] 干夸脱 = 1/8 pk
[DPT_US] 干品脱
[GAL_WI] Winchester 加仑（历史单位，1101 年 Winchester 标准）
```

**干量加仑 ≠ 液量加仑** —— 这是英制最反直觉的地方之一。

### 纺织

```
TEX = 1 g/km        特克斯
[DEN] = 1 g/9km     但尼尔（Denier，丝袜与纤维）
```

### 其他

```
[MESH_I]   目数 = 1/英寸      ← 筛网
[CH]       Charrière = 1/3 mm ← 医疗导管
[DRP]      滴 = 1 mL/20
[MET]      代谢当量 = 3.5 mL/min/kg
```

## 四、为什么不能直接打包 UCUM 库

`@lhncbc/ucum-lhc`（8.0.1，BSD，26.9 万周下载）能解析 UCUM 表达式，
但**它不理解中文**，也不提供「中文单位 ↔ UCUM 代码」的映射。

我们的架构是：
```
第 1 层  中文归一    cnchi → 注册名（自建，462 条 + 历史）
第 2 层  数值计算    mathjs + BigNumber
第 3 层  单位定义    从 UCUM 学来的因子（手工录入）
```

**不引入 ucum-lhc 的理由**：它的价值在「解析 UCUM 字符串」，
而我们的输入是中文表达式。引入它只增加 1.1 MB 而解决不了核心问题。

**它的价值在数据，不在代码** —— 所以按数据源采用。

## 五、采用方式

```json
{
  "source": "UCUM ucum-ci.units",
  "license": "GPL-2.0（本表只取事实性数据：单位名与换算因子）",
  "note": "单位换算因子是历史与物理事实，不受版权保护；
           本项目的注释与组织结构为原创"
}
```

每条单位在 `note` 里标注来源，便于追溯与复核。
