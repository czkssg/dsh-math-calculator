# 对外服务（mathEngine）

> 2026-11-20 · v3.30.0。对《数学插件对外服务化》提案（2026-11-20）的回应与实现说明。

## 一、已实现（第一期）

插件在 `apply` 里注册 **cordis 服务** `mathEngine`：

```ts
const engine = ctx.get('mathEngine')   // 可选；没有就是没装
const out = engine.evaluate('1 m + 1 ft')
// { ok: true, number: '1.3048', unit: 'm' }
```

**不经过工具流水线、不写会话历史、无 UI 副作用**；底层复用 `dispatchNew`（与工具同一套实现）。

### 方法

| 方法 | 作用 | 示例 |
|---|---|---|
| `describe()` | 能力自述 | `{ version, operations, unitFamilies, supportsCustomUnits, methods }` |
| `evaluate(expression, { variables? })` | 求值 | `evaluate('2+3') → { number: '5' }` |
| `convert(value, from, to)` | 单位换算 | `convert(1, 'm', 'ft') → { number: '3.2808399', unit: 'ft', steps: [...] }` |
| `checkDimension(unit)` | 量纲/单位校验 | `checkDimension('kg/m3') → { ok: true, unit: 'kg/m3' }` |
| `formula(id, params?)` | 公式代入（第三期） | `formula('kinetic_energy', { m: 2, v: 3 }) → { number: '9', unit: 'J', value: { output: '能量' } }` |
| `interval(expr)` | 区间运算（第三期） | `interval('20-50') → { number: '35', value: { result: { low: 20, high: 50 }, confidence: '很松' } }` |
| `constant(name)` | 常量查询（第三期） | `constant('c') → { number: '299792458', unit: 'm/s' }` |

### 返回结构（值与展示分离）

```ts
interface EngineServiceResult {
  ok: boolean
  number?: string        // 规范数值（字符串，避免浮点误差）
  unit?: string          // 无量纲时省略
  value?: unknown        // 复数 {re,im}、单位描述等
  steps?: string[]       // 推导过程（结构化数组）
  error?: { type: string; kind: 'input' | 'capability' | 'internal'; message: string; hint?: string }
}
```

不返回排版文本——怎么展示由调用方决定。

### 错误三档

| kind | 含义 | 调用方应对 | 覆盖的错误类型 |
|---|---|---|---|
| `input` | 输入写错 | 修正后重试 | `invalid_argument` `missing_params` `unit_mismatch` `non_finite` `out_of_range` |
| `capability` | 能力缺失 | **可降级** | `unknown_symbol` `unknown_unit` `unknown_formula` `unknown_argument` `unknown_subcommand` `unknown_op` `not_supported` |
| `internal` | 插件异常 | 记录并降级，不重试 | 其余 |

## 四、第二期：自定义单位命名空间（已实现）

```ts
engine.registerUnits('world-a', [
  { name: 'zcredit', factor: 1, base: '' },        // 无量纲（货币/计件）
  { name: 'zli', factor: 500, base: 'm' },         // 1 zli = 500 m
])

engine.evaluate('1 zli', { namespace: 'world-a' })   // { number: '1', unit: 'zli' }
engine.convert(1, 'zli', 'm', { namespace: 'world-a' }) // { number: '500', unit: 'm' }

engine.listUnits('world-a')        // 列出
engine.unregisterUnits('world-a')  // 注销（丢弃该世界的独立引擎）
```

实现要点：

- **每个命名空间一个独立引擎**（`createEngine()` 无缓存工厂）：单位只在该世界内生效，不污染全局；
- 注销 = 丢弃引擎实例（真正移除，不留残留单位）；
- **注册校验**：单位名必须字母开头字母数字；`factor` 正有限数；与内置/已注册同名直接拒绝；
- `base` 必须是已知单位（`m`/`kg`/`s`…）；无量纲留空；
- 未知命名空间 → `capability`（可降级）。

## 五、第三期：公式 / 区间 / 常量（已实现）

```ts
engine.formula('kinetic_energy', { m: 2, v: 3 })
// { ok: true, number: '9', unit: 'J', value: { id, name, expr, output: '能量' } }

engine.interval('20-50')
// { ok: true, number: '35', value: { result: { low: 20, high: 50 }, confidence: '很松', … } }

engine.constant('c')
// { ok: true, number: '299792458', unit: 'm/s', value: { name: 'c', meaning: '真空光速' } }
```

- `formula` 支持按 id 或中文名；参数缺省走公式默认值；输出量随 `value.output` 返回；
- `interval` 返回结构化区间（low/high/mid/相对半宽/置信档）；
- `constant` 读 `constants-graph.json` 的标准值（不是覆盖后的世界常数）。

## 五点五、扩展注册（货币 / 公式）

调用方可以往命名空间里**注册自己的货币与公式**（与自定义单位同一套隔离）：

```ts
engine.registerCurrencies('world-a', [
  { code: 'ZCR', name: '信用币', symbol: '¤', abbrev: '信', kind: 'fantasy' },
])
engine.currency('list', { namespace: 'world-a' })      // 内置 47 + 自定义
engine.currency('get', { code: 'ZCR', namespace: 'world-a' })

engine.registerFormulas('world-a', [
  { id: 'zpower', name: '自定功率', expr: 'F * v', params: { F: 1 }, unit: 'W' },
])
engine.formula('zpower', { F: 10, v: 2 }, { namespace: 'world-a' })  // { number: '20' }
```

- 注册校验：货币 code 字母开头（可含下划线）、不得与内置同名；公式 id 同理、expr 非空、params 为有限数；
- 隔离：不同命名空间互不可见；注销用 `unregisterCurrencies` / `unregisterFormulas`（只清该类，保留引擎与单位）；
- `formula()` 先查命名空间自定义公式，没有才走内置公式库。
