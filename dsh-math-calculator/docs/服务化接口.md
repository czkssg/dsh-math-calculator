# 对外服务（mathEngine）

> 2026-11-20 · v3.30.0。对《数学插件对外服务化》提案（2026-11-20）的回应与实现说明。

## 一、已实现（第一期）

插件在 `apply` 里注册 **cordis 服务** `mathEngine`：

```ts
const engine = ctx.get('mathEngine')   // 可选；没有就是没装
const out = engine.evaluate('1 m + 1 ft')
// { ok: true, number: '1.3048', unit: 'm' }
```

**不经过工具流水线、不写会话历史、无 UI 副作用**；底层复用 `dispatchNew`（与工具同一套实现）。

### 方法

| 方法 | 作用 | 示例 |
|---|---|---|
| `describe()` | 能力自述 | `{ version, operations, unitFamilies, supportsCustomUnits, methods }` |
| `evaluate(expression, { variables? })` | 求值 | `evaluate('2+3') → { number: '5' }` |
| `convert(value, from, to)` | 单位换算 | `convert(1, 'm', 'ft') → { number: '3.2808399', unit: 'ft', steps: [...] }` |
| `checkDimension(unit)` | 量纲/单位校验 | `checkDimension('kg/m3') → { ok: true, unit: 'kg/m3' }` |

### 返回结构（值与展示分离）

```ts
interface EngineServiceResult {
  ok: boolean
  number?: string        // 规范数值（字符串，避免浮点误差）
  unit?: string          // 无量纲时省略
  value?: unknown        // 复数 {re,im}、单位描述等
  steps?: string[]       // 推导过程（结构化数组）
  error?: { type: string; kind: 'input' | 'capability' | 'internal'; message: string; hint?: string }
}
```

不返回排版文本——怎么展示由调用方决定。

### 错误三档

| kind | 含义 | 调用方应对 | 覆盖的错误类型 |
|---|---|---|---|
| `input` | 输入写错 | 修正后重试 | `invalid_argument` `missing_params` `unit_mismatch` `non_finite` `out_of_range` |
| `capability` | 能力缺失 | **可降级** | `unknown_symbol` `unknown_unit` `unknown_formula` `unknown_argument` `unknown_subcommand` `unknown_op` `not_supported` |
| `internal` | 插件异常 | 记录并降级，不重试 | 其余 |

## 二、与工具共存

- 模型对话照旧用 `math_execute`（提示注入与提醒钩子不动）；
- 其他插件用 `mathEngine`；
- **一致性由测试锁住**：`r81-math-engine-service` 断言「同输入经两条路径得到相同数值」。

## 三、发现与降级（调用方约定）

```ts
const engine = ctx.get('mathEngine')
if (engine === undefined) { /* 没装：走自己的兜底，不要报错 */ }
```

服务缺失时 `ctx.get` 返回 undefined（不要硬依赖）。
