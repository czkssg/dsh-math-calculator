# dsh-math-calculator v3.0.0 发布公告

**发布日期**：2026-11-13

## 一句话

v3 是把实现按「数据 / 功能 / 入口」三层重排的**重写版**：45 个 operation 全部走新实现，
公式库从 665 条扩到 **773 条**（带来源与量纲），删除了 5,700 行老入口与 60+ 个老模块，
测试从 14 套扩到 **45 套 / 1,810 项**。

## 主要变化

### 1. 入口分层（破坏性内部重构，对调用方兼容）

- `dispatch.ts`：operation 路由（45 个；未覆盖路径直接报明确错误，不再静默回退）
- `tool.ts`：schema / execute / render（输出 schema 完整声明 `additionalProperties:false`）
- `index.ts`：5,735 行 → **180 行**，只留注册工具 + 系统提示 + agent 提醒钩子
- 删除：`src/ops/*`（24 个）、老工具实现、自动建表、UI 后端路由

### 2. 公式库 665 → 773

- **结构化**：参数带 `quantity`（语义量名）与 `dimension`（7 基量向量），
  支持 `{T:"300 K"}`、`{P:"1 atm"}` 这种带单位参数，量纲不符报 `unit_mismatch`
- **反解**：`{formula:"...", solveFor:"m", targetValue:100}`（符号解 + 数值兜底 + 代回验证）
- **公式即函数**：参数契约（必填/默认）、缺参点名、调用结果带相邻公式
- **关系图**：按共用物理量/常数/同标签连边（40,794 条边），同名异义会标注
  （如 `n`：物质的量 vs 数量）
- **信源**：92 条公式带 `sources`（教材章节 + URL + 许可 + 访问日期）
- 4 条展示式（含 Σᵢ）显式标记，求值时报「这是展示式」而不是语法错

### 3. 新增 operation

`chain`（链条传导）、`threshold`（阈值判定）、`scaling`（缩放律）、`anchor`（基准锚定）、
`quick_feasible`、`hierarchy`、`world_state`、`units_audit`、`timeline_check`、`extract_numbers`

### 4. 实体拓扑

距离/最短路径/视线/可达预算、建筑与载具容量、七条通用规则（闭合/对称/无环/可达/容量/连续/一致）

### 5. 修复（示例）

- `noonElevation` 北半球冬至返回夏至值（45°N 68.44° → 21.56°）
- `feasibility` 字符串单位被静默丢弃、未知 id 假通过
- `chain` 断点用累计占比（永远判末段）→ 增量占比
- `algebrite` 特征值省略号导致 `eig` 假失败
- 德拜低温热容系数 `9R` → `(12π⁴/5)R`（偏低约 26 倍）
- 精度三件套：超精度提示、`displayPrecision:0` 只留整数、越界钳制并提示
- `balance` 跨量纲拒绝、`dist` 多余参数拒绝、`world terrain.kind` 拼错报错

## 升级注意

- **调用方无需改参**：operation 与参数名保持兼容；`overrides` 仍可用（新写法 `params` 等价）
- `evaluate` 的 `precision` 不再改变引擎精度（固定 64 位），需要更多显示位请用 `displayPrecision`
- 老 `index.ts` 的自动建表与 UI 路由已移除；如果你依赖面板接口，请留在 2.x
