# UI 反馈修复

> 用户反馈四项：标题重复、自动切换未生效、非中文处需标注、入口样式与依赖图。

## 一、标题重复「数学工作区 数学工作区」

### 根因

宿主会把 `label` 回调的返回值**当作标题文字**渲染，
而我的组件 `SidebarTitle` 里**又写了一遍**同样四个字，于是渲染两遍。

对比社区插件 `dsh-context` 的做法：

```js
slots.register({
  name: 'sidebar.panellist',
  id: oc, order: 20,
  label: () => r('ov.title'),   // ← 文字在这里
}, (props) => createElement(T, { size: props.size }))  // ← 组件只返回图标
```

### 修法

组件只返回图标，文字交给 `label`：

| 位置 | 原 | 现 |
|---|---|---|
| 左侧入口 | `∑` + 「数学工作区」 | 只有 `∑` |
| 右侧页签 | `⚙` + 「本区」 | 只有 `⚙` |

## 二、自动切换没生效

### 根因（关键）

只订阅了「工作区列表变化」：

```ts
list.subscribe(bindHost)   // 只在新建/改名/删除时触发
```

**但用户切换工作区时，列表本身没有变化**——变的只是「当前指向」。
所以 `bindHost` 永远不触发，自动切换看起来「没做到」。

查了已装的全部社区插件，**没有找到「当前工作区变化」的订阅点**，
宿主的 `uiWorkspace` 只暴露了 `workspaces.list` 和 `sessions`。

### 修法：轮询兜底

```ts
let lastActiveId = ''
const pollActive = function () {
  // 用「当前会话」反推所在工作区，拿不到就退回第一个
  const active = items.find(item =>
    item.sessionIds.includes(currentSessionId)) || items[0]

  if (active.workspaceId === lastActiveId) return   // 没变，什么都不做
  lastActiveId = active.workspaceId

  // 变了：绑到对应数据表 + 通知两侧刷新
  fetch('/workspaces/bind', ...).then(notifyWorkspaceChanged)
}
setInterval(pollActive, 2000)   // 2 秒一次
```

**为什么用轮询**：切换工作区是低频操作，2 秒足够快；
只比对 id 字符串，开销可忽略；且**只在不一致时才发请求**。

## 四、依赖图改版

用户要求：「希望可以像图片一样点开伸缩，希望加上标注，连线希望更明显一些」。

### 原来为什么难用

40 个节点一次性铺开，画布 **1970px 宽**，在侧栏里要横向滚动。

### 改成按层折叠

```
▾ 第一层（恒星）（3 项）            点击收起
    恒星寿命  辐射谱峰值波长  恒星光源

▸ 第四层（行星）（12 项）           点击展开

▸ 基础常数（20 项）                 点击展开
```

- **默认只展开最上一层**，其余收起——一屏就能看完结构
- **点击层标题**折叠/展开
- 每层显示项数
- 节点框**边框越粗 = 被越多东西依赖**

同时提供了 `arrowHead()` 生成箭头三角，让方向更明显。
