# 家庭结构设计（2026-11-27）

> 目标：回答「这个村一年生几个孩子、一户几口人、一代人差多少岁」。
> 上游：[完整世界观缺口分析](完整世界观缺口分析.md) 2.3「人口结构（有数字，没有纹理）」。
> 复核结论：抚养比、预期寿命、存活率、更替生育率已有；**户规模与生育间隔是 0 条**。

## 一、缺口定位

| 问题 | 现状 |
|---|---|

## 二、开源记录（硬门槛 ①②）

| 渠道 | 结果 | 评估 |
|---|---|---|
| npm / GitHub | 无人口学公式库（这类多在 R 的 `demography` / 联合国的 Excel 工具里） | 不引；公式本身是标准定义 |
| PMC | Bongaarts「proximate determinants of fertility」框架（文献 13616691 等）确认：**生育间隔 = 产后不孕 + 等待受孕 + 妊娠** | 作为 `birth_interval` 的分解依据 |
| 医学常数 | 妊娠约 9 月；哺乳期产后闭经 6~24 月；育龄女性每月受孕概率（fecundability）约 0.2（25 岁） | 标准值，用于默认参数 |

## 三、三条公式

### 3.1 `birth_interval`（两次生育隔多久）

```
T = 妊娠期 + 产后闭经 + 1 / 每月受孕概率
```

- 默认：妊娠 9 月、产后闭经 12 月（有哺乳）、fecundability 0.2 → **26 月 ≈ 2.2 年**；
- 与人类学实测一致（自然生育人群间隔 2~3.5 年）；
- 纯机制式：**延长哺乳 → 闭经变长 → 间隔变长**（这就是自然生育率调节的主要机制，
  Bongaarts 框架里 Ci 那一项）。

### 3.2 `generation_length`（一代人差多少岁）

```
L = 初婚年龄 + (生育间隔/12) × (子女数 − 1) / 2
```

- 含义：母亲在「第一个孩子」与「最后一个孩子」之间的中点年龄；
- 传统社会：初婚 20、间隔 2.2 年、8 个孩子 → **约 27.7 岁**（与历史人口学的世代长度吻合）；
- 现代：初婚 28、间隔 3 年、2 个孩子 → 29.5 岁（晚婚少生 → 世代拉长）。

### 3.3 `household_size`（一户几口人）

```
户规模 = 成年人数 + 存活子女数 + 需赡养老人数
```

- 前工业社会典型 5~8 人（夫妇 + 4~5 个存活子女 + 老人）；
- 这是**账**不是预测：三个数都应由你的设定给出（`survival_to_age` 可帮算老人数）。

## 四、验证方式

1. **机制方向**：哺乳期闭经延长 → 生育间隔变长（反比/正比关系正确）；
2. **量级锚点**：默认参数下生育间隔落在 2~3.5 年、世代长度落在 25~32 岁；
3. **边界**：fecundability = 0（不孕）时不能静默返回 Infinity；
4. **算术自洽**：户规模 ≥ 成年人数；子女数为 1 时世代长度 = 初婚年龄。

测试：`test-v3/r106-household.mjs`。

## 五、明确不做

- **分年龄死亡率生命表**：需要完整 lifetable 数据，本项目拿不到一手来源，硬编就是猜；
- **婚姻市场（性别比 → 未婚率）**：需要婚姻挤压模型与数据，量级不稳；
- **迁移（推拉模型）**：叙事频率低，另议。
