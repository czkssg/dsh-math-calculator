# 政权的税收与财政支出 —— 理论、公式与可推导结构

> 承接《宏观经济理论检索报告》的财政部分，本文专门做**政权财政**这一块。
> 面向「小说世界观中的国家/文明」：钱从哪来、花到哪去、什么时候会崩。
> 只列清单与判据，不含代码；来源全部可核验。

---

## 一、现状盘点：只有 3 条，且缺一整层

库内现有财政相关只有 3 条，但**质量意外地好**：

| id | 公式 | 评价 |
|---|---|---|
| `fiscal_revenue` | 人口 × 人均产出 × 税率 | ✓ 可用。desc 里那句「前工业国家实际征税率通常只有 5%—10%（名义税率可以高得多，但收不上来）」**很专业**，这是财政史的核心事实 |
| `army_pay_cost` | 兵数 × 人均年饷 | ✓ 可用。desc「兵员成本约为普通劳动力产出的 1.5—3 倍」也对 |
| `fiscal_burden_ratio` | 军费 / 财政收入 | ✓ 可用。desc「长期 0.5 以上往往几十年内崩一次」是有史实支撑的判断 |

**缺的是中间那一整层**：

```
  现有：收入（一个乘法）→ 军费（一个乘法）→ 比值
  缺：  支出结构 / 赤字 / 基本余额 / 税种组合 / 铸币税 / 征收成本
```

现有三条只能回答「够不够养兵」，**回答不了「这个政权的财政结构是否可持续」**。
而后者才是文明叙事里真正会出问题的地方。

## 二、A 组：财政恒等式（最硬，任何政权都逃不掉）

### A1. 财政收支恒等式与赤字

```
  财政赤字  D = G − T
  总支出 G = 经常性支出 + 资本性支出 + 利息支出
  总收入 T = 税收 + 非税收入（专卖、官产、罚没）
```

- 来源：**ECB Data Portal《What is the general government balance?》**（明写「balance 是收入与支出之差」）；
  **印度财政部《Budget at a Glance 2025-26》**（明写「Fiscal Deficit = 总支出 − 总收入（不含债务性收入）」）；
  IMF eLibrary《Fiscal Accounting and Analysis》
- **性质**：**会计恒等式**，不是理论
- **跨世界照用**：✓ **绝对成立**（定义级，任何政权都逃不掉）
- **关键细节（很多人会错）**：赤字**不含借债**。借来的钱是「赤字融资」而不是「收入」。
  这个区分很重要 —— 把借债算成收入，就是财政崩溃前的典型自欺

### A2. 基本余额（primary balance）—— 剔除利息后的真实经营状况

```
  基本余额  PB = T − (G − 利息)      =  财政余额 + 利息
  即：       PB = D + 利息支出
```

- 来源：**印度 IES《Deficit Measurement》**（明写「Primary Deficit = Fiscal Deficit − 净利息支付」）；
  IMF《Fiscal Accounting》：「按定义剔除利息，才能准确衡量当期的**可自由裁量**财政政策」
- **性质**：**定义级恒等式**
- **为什么这条最有诊断价值**：它把「经营亏损」与「历史债务的利息」分开。

```
  基本余额为正、但总赤字为负  → 经营是赚的，只是被旧债利息拖垮（可救）
  基本余额为负                → 经营本身在亏，越借越亏（结构性危机）
```

**这是判断「这个帝国还有没有救」的第一条判据**，而现有库完全没有。

### A3. 财政可持续性条件（把债务动态接到财政上）

```
  稳定条件：  PB ≥ (i − g)·d
  i 名义利率 ｜ g 名义增长率 ｜ d 债务/GDP

  含义：基本盈余必须大到足以抵消「利息率超过增长率」造成的债务自我膨胀
```

- 来源：**IMF TNM/2010/02**（债务动态主方程）；**ECB Economic Bulletin 2019**（「i 与 g 之差是关键变量」）；
  法国 Tresor-Economics No.334（明写 `(g−r)d/(1+g)` 形式）
- **性质**：**由差分方程推导**，不是经验
- **跨世界照用**：✓ 完全通用
- **这条是财政学的核心判据**：

```
  i > g（高利贷型社会）→ 债务自我膨胀，必须持续基本盈余才能稳住
  i < g（高增长社会）  → 通胀与增长会自然稀释债务，允许持续基本赤字
```

  这解释了为什么**古代帝国（高利率、低增长）财政特别脆**，
  而**工业革命后的高增长期能承受高债务**

## 三、B 组：税收结构（政权能力的具体体现）

### B1. 宏观税负与有效税率

```
  有效税率 ETR = 实际税收 / GDP
  注意：ETR ≠ 名义税率 —— 前者含漏征、免征、逃税
```

- 来源：**IMF《Revenue Fundamentals, Fiscal Forecasting, and the ETR》**（明写 ETR 用于收入预测）；
  IMF《Elements of Revenue Forecasting》
- **性质**：**定义比值**（硬）；但「ETR 是多少」是经验事实
- **跨世界照用**：✓ 比值通用，具体数值靠设定
- **与现有 `fiscal_revenue` 的关系**：那条用的是「税率」，本质是**名义税率**。
  补这条 ETR 是把「名义」与「实际」分开 —— 而现有 desc 已经警告了这一点
  （「名义税率可以高得多，但收不上来」），**但没有任何公式能算这个差距**

### B2. 税收弹性 / 税基弹性（判断「税收跟不跟得上经济增长」）

```
  税收弹性 ε = (ΔT/T) / (ΔB/B)       （剔除政策变动）
  税收浮力 β = (ΔT/T) / (ΔGDP/GDP)   （含政策变动）

  含义：ε > 1 = 税收增长快于经济（累进性）；ε < 1 = 跟不上
```

- 来源：**IMF《Elements of Revenue Forecasting II: The Elasticity Approach》**
  （明写 `Elasticity = (ΔAT/AT)/(ΔTB/TB)`）；**IMF《How to Forecast Corporate Income Tax Revenues》**
  （明确定义 elasticity 与 buoyancy 的区别）；Queen's 大学《Tax Analysis and Revenue Forecasting》
- **性质**：**定义比值**（硬）；ε 的数值是经验
- **跨世界照用**：✓ 完全通用
- **价值**：回答「**为什么这个国家的税收总是不够**」。
  ε < 1 意味着经济在长但税收跟不上 —— 而这往往是**税基萎缩**（如农业税基 vs 工业增长）
  或**征管能力不足**。这是「政权能力跟不上经济变化」的定量表述
- 现有库：**没有**

### B3. 税种组合（谁承担税负）

```
  【直接税】所得税、土地税、人头税 —— 直接落在个人/资产上
  【间接税】消费税、关税、专卖 —— 含在价格里，转嫁
  【结构比】直接税 / 总税收
```

- 来源：Atkinson & Stiglitz《The design of tax structure》（直接税与间接税的最优组合）；
  LSE Stern 讲义；IMF 收入讲义
- **性质**：**结构性分类**，不是公式
- **跨世界照用**：✓ 分类通用
- **为什么对设定有用**：税种结构决定**谁在承担政权成本**：

```
  直接税为主 → 政权强、官僚体系健全（能查清个人财产）
  间接税为主 → 政权弱、只能卡在流通环节（如关卡税、盐铁专卖）
  人头税为主 → 最原始，只要能数人头
```

**这是判断「这个政权处在哪个发展阶段」的最快指标。** 建议做成 help 的对照表，不写成单条公式

### B4. 铸币税（通胀税）—— 最隐蔽的一种财源

```
  实际铸币税 = Δ(基础货币) / 物价水平
  或近似：  铸币税 ≈ 通胀率 × 实际货币余额
```

- 来源：**Berkeley Obstfeld《Notes on Seigniorage and Budget Constraints》**
  （把货币创造整合进国家预算账户）；Mankiw 教材体系；Toronto Floyd《Inflation: A Tax on Money Holdings》
- **性质**：**恒等式**（铸币税定义 = 货币增量/价格）
- **跨世界照用**：✓ 完全通用 —— 只要有权铸币
- **为什么特别有价值**：

```
  它把「滥发货币」与「财政赤字」连起来了：
  赤字无法靠税收弥补时 → 铸币就成了最后一根财源
  而铸币税本质是「对持有货币者的隐性征税」→ 通胀
```

  这解释了**历史上几乎所有恶性通胀都发生在财政危机之后**。
  写「帝国崩溃」时，这是最标准的经济学机制
- **与货币层的接口**：`fisher_money`（MV=PY）+ 本式 → 完整的「赤字→印钱→通胀」链
- 现有库：**没有**

## 四、C 组：支出结构（钱花到哪去）

### C1. 支出分类与刚性

```
  经常性支出 = 官僚薪酬 + 军饷 + 宫廷 + 宗教/祭祀
  资本性支出 = 基建 + 军工 + 水利
  利息支出   = 存量债务 × 利率

  刚性支出 = 官僚 + 军饷 + 利息   ← 砍不掉的那部分
  可裁量支出 = 资本性支出          ← 能砍的那部分
```

- 来源：印度预算手册的支出分类（revenue vs capital expenditure）；IMF 财政会计；NCERT 教材
- **性质**：**分类**（非公式）
- **跨世界照用**：✓
- **为什么这条最关键**：政治史的核心就是**刚性支出的比例**：

```
  刚性占比 80%+ → 政权几乎没有政策自由度，任何冲击都直接触发危机
  刚性占比 50%  → 有余力搞建设与改革
```

**「改革为什么推不动」的定量答案就是「刚性支出占比太高」。**
这条建议做成一条「财政自由度」公式（见推荐清单 C1）

### C2. 官僚成本与征管效率

```
  征收成本率 = 征税成本 / 征得税款
  官民比 = 官僚人数 / 总人口
```

- 来源：**OECD《Tax Administration in OECD and Selected Non-OECD Countries》**
  （跨国征管成本比较）；UK Parliament Hansard（征管人员数历史数据）；
  Productivity Institute WP043（税收征收的生产率）
- **性质**：**比值**（硬）；具体数值是经验
- **跨世界照用**：✓
- **价值**：解释「为什么有些政权加税反而收得更少」——
  因为官僚层本身吃掉了增量。**官民比是政权效率的最直接代理指标**
- 现有库：**没有**（`cost_of_corruption` 只算腐败，不算征管成本）

## 五、D 组：只写推演配方、不做公式（3 项）

| 项 | 为什么不公式化 | 该怎么用 |
|---|---|---|
| **拉弗曲线** | 无可靠最优税率系数（拉弗当年画在餐巾纸上）；美国财政部 OTA Paper 41 的研究显示「边际税率过高会进入禁区」但**没有给出普适阈值** | 只在 desc 写定性提示：**累进税率越高，进入「税收反而下降」的禁区所需平均税率越低** |
| **税种最优组合**（Atkinson-Stiglitz） | 是理论框架（谁承担多少），不是单一等式 | 做成 help 对照表：直接税/间接税/人头税 ↔ 政权能力阶段 |
| **盐铁专卖/关税的具体费率** | 是历史经验值，跨世界无意义 | 作为**设定参数**（`monopoly_rate`、`tariff_rate`）交给用户填 |

## 六、推荐清单

### 第一梯队（4 条：恒等式或严格推导）

| id | 公式 | 类型 | 来源 |
|---|---|---|---|
| `fiscal_balance` | 赤字 D = G − T（**不含借债**） | **恒等式** | **ECB 数据门户** + **印度预算手册** + IMF |
| `primary_balance` | PB = T − (G − 利息) | **恒等式** | **印度 IES** + **IMF 财政会计** |
| `fiscal_sustainability` | PB ≥ (i − g)·d | **推导** | **IMF TNM/2010/02** + **ECB 2019** |
| `seigniorage` | Δ基础货币/物价 ≈ 通胀×实际货币余额 | **恒等式** | **Berkeley Obstfeld** + Mankiw + Toronto Floyd |

### 第二梯队（3 条：结构比值，需设定数值）

| `effective_tax_rate` | ETR = 实际税收/GDP（≠名义税率） | **IMF Revenue Fundamentals** |
| `tax_elasticity` | ε = (ΔT/T)/(ΔB/B) | **IMF Elasticity Approach** 三篇 |
| `fiscal_autonomy` | 可裁量支出 / 总支出 = 1 − 刚性占比 | 由 A1/C1 的分解推出 |

### 第三梯队（2 条：成本比值）

| `collection_cost_ratio` | 征管成本/税收 | **OECD 征管比较** + Hansard + Productivity Inst. |
| `bureaucrat_ratio` | 官僚数/总人口 | 同上 |

### 不做公式（3 项，写进 help）

拉弗曲线（定性提示）、税种最优组合（对照表）、专卖/关税费率（设定参数）

## 七、这批公式怎么拼出一条「政权财政崩溃」推演链

这是财政层的核心价值：**把「帝国为什么衰亡」拆成可逐步核查的因果链**。

```
① effective_tax_rate    设定名义税率 30%，实际只有 10%
   → 结论：征管能力弱，那 20% 的差距是漏征+逃亡

② fiscal_balance        收入 10% GDP，支出 15% GDP → 赤字 5% GDP

③ primary_balance       PB = −5% + 利息 3% = −2% GDP
   → 结论：不是被旧债利息拖垮，而是**经营本身在亏**（结构性危机）

④ fiscal_sustainability  i=8%、g=2%、d=80% GDP
   需要 PB ≥ 6%×80% = 4.8% GDP，而实际是 −2% GDP
   → 缺口 6.8% GDP/年 → 债务每年涨约 7 个点，十年翻倍

⑤ seigniorage          税收已加不动、借债又 i>g → 只能铸币
   铸币 5% GDP → 按费雪方程，通胀随之上升
   → 通胀反过来推高 i（债主要求更高利息）→ 回到 ④，形成**死亡螺旋**

⑥ collection_cost_ratio 官僚吃掉 30% 的税 → 加税的净收益更少
   fiscal_autonomy     刚性支出 85% → 没有政策空间做改革
   → 结论：**改革也推不动**，因为没有可裁量的钱
```

**这条链每一步都有实数支撑，且能推出「为什么这个政权看起来还能撑、其实已经在螺旋里」。**

这比「这个帝国很腐败所以要亡」可信得多 —— 因为腐败只是其中一环，
真正致命的是**基本余额为负 + i>g + 无政策自由度**这三者叠加。

## 八、三条设计建议

### 1. 财政公式必须区分「名义」与「实际」

现有 `fiscal_revenue` 用的 `tax_rate` 是**名义税率**，但 desc 已经写了
「前工业国家实际征税率只有 5%—10%」。**这是库内少见的「知道问题但没给解」的地方**。

补 `effective_tax_rate` 就是把这个差距**做成可算的量**，
而不是留在注释里靠人记。而「名义 vs 实际」的差距本身就是一个世界观参数 ——
**它衡量政权对社会的渗透能力**。

### 2. 「刚性支出占比」应当独立成一个量

它决定了政权的**政策自由度**，而这是政治叙事里最核心的约束。
`fiscal_autonomy = 1 − 刚性占比` 只有一行，但能回答「为什么改革推不动」。

### 3. 铸币税必须和货币层打通

它是**财政与货币的唯一接口**。没有它，「赤字→印钱→通胀」这条最经典的
崩溃机制就断在中间 —— 而那正是历史上大多数政权崩溃的真实路径。

两份报告合起来覆盖了宏观层的完整链条：

| 层 | 已有/待补 | 关键公式 |
|---|---|---|

所以建议这两批**一起实现**，因为 `fiscal_sustainability` 直接依赖 `debt_dynamics` 的 `d`。
