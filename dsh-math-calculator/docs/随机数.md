# 随机数与行为映射

> 2026-11-19 · v3.20.0。长周期、可复现的随机数，以及「给实体分配行为倾向」的用法。

## 一、选型（为什么是 xoshiro256++）

| 方案 | 周期 | 状态 | 评价 |
|---|---|---|---|
| 原 LCG（core/prng.ts） | 2^32 | 4 B | 太短，低位质量差；保留做兼容 |
| seedrandom（alea） | 约 2^72 | 小 | 成熟，但周期短于 2^128 |
| mersenne-twister | 2^19937−1 | 2.5 KB | 周期极长，但 JS 实现偏慢、状态大 |
| **xoshiro256++** | **2^256−1** | **32 B** | 快、通过 BigCrush；算法公有领域（Vigna 2018） |

结论：新 `random` 操作用 **xoshiro256++**；LCG 只作为 `algorithm:"lcg"` 的兼容模式。
播种：`SHA-256(seed 文本)` → 4×64 位状态；空种子固定为 `dsh-default-seed`。

## 二、序列

```jsonc
{ "operation": "random", "randomSeed": "world-a",
  "count": 10, "min": 0, "max": 100, "integer": true }
```

同 seed 同结果；换 `randomSeed` 即换世界。周期 2^256−1，推演中不会循环。

## 三、行为映射（推演用）

```jsonc
{ "operation": "random", "randomSeed": "world-a",
  "randomActors": ["甲", "乙"],
  "randomTraits": {
    "勇气": { "min": 0, "max": 1 },
    "出身": { "choices": ["商人", "农民", "工匠"] }
  } }
```

每个实体得到一组特征值。**每个实体的子流由 `seed|实体名` 派生**：

- 与实体排序无关（同一人无论排第几都得同一值）；
- 同一世界种子下稳定（跨调用可复现）；
- 加实体不会改变已有实体的值。

这正是「行为映射」需要的性质：人物/城市/事件的倾向值可以稳定地当作设定用。

## 四、边界

- **不是密码学安全**：不用于密钥、抽奖等安全场景；用于虚构世界的确定性抽样。
- 行为映射只给「倾向值」，具体行为仍由叙事逻辑决定（工具不替作者做因果）。
- `conflict` / `diverge` 等旧推演仍用 LCG（`seed` 数字），保持历史结果兼容。

## 五、落点

- 操作：`operation:"random"`（help 第 64 节）；
