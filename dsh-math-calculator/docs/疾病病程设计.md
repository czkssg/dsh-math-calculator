# 疾病病程设计（2026-11-27）

> 目标：回答「这场病第几天死人、死多少、实际多少人感染」。
> 上游：[完整世界观缺口分析](完整世界观缺口分析.md) 2.2「疾病与医学（只有毒理，没有病程）」。
> 复核结论：传染动力（R0/倍增/峰值/最终规模/隔离/群体免疫）已有；**个体病程与病死率换算是 0 条**。

## 一、缺口定位

| 问题 | 现状 |
|---|---|
| 第几天开始死人 | ❌ 0 条（`epidemic_generation_interval` 是传播代际，不是个体病程） |
| 死一个，实际多少人感染 | ❌ 0 条（没有 CFR 反推） |
| 病死率 / 感染者里死多少 | ❌ 0 条 |

**传播动力学**（多少人会被感染、多快）已有；缺的是**个体时间轴**与**死亡换算**。
这两件事在叙事上完全不同：一个是「城里开始烧尸」的宏观曲线，一个是「第三天上吐下泻、第七天死」的个体。

## 二、开源记录（硬门槛 ①②）

| 渠道 | 结果 | 评估 |
|---|---|---|
| 本库 | 传染动力 9 条已齐 | 不重复实现 |
| npm / GitHub | 无疾病病程库（这类参数在各家流行病学数据库里） | 不引 |
| 领域数据 | 潜伏期 / 病程 / 病死率**按病种差异极大**（流感潜伏 2 天、CFR 0.1%；天花潜伏 7~17 天、CFR 30%；肺鼠疫 CFR 60~90%） | **不内置单一值**，全部做成参数，desc 给查表锚点 |

**关键判断**：这三条都是**纯算术/时间轴**，可自证；「某病具体几天死」是参数，不是公式。

## 三、三条公式

### 3.1 `infection_to_outcome`（感染后第几天出结果）

```
T = 潜伏期 + 病程
```

- 潜伏期：暴露 → 出现症状（流感 2、麻疹 10~12、天花 7~17）；
- 病程：症状 → 康复或死亡（流感 7、天花 14~21、肺鼠疫 3~5）。
- 例：天花 12 + 18 = **30 天**（「染上后一个月才见分晓」——这就是隔离期要长的原因）。

### 3.2 `deaths_from_cases`（这些病例里会死多少）

```
死亡 = 病例数 × 病死率
```

- CFR 按病种：流感 0.001、麻疹 0.002、天花 0.3、肺鼠疫 0.6~0.9；
- 例：1000 例天花 × 0.3 = **300 死**。

### 3.3 `cases_from_deaths`（死了一个人，实际感染多少）

```
病例数 = 死亡数 / 病死率
```

- 这是**最容易被忽略的反推**：病死率低的病，一例死亡背后是巨大的感染数；
- 例：报告 1 例死亡、CFR 0.1%（流感级）→ 实际约 **1000 人感染**（这就是「冰山」）。

## 四、验证方式

1. **正反可逆**：`deaths_from_cases(cases_from_deaths(d))` 应回到 d（容差 1e-9）；
2. **量级锚点**：天花参数下感染到结局 ~30 天、CFR 30% 时 1000 例死 300；
3. **边界**：CFR = 0 时 `cases_from_deaths` 不能静默返回 Infinity；
4. **与 SIR 串联**：`sir_equilibrium` 最终感染比例 × 人口 = 病例 → × CFR = 死亡。

测试：`test-v3/r107-disease-course.mjs`。

## 五、明确不做

- **SEIR 的个体异质性**（老少病亡率不同）——需要分龄病死率数据，本项目无一手来源；
- **具体病的完整临床分期**（前驱期/极期/恢复期）——过细，且各病差异太大；
- **后遗症/免疫时长**——数据不足，写出来就是猜。
