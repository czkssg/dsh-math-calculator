# 材料本构层公式检索报告

> 针对「工程方面有没有通用的、基于材料性质的公式」的联网核实。
> 只列清单与判据，不含代码。来源全部可核验。

---

## 一、先说结论：现有 13 条材料公式全在「构件」层，本构层几乎空白

扫过库内 `materials/structures` 全部 13 条，它们的输入都是**构件几何与载荷**：

```
  buckling_euler            需要 E, I, K, L        ← 构件
  beam_center_deflection    需要 载荷、跨度、EI     ← 构件
  column_axial_capacity     需要 截面、强度        ← 构件
  hardness_to_yield         需要 H                 ← 材料，但只有这一条
  corrosion_rate_weightloss 需要 W, A, ρ, t        ← 材料，经验式
```

**缺的是中间那一层：材料本身的「应力 → 应变 → 失效」关系。**

最直接的证据：库里有 `strain`（`ε = ΔL/L₀`，纯几何定义），
**却没有配对的胡克定律 `σ = E·ε`** —— 有应变没应力，这条链是断的。

这对「材料属性靠硬设定」的用法尤其不利：你设定了 `E = 2e11 Pa`、`σy = 235 MPa`，
但没有任何公式能把这些数变成「这个构件会不会坏」。

## 二、A 组：本构与失效（最该补的，5 条）

### A1. 胡克定律 —— 补上断掉的那一环

```
  σ = E · ε            应力 = 弹性模量 × 应变
  ε = σ / E            已知应力求变形
```

- 来源：**DoITPoMS（剑桥大学材料系教学站）《Elastic deformation: Hooke's law and stiffness》**；
  Linköping《Applied Mechanics》§8.6 明写 `σ = Eε` 是「最简单的本构关系」；OpenStax College Physics §5.3
- **通用性**：材料力学公理，与材料种类无关 —— 只需给出该材料的 E
- **跨世界照用**：✓ 完全通用。E 由用户硬设定，公式本身不含地球假设
- **与库内关系**：`strain` 已有但孤立；补这条就形成 `ΔL → ε → σ → 判安全` 的完整链
- **配套建议**：同时给一条 `yield_check`（`σ/σy = 安全余量`）—— 见 A5

### A2. 断裂韧性 —— 「有裂纹时还能不能撑住」

```
  K_I = Y · σ · √(π·a)        应力强度因子
  失稳判据：K_I ≥ K_IC         即 σ_c = K_IC / (Y·√(π·a))
```

- 来源：**MIT 3.11《Introduction to Fracture Mechanics》**；
  Wiley《Fundamentals of Fracture Mechanics》（明写 K_I 的定义与裂纹几何因子）；
  fracturemechanics.org《Griffith's Energy Release Rate》
- **通用性**：线弹性断裂力学（LEFM）的核心，与材料无关（K_IC 是材料常数）
- **跨世界照用**：⚠ 有条件 —— LEFM 假设**脆性/小范围屈服**；
  若是高韧性延性材料（大范围屈服），该用弹塑性 J 积分，LEFM 会低估承载。desc 必须写明
- **为什么这条特别有用**：它解释了**为什么大构件必须比小试样更小心** ——
  同样的 K_IC，裂纹越长，能承受的应力越低（σ_c ∝ 1/√a）。
  一条 1 mm 的裂纹 vs 1 cm 的裂纹，承载差 √10 ≈ 3.2 倍。
- 与库内关系：`wall_breach_energy` 用「toughness × 面积 × 厚度」，
  那是**能量口径**的粗估；K_IC 是**应力口径**的严格判据，两者互补不重复

### A3. 蠕变（Norton 幂律）—— 长期载荷下的缓慢变形

```
  ε̇_cr = A · σ^n · exp(−Q/(R·T))
  A 蠕变系数 ｜ n 应力指数 ｜ Q 激活能 ｜ R 气体常数 ｜ T 绝对温度
```

- 来源：**DoITPoMS《Constitutive Laws for Creep》**（给出含温度项的完整式）；
  COMSOL 材料库文档；Norton 模型的两种常见参数化
- **通用性**：幂律蠕变的通用形式，跨金属/陶瓷/聚合物都成立（n 值不同）
- **跨世界照用**：✓ 形式通用；⚠ Q 与 A 需按材料标定，且**温度是关键变量**
- **价值**：回答「这个承压塔在高温下能撑多少年」。
  对蒸汽朋克/工业设定极实用 —— 锅炉、管道、蒸汽机的真实瓶颈往往不是强度而是**蠕变**
- 简化版：`ε̇_cr = A·σ^n`（等温，只给 A 与 n），这是最常用的工程形态

### A4. 弹性应变能密度 —— 「材料能存多少能量」

```
  u = σ²/(2E) = ½·σ·ε       弹性应变能密度 J/m³
  总能量 U = u · V          乘以体积
```

- 来源：Univ. of Washington《Strain Energy I》；Auckland《Solid Mechanics Part I》§8 Energy；
  Lu & Yu《Energy absorption of structures and materials》
- **通用性**：力学基本结论
- **跨世界照用**：✓
- **价值**：两条经典用途
  · **弹簧/弓弩储能**：`U = σ²V/(2E)` —— 决定了「这把弓能存多少焦耳」，即射程上限
  · **抗冲击**：材料在不发生永久变形前能吸收的弹性能，是「摔不坏」的定量判据
- 注意区分：弹性应变能（可恢复）vs 塑性功（不可恢复的吸收），
  后者是真正「吸能」的机制，需 `∫σdε` 到断裂应变，属于塑性力学范畴

### A5. 安全系数 / 许用应力 —— 把材料强度变成设计判据

```
  σ_allow = σ_y / n          许用应力
  n = 安全系数              （静载 1.5~2，冲击 2~4，疲劳 3~6，脆性材料更高）
  校核：σ_work ≤ σ_allow  →  安全
```

- 来源：传统工程设计惯例；Linköping 教材、OpenStax 都按此讲
- **通用性**：✓ 纯比值判断，不含材料假设
- **跨世界照用**：✓（系数可调）
- **诚实标注**：安全系数是**工程惯例而非物理结论**，
  取值依赖失效后果与不确定性。desc 要写「这是惯例取值，不是定律」

## 三、B 组：材料组合与选择（2 条，写「造物」时极有用）

### B1. Voigt / Reuss 混合律 —— 复合材料的模量上下界

```
  Voigt（等应变，上界）: E_c = V_f·E_f + (1−V_f)·E_m
  Reuss（等应力，下界）: E_c = 1 / (V_f/E_f + (1−V_f)/E_m)
```

- 来源：**Wikipedia《Rule of mixtures》**；**Princeton MAE324 §6**（两个式子逐个给出）；
  Granta EduPack《Composites (Simple Bounds）》
- **通用性**：✓ 纯体积加权，与材料种类无关
- **跨世界照用**：✓ 完全通用
- **价值**：这是**「发明新材料」的正确入口**。作者设定「用 30% 纤维 + 70% 基体」，
  这两个式子立刻给出模量的**可信区间**，而不是让他凭感觉编一个数
- 重要提醒：上下界之间可能有 2~3 倍差距（取决于纤维排布），
  desc 必须说明「真值落在两界之间，需看排列方式」—— 不能只给一个数

### B2. Ashby 性能指数 —— 「选哪种材料」的判据

```
  轻而刚的梁    M = E^(1/2) / ρ
  轻而强的梁    M = σ_y^(2/3) / ρ
  轻而刚的板    M = E^(1/3) / ρ
  轻而强的板    M = σ_y^(1/2) / ρ
  弹性储能      M = σ_y² / E          （弹簧材料）
```

- 来源：**MIT 3.054 / 3.36《Foam Design》Lecture 8** —— 明写「为最小化给定刚度梁的质量，
  性能指数是 **E^(1/2)/ρ**」；ASM Handbook vol.20《Performance Indices》；
  Granta EduPack 白皮书；IIT Kharagpur 材料课讲义
- **通用性**：✓ 由「刚度要求 + 最小质量」推出，是通用的设计目标函数
- **跨世界照用**：✓ 完全通用（指数与几何形式绑定，与材料无关）
- **为什么这条对架空设定特别有价值**：它把「选材」从**审美判断**变成**可计算判断**。
  比如设定「这种生物合金很轻很强」，用 M = σ^(2/3)/ρ 一算就知道它到底排第几
- 建议形态：**一条公式 + 一个 mode 参数**（beam_stiff / beam_strength / panel_stiff / …），
  而不是拆成五条 —— 因为它们的骨架完全相同

## 四、C 组：有条件、或已有替代（不建议新增）

| 泊松比 ε 横向/ε 纵向 | **不做公式，只做参数说明**。它是**定义**不是计算式（`ν = −ε_trans/ε_axial`），且三向应力状态要用广义胡克定律（6×6），超出单值求值范围 |

## 六、这套公式怎么服务「材料属性靠硬设定」

你的用法是对的，而且这批公式正是为它设计的。**分工应该这样划**：

```
  作者硬设定：E, σy, K_IC, ρ, n, A, Q      ← 材料「身份证」
  公式算出：   ε, σ, K_I, M, ε̇, u        ← 由身份证推导的后果
```

举个完整例子：

```
① 设定「这世界的钢：E = 2e11 Pa、σy = 235 MPa、K_IC = 30 MPa·√m、ρ = 7850」
② hooke_law            σ = 200 MPa 时的应变 ε = 1e-3
③ safety_factor_check  200/235 = 1.18 → 安全系数 1.18，低于 1.5，不安全
④ fracture_kic         若有一条 5 mm 裂纹：σ_c = 30/(1·√(π·0.005)) = 239 MPa
   → 结论：裂纹 5 mm 时，承载能力几乎等于屈服强度，两者临界
⑤ ashby_index          与「生物合金 ρ=3000、σy=400 MPa」比 M = σ^(2/3)/ρ
   → 生物合金 0.27 vs 钢 0.20，确实更强
```

**这条链的关键是：每一步的输入都是你硬设定的，公式只负责推导后果。**
这正是我们要的 —— 工具不判断你的材料合不合理，只保证「基于你给的性质，后果是算对的」。

## 七、一条重要的设计建议

**这批公式应支持「材料卡片」而不是散装参数。**

现在每条公式都要手填 E、σy、K_IC、ρ 四个数，同一材料反复手打 —— 而
`workspaceVariables` 已经能存（上一轮 DIY 方案已验证：`{O2_ENERGY:21100}` 可复用）。

所以理想形态是：

```
workspace set vars { STEEL_E: 2e11, STEEL_SY: 235e6, STEEL_KIC: 30e6, STEEL_RHO: 7850 }
formula hooke_law { E: "STEEL_E", eps: 1e-3 }
                                ↑ 若 overrides 能解析工作区变量，材料卡片就成立了
```

**这正好是上一轮 DIY 方案里 P2 项（「工作区变量可用于 overrides」）**。
两条需求在这里汇合了：它既服务于生物巨兽参数复用，也服务于材料卡片。
这也让 P2 的优先级从「性价比高」升到「**这批公式能否好用**的前提」。
