# 运行日志

> 目的（用户 2026-11-15）：**不依赖使用者自行反馈**——每次调用的结果与报错自动落盘。

## 一、位置

```
<DSH_MATH_CALC_HOME>/logs/run.log.jsonl
```

`DSH_MATH_CALC_HOME` 未设置时是 `<当前目录>/.dsh-math-calculator`。

## 二、格式（每行一条 JSON）

```json
{"at":"2026-11-14T18:16:48.502Z","operation":"formula","ok":false,"errorType":"missing_params","errorMessage":"formula 需要 formula（公式 id 或名称）","ms":0,"input":"{\"operation\":\"formula\"}"}
```

| 字段 | 含义 |
|---|---|
| `at` | ISO 时间 |
| `operation` | 实际执行的 operation（auto 会报解析后的值） |
| `ok` | 成功/失败 |
| `errorType` / `errorMessage` | 失败时才有，与工具返回的 `error` 一致 |
| `ms` | 耗时（毫秒） |
| `input` | 输入前 200 字符（表达式原文或参数 JSON） |

## 三、容量与隐私

- 单文件超 **2 MB** 轮转成 `run.log.1.jsonl`（只留一份旧档），不会无限增长；
- 只记前 200 字符，不记完整长文本、不记工作区变量值；
- **写日志失败不影响工具返回**（旁路，try/catch 静默）。

## 四、怎么读

代码里：`readRecentRunLogs(limit)` 返回最近 N 条。
命令行：

```powershell
Get-Content "$env:DSH_MATH_CALC_HOME/logs/run.log.jsonl" -Tail 20
```

统计失败率：

```powershell
Get-Content ...\run.log.jsonl | ForEach-Object { ($_ | ConvertFrom-Json).errorType } | Group-Object
```

## 五、它解决什么

反馈报告里 97 条缺陷、1,069 次失败，全靠使用者一篇篇整理。有了这份日志：

- 开发者可以直接看「哪些 operation 失败最多、错误类型分布」；
- 用户不需要复述报错，日志已经在本地；
- 复盘时按 `at` 与 `input` 就能复现。
