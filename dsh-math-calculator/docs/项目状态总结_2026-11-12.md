# 第一部分：这是什么

## 1.1 定位

**一个带约束检查的世界观推演引擎**，不是计算器。

三条不可违反的性质：

| 性质 | 含义 |
|---|---|
| **可信度标签** | 结果带 `[精确]`/`[标度]`/`[量级]`/`[仅方向]`。它们是结论强度的声明，引用时必须保留 |
| **不猜** | 判据由调用方给（`sanity:{max,min,expect,note}`）。工具不替你决定「这个数合不合理」 |
| **`result` 是数据通道** | 提示走 `notice`。不要把提示当结论读 |

## 1.2 当前规模（实测，非估算）

| 项 | 数量 |
|---|---|
| 版本 | 2.3.25 |
| operation | **40 个** |
| help 节 | **48 节** |
| 公式库 | **665 条** |
| 单位 | 462 条 / 32 量纲 |
| 测试 | **134 套 / 6,702 项** |
| 外部依赖 | 仅 mathjs |

## 1.3 推演段与对账段

```
推演   从零生成世界观（定框架）—— 主要工作
对账   检查既有文档一致性（收官）—— 收尾工作
```

两段共用同一批底层能力，这是「投一次赚两次」的由来。

# 第四部分：判断与教训

## 4.1 我自己犯过的错（都留了证据）

| 错 | 根因 | 教训 |
|---|---|---|
| 把「对账占 80%」当立足点 | 照抄了反馈包一个已被自己推翻的结论 | 转述他人结论前先核对它是否被修正过 |
| 把「拓扑模型」做成依赖传导 | 只读了需求的一句话就动手 | 名词先确认定义，尤其多义词 |
| 以为空间拓扑与依赖图二选一 | 没问就假设 | 不确定就问 |
| 照搬 novel-writer 的陈条/缺席/断线 | 以为「同构」 | **能复用的是机制，不是检查项**——检查项绑定领域前提 |
| 手写 `traverse`/`findCycles` | 没想到先查 | 已立为规矩（见 `docs/开工前先查开源.md`） |
| 反复压缩 help 到字符预算 | 把「省 token」当目标 | 用户的真实目的是**防止注意力分散**，不是省字符 |

## 4.2 三次「手写后发现开源有」

| 手写的 | 开源早有的 | 代价 |
|---|---|---|
| `traverse` + `findCycles`（80 行） | `graphology` components/dag/shortest-path | 还写出了上游方向 bug |
| 地形绕障寻路（计划） | `@turf/turf` 的 `shortestPath` | 计划未开工即作废 |
| 复合单位三次补丁 | `@lhncbc/ucum-lhc` | 修三次仅覆盖 2/3 |

**这就是「开工前先查开源」成为硬门槛的原因。**

## 4.3 一个被推翻的设计判断

**原判断**：help 分层的目标是「省 token」。

**实际目的**（用户澄清）：**防止一次性注入让 AI 注意力分散**。

据此重做后的效果：

```
d-modern-society  5603 → 拆成 4 节，查物理只付 2385（省 57%）
d-coldwar         5198 → 拆成 5 节，查控制论只付 870（省 83%）
```

**判据也不同了**：不是「长度 ≤N」，而是「拆开的理由不是长，是内容互不相关」。
