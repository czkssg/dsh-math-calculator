# 生物学「通用公式」候选清单

> 针对公式库现有 31 条生物公式（其中 **14 条是人类医学/毒理特化**）的补充候选。
> 本文只列清单与判据，不含代码。

---

## 一、什么叫「通用」：五条判据

生物学公式最容易写成「只对某个物种成立」。我用的判据是五条全过才算通用：

| # | 判据 | 反例（现在的库里） |
|---|---|---|
| 1 | **跨类群**成立，不依赖人类解剖 | `widmark_bac`（血液酒精）、`clark_child_dose`（儿童剂）、`pregnancy_days_remaining`（孕期） |
| 2 | **跨尺度**成立，从微生物到鲸 | `bmr_mifflin`（成人公式，体重外推到 9e6 kg 必错） |
| 3 | **跨世界**成立：常数显式暴露，或形式与地球无关 | `heat_dissipation` 用 σ（可换，合格）；反例是烘焙了地球 g 的经验式 |
| 4 | **有物理/几何/化学根源**，不是拟合的行业系数 | `daily_water_need`（人类经验值） |
| 5 | **参数现实可得**：不需要查专业表就能填 | `allometric` 要 Y0/m0/m/b 四个，其中 b 得查表 |

第 5 条最容易被忽略。**「通用幂律」在数学上能算任何东西，但用户不知道指数该填多少，
它就成了一个空壳** —— 这正是文档批评 `metabolic_generic` 的真实成因（虽然它恰好有默认值）。

所以下面的候选，凡是幂律类的，都**直接给理论指数**，而不是再给一个待填 b 的通用式。

## 二、族 1：异速生长（生物学的「牛顿定律」）

幂律 `Y = Y₀·(M/M₀)^b` 是形式，价值在 **b 的理论值**。
分形输运网络理论给出了 1/4 的整数倍这一族指数，所以它跨类群稳。

| 建议 id | 公式 | 指数 | 为什么通用 | 地球外 |
|---|---|---|---|---|
| `sa_volume_ratio` | 表面积/体积 ∝ M^(-1/3) | **-1/3（几何必然）** | **纯几何**：任何三维物体体积∝L³、表面积∝L²。不依赖生物化学 | ✓ 完全通用 |
| `heart_rate_scaling` | 心率 ∝ M^(-0.25) | -1/4 | 与代谢同源（分形网络）；从鼩到鲸跨 6 个数量级成立 | ✓ 系数需标定 |
| `resp_rate_scaling` | 呼吸频率 ∝ M^(-0.25) | -1/4 | 同上 | ✓ |
| `gen_time_scaling` | 世代时间 ∝ M^(0.25) | +1/4 | 生命周期与代谢率反比 | ✓ |
| `pop_density_scaling` | 种群密度 ∝ M^(-0.75) | -3/4 | Damuth 定律：能量通量决定可支撑个体数 | ✓ |
| `locomotion_speed_scaling` | 运动速度 ∝ M^(0.17~0.25) | 0.17/0.25 | 步频∝M^-0.25 × 步长∝M^0.4 的合成 | ✓ 分野：陆/水/飞 |
| `strength_scaling` | 力量 ∝ M^(2/3) | 2/3 | 肌肉横截面积∝L²，**这是「巨兽举不动自己」的根源** | ✓ 完全通用 |

**`sa_volume_ratio` 是这一族里最该先做的**。它一个式子就能回答巨兽设定的两个核心问题：

```
  体重 ×8 → 表面积 ×4 → 单位体重散热能力 ÷2   ← 为什么会过热
  体重 ×8 → 鳃面积 ×4 → 单位体重摄氧能力 ÷2   ← 为什么会缺氧
```

而现有库里的 `body_surface_area` 是 Du Bois 的人体经验式（`W^0.425 × H^0.725 × 0.007184`），
**外推到 9000 吨必错**，且它给不了「比例」这个更有用的信息。

## 三、族 2：输运极限（物理根源，跨介质跨世界）

这一族是「生物为什么长不了那么大」「为什么必须进化出循环系统」的答案。

| 建议 id | 公式 | 为什么通用 | 关键系数 |
|---|---|---|---|
| `fick_diffusion` | J = D·A·ΔC/δ | 呼吸、皮肤吸收、细胞供氧、根吸水**全是它**。纯物理 | D：O₂在水中 2e-9 m²/s、在空气中 2e-5 |
| `diffusion_time` | t ≈ L²/(2D) | **尺寸上限的根源**：L 翻倍，时间 4 倍 → 这就是为什么细胞必须小、大生物必须有循环 | 同上 |
| `oxygen_convection` | V̇O₂ = Q̇·(CaO₂ − CvO₂) | Fick 的对流版，任何有循环的生物都成立 | 血氧含量 ~200 mL/L（人）|
| `oxycaloric_equivalent` | 1 L O₂ ≙ 20.1 kJ（碳水）/19.6（脂肪）| **代谢↔能量的通用换算**，跨物种跨燃料都稳 | 20.1 / 19.6 kJ/L |
| `capillary_rise` | h = 2γcosθ/(ρgr) | Jurin 定律：**树高极限、微血管、土壤持水**同一个式子 | γ水 0.0728 N/m |
| `oxygen_store_scale` | 氧储 ∝ M^0.9~1.0 | 憋气容量随体重近线性；鲸类实测支持 | 需按类群标定 |

**`fick_diffusion` + `diffusion_time` 是这一族的地基。** 它们能立刻否掉「一只能呼吸的巨兽」的很多方案：

```
  若靠扩散供氧，特征尺寸 L 的生物，供氧时间 ~ L²/D
  1 mm 细胞  → 0.5 s    可行
  1 m 组织   → 5.6 天   不可行 ← 所以必须有循环
```

## 四、族 3：生化动力学（跨物种跨世界最稳）

| 建议 id | 公式 | 为什么通用 |
|---|---|---|
| `michaelis_menten` | v = Vmax·S/(Km + S) | **一条式子覆盖五种现象**：酶动力学、载体转运、Holling 摄食功能反应、受体结合、土壤养分吸收。都是同一个饱和形式 |
| `q10_temperature` | R(T) = R₀·Q₁₀^((T−T₀)/10) | **所有代谢率的温度律**。比 Arrhenius 更贴合生物学（Q₁₀ ≈ 2~3 是跨类群的稳值），而 Arrhenius 要活化能 Ea 得查 |
| `monod_growth` | μ = μmax·S/(Ks + S) | 微生物生长；**注意它是米氏的一个特例**，可以不单列 |

`q10_temperature` 值得特别说：现有 `arrhenius` 是化学式（要 Ea），
而生物学家与生态模型实际用的几乎都是 Q₁₀ 形式——**同一条规律，两个学科用两个参数化**，
生物学场景给 Q₁₀ 版本更可用。

## 五、族 4：生态与分布（写世界观的刚需）

| 建议 id | 公式 | 为什么通用 | 关键系数 |
|---|---|---|---|
| `species_area` | S = c·A^z | 岛屿生物地理学核心式：面积小 → 物种少。**做群岛/隔离大陆设定必用** | z ≈ 0.25（岛屿）/0.15（大陆） |
| `beer_lambert` | I = I₀·e^(−kz) | 光在水中/林冠/雪层中的衰减，**同一式子三种介质** | k：清水 0.02~0.05 /m，浊水 0.5+ |
| `holling_type2` | 摄食率 = aN/(1+ahN) | 相同于米氏；功能反应 II 型。**捕食设定的基础** | a 攻击率、h 处理时间 |
| `metabolic_biomass_allocation` | 净生产 = 同化 − 呼吸 | 能量预算的通用恒等式（常与 `trophic_chain_support` 联动） | — |

`species_area` 的价值在于：**它能给「这个岛能养多少物种」一个数**，
而现在的库只有 `population_density_limit`（人数）与 `grazing_capacity`（头数），没有物种数这个概念。

## 六、族 5：渗透与体液平衡（跨介质设定必用）

| 建议 id | 公式 | 为什么通用 |
|---|---|---|
| `van_t_hoff_osmotic` | π = i·M·R·T | 渗透压的物理式。跨物种（淡水鱼/海水鱼/陆生）与跨溶剂都成立。**「这头巨兽能不能在淡水活」的关键判据** |
| `osmotic_water_flux` | Jv = Lp·(Δπ − ΔP) | Starling 关系的简化式，用于体液交换 |

## 七、汇总：建议采纳的子集

### 第一梯队（8 条：通用性最强、场景最刚需）

| 1 | `sa_volume_ratio` | 表面积-体积比 M^(-1/3) | 巨兽过热/缺氧的根源，**纯几何** |
| 2 | `fick_diffusion` | 扩散通量 | 呼吸/吸收/供氧的地基 |
| 3 | `diffusion_time` | 扩散时间 ∝ L² | 尺寸上限的定量判据 |
| 4 | `oxygen_convection` | V̇O₂ = Q̇·ΔC | 循环系统输送上限 |
| 5 | `oxycaloric_equivalent` | 1 L O₂ ≙ 20.1 kJ | 代谢↔能量换算，跨燃料 |
| 6 | `michaelis_menten` | 饱和动力学 | 一条式子覆盖五种现象 |
| 7 | `q10_temperature` | 温度系数 | 所有代谢率的温度律 |
| 8 | `species_area` | S = cA^z | 岛屿/隔离大陆的物种数 |

### 第二梯队（5 条：有用，场景稍窄）

| 9 | `heart_rate_scaling` | 心率 ∝ M^(-1/4) |
| 10 | `pop_density_scaling` | 种群密度 ∝ M^(-3/4) |
| 11 | `strength_scaling` | 力量 ∝ M^(2/3) |
| 12 | `beer_lambert` | 光衰减 |
| 13 | `van_t_hoff_osmotic` | 渗透压 |

### 不建议做

| 不做 | 理由 |
|---|---|
| `monod_growth` | `michaelis_menten` 的特例，重复 |
| `holling_type2` | 同上；可用 `michaelis_menten` 换参数名 |
| Lotka-Volterra 动态 | 需要解 ODE，已有 `operation:"ode"`，不该塞进单次求值 |
| 又一个「通用幂律」 | `allometric` 已有；问题不是缺通用式，而是**缺带理论指数的专用式** |
| 巨兽专用公式（巨型生物氧储、滤食效率） | 见 DIY 方案：参数太特殊，应由用户用 `formula-table` 自己攒 |

## 八、两条设计建议（比条目本身更重要）

### 1. 幂律类一律「指数内置、系数可调」

现有 `allometric` 是 `Y0·(m/m0)^b`，四个参数全必填 —— **通用但不可用**。
对比 `lifespan_scaling`：它把 b 默认成 0.25，所以只填 L0/m0/m 就能用。

新条目应延续后者的形态：**理论指数写死（并注明出处），标定系数给默认值**。

```
  sa_volume_ratio  { mass, ref_mass=1, ref_ratio=6.0 }  ← 指数 -1/3 内置，只问质量
  heart_rate_scaling { mass, ref_mass=1, ref_rate=70 }  ← 指数 -1/4 内置
```

### 2. 每条 desc 里写「这个指数从哪来」

这是本项目已有约定（`empiricalNote` 的「底层原理」「藏了什么」）。
对异速生长族尤其重要，因为 1/4 与 2/3 各有各的来源：

```
  1/4  ← 分形输运网络的最优层级（West-Brown-Enquist）
  2/3  ← 肌肉横截面积的纯几何
  1/3  ← 体积/表面积的纯几何（无需任何生物假设）
  3/4  ← 分形网络的能量通量
```

分清「几何必然」与「网络理论推论」很重要：
前者在任何世界都成立（**包括非碳基**），后者依赖「存在分形输运系统」这个前提。
