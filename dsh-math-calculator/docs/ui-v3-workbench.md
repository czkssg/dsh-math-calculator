## 二、关键：只有基础量可输入

### 23 个可输入参数（7 组）

| 组 | 数量 | 其中默认展开 |
|---|---|---|
| 恒星 | 4 | 恒星类型 |
| 轨道 | 2 | 离恒星多远 |
| 行星 | 5 | 质量、半径、日长、轴倾角 |
| 大气 | 5 | —（全在进阶） |
| 地表 | 2 | —（全在进阶） |
| 卫星 | 3 | —（全在进阶） |
| 天空 | 2 | —（全在进阶） |

**默认展开 6 个，进阶 16 个折叠。**

### 派生量一个都不在输入清单里

测试专门守着这条：

```
不把 gravity 当输入        ✓
不把 surfaceGravity 当输入 ✓
不把 surfaceMeanK 当输入   ✓
不把 scaleHeight 当输入    ✓
不把 escapeVelocity 当输入 ✓
```

### 硬塞也会被丢弃

```js
deriveAll({ planetMass: 2, gravity: 99, surfaceMeanK: 999, 乱写的字段: 1 })
→ planetMass: 2      ✓ 保留
→ gravity: undefined  ✓ 丢弃
→ surfaceMeanK: undefined ✓ 丢弃
→ 重力仍按 G·M/R² 现算 = 19.6 m/s²（2 g）
```

**这是体系自洽的技术保证**：派生量绝不可能被固化成一个与公式冲突的值。

## 三、改一个基础量，全链自动重算

实测（planetMass 1 → 2）：

| 量 | 改前 | 改后 |
|---|---|---|
| 重力 | 9.82 m/s² | **19.64 m/s²** |
| 逃逸速度 | 11.2 km/s | 变大 |
| 大气标高 | 8399 m | **4200 m**（重力压扁） |
| 生物高度上限 | 25 m | **12.5 m** |

**一个输入改动，物理、生物、文明三层全部跟着变。**

## 四、反解：说要什么，告诉你改哪个数

```
┌─ ④ 我想要… ─────────────────────┐
│ [重力要几倍地球 ▾] [1.5] g [算]  │
│                                  │
│ 重力 ∝ 质量 / 半径²。半径保持 1   │
│ 地球半径时，要 1.5 g 需质量 1.5   │
│ 地球质量。                        │
│                                  │
│ 连带效应：                        │
│   实际重力：1 g → 1.5 g          │
│   逃逸速度：11.2 → 13.7 km/s     │
│   大气标高：8400 → 5600 m        │
│                                  │
│        [应用这个改动]             │
└──────────────────────────────────┘
```

### 4 个锚点

| 锚点 | 反解公式 | 输出 |
|---|---|---|
| 重力要几倍 | `M = g · R²` | planetMass |
| 逃逸速度要多少 | `R = 2GM/v²` | planetRadius |
| 生物能长多高 | `g = 25/L → M = g·R²` | planetMass |
| 一天要多长 | 直接是 rotationHours | rotationHours |

实测：

```
要 1.5g    → planetMass = 1.5      ✓
要 50 米巨兽 → planetMass = 0.5      ✓
要 15 km/s  → planetRadius = 0.556  ✓
```
