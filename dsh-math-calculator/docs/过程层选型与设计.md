## 一、结论先行

1. **不引第三方库**。npm/GitHub 上没有值得引的 SIR/传染病库（见第二节）；
   底层复用已有的 `ode`（RK4、多状态、`at` 精确取点、极值）与 `simulate`。
2. **80% 是配方，20% 是公式**——与《完整世界观缺口分析》1.2 的判断一致，本次实测也证实。
3. **本轮只做最小可用集**：
   - 公式 `epidemic_peak_fraction`（峰值比例，闭式，可自验）；
   - 公式 `spread_wave_speed`（空间蔓延速度，Fisher-KPP 闭式，疫情/火势/谣言通用）；
   - **峰值时刻不造闭式**——它没有简洁解析式，走 `ode` 的 `value.extrema`（本轮已修好）；
   - SIR/SEIR 的**配方**写进本文第六节与 `ode` 的 help，不新增 operation。

**结论**：自写两条闭式 + 配方；用 `ode` 的数值解做交叉验证（本项目既有做法）。

## 三、第一性原理：这一层缺什么

现有引擎擅长**终态求解**（给参数 → 算「会怎样」）。缺的是**时间轴上的因果**：

| 问题 | 需要的量 | 现状 |
|---|---|---|
| 多久翻一倍 | 倍增时间 | ✅ `epidemic_doubling_time` |
| 最终多少人感染 | 最终规模 | ✅ `sir_equilibrium`（不动点迭代） |
| **峰值那周多少人病着** | 峰值比例 | ❌ 本次补（闭式） |
| **何时达峰** | 峰值时刻 | ❌ 无闭式 → 走 `ode` 极值 |
| **每天传多远** | 空间前沿速度 | ❌ 本次补（Fisher-KPP） |
| 曲线长什么样 | 时间序列 | ❌ 靠配方（`ode` 的多状态） |

关键认知：**这些量不是同一件事**。R0=3 时峰值 30%、最终感染 94%，
峰值决定「医院撑不撑得住」，最终规模决定「死多少人」——混用会写出错的设定。

## 四、两条公式的定义

### 4.1 峰值比例 `epidemic_peak_fraction`

```
I_peak/N ≈ 1 - (1 + ln R0)/R0        （max(0, …) 兜住 R0 ≤ 1）
```

推导：峰值时 `dI/dt = 0` → `S = N/R0`；再用「达峰前 R 可忽略」的守恒近似消去 R。
适用：均匀混合、无干预、无年龄结构。**是近似**，实测与 ode 数值差 0.1%（R0=3）。

### 4.2 空间蔓延速度 `spread_wave_speed`

```
v = 2·sqrt(D·r)
```

Fisher–KPP 反应扩散方程的最小行波速度。D 与 r 必须同单位体系（km²/天 配 1/天）。
同一个式子解释三种现象：疫情（D=人员流动、r=γ(R0−1)）、火势（D=飞火/热辐射、r=燃烧增长）、
谣言（D=社交接触、r=传播率）。

## 五、实现与验证（TDD）

测试 `test-v3/r103-process-formulas.mjs`：

1. **峰值比例 vs ode 数值**：R0 = 2 / 3 / 4，闭式与 `ode` 轨迹极值对照，容差 2%；
2. **R0 ≤ 1 边界**：R0=1 → 0、R0=0.5 → 0（不应给负数）；
3. **波速 vs 一维 PDE 数值解**：显式差分解 Fisher–KPP，测前沿斜率，与 `2√(Dr)` 对照；
4. **公式可被 `formulas` 取到并可求值**（两条都要能进实现）。

## 六、配方（可直接抄）

### 6.1 SIR 时程（回答「第几周、峰值多少、最后死多少」）

```json
{ "operation": "ode",
  "expression": "dS/dt=-0.3*S*I/1000, dI/dt=0.3*S*I/1000-0.1*I, dR/dt=0.1*I",
  "initial": { "S": 999, "I": 1, "R": 0 },
  "from": 0, "to": 120, "steps": 2000, "at": [10, 20, 30, 40] }
```

读法：`at` 给指定周；`value.extrema.I.maxT` 是达峰时刻；`value.final.R` 是累计感染。

### 6.2 SEIR（有潜伏期，更贴真实）

```json
{ "operation": "ode",
  "expression": "dS/dt=-0.3*S*E/1000, dE/dt=0.3*S*E/1000-0.2*E, dI/dt=0.2*E-0.1*I, dR/dt=0.1*I",
  "initial": { "S": 999, "E": 0, "I": 1, "R": 0 },
  "from": 0, "to": 200, "steps": 3000 }
```

### 6.3 参数怎么定

- `β`：从 R0 反推，β = R0·γ（γ = 1/病程天数）；
- 病程 10 天 → γ = 0.1；R0=3 → β = 0.3；
- 参数量级不确定时，先跑两组（乐观/悲观）看结论是否翻转——**不猜单点值**。

## 七、明确不做（避免范围失控）

- 不新增 `process` / `epidemic` operation（配方用 `ode` + 文档承载）；
- 不做空间 PDE 求解器（波速给量级即可，精确场靠外部）；
- 不实现火势的 Rothermel 物理模型（那需要燃料/坡度/风，属另一层）；
- 不写 SEIR 的闭式解（无简洁式，走数值）。
