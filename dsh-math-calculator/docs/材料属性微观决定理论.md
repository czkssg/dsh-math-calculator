# 材料属性的微观决定理论 —— 能否连到基础物理量

> 针对「决定材料属性的理论有没有对应公式、能不能和基础物理量联系起来」的联网核实。
> 核心问题：**材料的 E、σy、熔点、脆性，究竟是硬设定，还是能从更底层推出？**

---

## 一、先分级：材料的哪一层能连到基础物理量

这个问题必须分层回答，否则会得出「都能推」或「都推不了」的假结论。

| 层级 | 属性 | 能否由基础物理量推出 | 依据 |
|---|---|---|---|
| **L1 原子尺度** | 结合能、弹性模量、理论强度、熔点 | **能** —— 键能与键密度可推 | 有解析式（见下） |
| **L2 微观组织** | 晶粒尺寸、位错密度、空位浓度 | **能，但需组织结构参数** | Hall-Petch、Taylor 等经验式 |
| **L3 工程性能** | 实际屈服强度、韧性、疲劳寿命 | **半能** —— 本质由 L2 的缺陷结构决定 | 经验 + 微观力学 |
| **L4 特定品种** | 45 钢的 E=2.06e11、Ti-6Al-4V 的 σy | **不能** —— 那是工艺史的产物 | 只能查表或硬设定 |

**所以「架空宇宙可以大改」的正确落点是 L1 与 L2** —— 那里有物理联系，
改了基础物理量，材料属性会跟着变，而且变的方向和幅度是算得出来的。
L4 本来就该硬设定（现实里也是查表）。

## 二、A 组：真正的「由物理量推出材料属性」（4 条，有解析式）

### A1. 理论强度（理想强度）—— 由结合能/弹性模量推

```
  Frenkel 估计：  σ_ideal ≈ E / 10          （常见形式 E/5~E/15）
  Frenkel 剪切式：τ_ideal ≈ G / (2π)        （或 G/10 量级）
  由表面能：      σ_ideal ≈ √(E·γ / a₀)     （Orowan-Polanyi）
```

- 来源：**《Theoretical Strength of Solids》(Communications 2004)** —— 明确列出 Frenkel 与
  Orowan-Polanyi 两个经典估计；arXiv 2105.05099 开篇即说「早期理论证明最大可承受拉/剪强度是受控的」；
  Nature Comm 2019 讨论钻石的理论极限
- **这是真正连到基础物理量的一条**：`E` 由原子键强度与键密度决定，
  所以「换个世界，键更强 → E 更大 → 理论强度更大」是有物理依据的
- **跨世界照用**：✓（E 换了自然跟着变）
- **关键工程意义**：实际材料强度通常只有理论值的 **1/100 ~ 1/10**（因为缺陷），
  这个比值本身就是一个可调的世界观参数：**「这个世界的冶金水平」= 实际/理论比**

### A2. 熔点与结合能 —— Lindemann 判据

```
  Lindemann：熔化发生在原子热振动振幅达到原子间距的临界分数时
  T_m ∝ (结合能) × (原子质量) / (原子间距²)      （量级形式）
  经验标度：T_m ≈ (2/3) × 结合能/k_B             （单原子金属的粗略关系）
```

- 来源：**Phys Rev 102,308 (1956)《The Lindemann and Grüneisen Laws》**（把 Lindemann 假设
  改写为「均方根热振幅达到临界分数」的严格形式）；Lindemann 1910 原始工作；
  PMC10722469《Melting Is Well-Known, but Is It Also Well-Understood?》；
  J Phys Chem Solids 2003《Empirical correlation between melting temperature and cohesive energy》
- **连到基础物理量**：结合能 ← 键能 ← 电子结构。所以**换了键强度，熔点跟着变**
- **跨世界照用**：✓ 定性可靠，定量需标定（金属/共价/离子差异大）
- **价值极高**：熔点是最「可感知」的材料属性（能不能造蒸汽机、能不能在岩浆边生存），
  而它居然可以从结合能推 —— 这意味着**架空设定里可以反过来设计**：
  「我要一个熔点 2000°C 的金属」→ 反推需要多大的结合能

### A3. 弹性模量与结合能 —— 二阶导数关系

```
  E ∝ (d²U/dr²)/r₀                 （势能对间距的二阶导 × 原子间距）
  简化标度：E ≈ 结合能 / 原子体积 × 常数
```

- 这是**模量的物理定义**：E 就是势能井底的曲率。
- 联系：**结合能越深 → 井越陡 → E 越大**。这条让「硬设定 E」变成了「设定键强度」
- **跨世界照用**：✓ 完全通用（这是定义级关系）
- 建议形态：不收成公式（它是标度关系不是等式），但**写进 desc 作为设计指引**

### A4. Pugh 判据 —— 由弹性常数推「脆还是韧」

```
  Pugh 比：  G / K      （剪切模量 / 体积模量）
  判据：     G/K > 0.57（即 B/G < 1.75） → 偏脆
             G/K < 0.57                    → 偏韧
```

- 来源：**Nature Sci Rep 2021《Generalization of intrinsic ductile-to-brittle criteria by Pugh and Pettifor》**；
  Sci Dir《Predicting whether a material is ductile or brittle》（Thompson & Clegg，剑桥材料系）；
  Royal Society Proc A 2020 讨论泊松比的临界值
- **连到基础物理量**：K 与 G 都由结合能曲线推出，所以**脆性也可以从底层推**
- **跨世界照用**：✓（比值判据，无量纲）
- **诚实标注**：这是**筛选**而非定论，Nature 那篇本身在「推广」它（说明原判据不够普适）
  desc 必须写「经验判据，用于快速筛选」

## 三、B 组：微观组织 → 性能（3 条，可微调）

### B1. Hall-Petch —— 晶粒尺寸决定屈服强度

```
  σ_y = σ_0 + k_y · d^(−1/2)
  d 晶粒直径 m ｜ k_y 强化系数（钢约 0.15~0.6 MPa·√m）
```

- 来源：**Callister《Materials Science and Engineering》Ch7**（标准教材）；
  Springer J Mater Sci 2019《The Hall–Petch and inverse Hall–Petch relations》；
  UC Berkeley Morris《The Influence of Grain Size on the Mechanical Properties of Steel》
- **这是「工艺可调」的典型**：同一成分的钢，晶粒细化一个数量级，强度可翻倍。
  架空设定里「这个世界的锻造工艺」就对应 `d` 与 `k_y` 两个可调量
- **跨世界照用**：✓ 形式通用（阐明了「为什么细晶更强」：晶界阻挡位错）
- **重要提醒**：**有反 Hall-Petch 区**（纳米晶粒下强度反而下降）。
  Springer 那篇标题就含「inverse Hall–Petch」，desc 必须写这个边界

### B2. 位错强化（Taylor 关系）

```
  Δσ ≈ α · G · b · √ρ
  α 常数(~0.3) ｜ b 柏氏矢量 ｜ ρ 位错密度 m⁻²
```

- 与 Hall-Petch 同族：都是「缺陷密度 → 强度」。
- **价值**：`ρ` 从冷加工量决定（退火 vs 淬火差 3~5 个数量级），
  这是「热处理工艺」在公式上的直接体现
- 建议与 B1 合并为一条「强化机制」公式族，或只做 B1（更常用）

### B3. 格律奈森（Grüneisen）—— 由非谐性推热膨胀

```
  α = γ · C_v / (3 · K)          γ Grüneisen 参数（通常 1~3）
```

- 来源：Phys Rev 139,A877《Thermal Expansion and Other Anharmonic Properties of Crystals》；
  Phys Rev B 105,064112（自洽声子理论下的 Grüneisen 修正）
- **连到基础物理量**：γ 是非谐性的度量（键势偏离对称的程度），
  所以**热膨胀可以从键势形状推**
- **跨世界照用**：✓（γ 可调，物理意义明确）
- **为什么有用**：现有库只有 `thermal_expansion`（`ΔL = αLΔT`），**α 是硬设定**。
  这条让 α 可以从 K、C_v、γ 推出来 —— 补上了闭环

## 四、C 组：有价值但只到「经验关联」

| 项 | 已有联系 | 判定 |
|---|---|---|
| Wiedemann-Franz `κ/(σT) = L₀` | 由电子输运推出（L₀ = 2.44e-8 W·Ω/K²） | **做**。它把「导热」与「导电」锁在一起，是**罕见的严格关系**，来源 TU Graz + DoITPoMS + Wikipedia |
| Gibbs-Thomson 纳米熔点降低 | 表面能修正，有解析式 | 值得做（纳米材料设定），但场景窄 |
| 空位浓度 `n/N = exp(−Q_v/kT)` | 阿伦尼乌斯型 | 可做，参数 Q_v 需设定 |
| 表面能 γ 与结合能 | 断键数标度（`γ ≈ 结合能/面积 × 配位数损失`） | 只做 desc 说明，不收公式（形式不定） |
| 自扩散 `D = D₀·exp(−Q/kT)` | 已有阿伦尼乌斯，**但缺材料版的 D₀、Q 语义** | 可作为 `arrhenius` 的材料特化说明 |

| id | 公式 | 联系的基础物理量 | 来源 |
|---|---|---|---|

### 不收公式，但写进 desc 的设计指引

| 项 | 内容 |
|---|---|

| 实际/理论强度比 | 现实为 1/100~1/10，**这个比值就是「冶金水平」** |
| 表面能 ↔ 结合能 | 断键数标度；纳米尺度的重要修正 |

## 六、这套东西对「架空宇宙大改」的用法

你说「很多时候可以微调或者大改」——这批公式的价值正是**把大改变成有依据的推导**。

### 场景 A：改基础物理量，看材料怎么变

```
① 设「这个世界的电磁耦合更强」→ 结合能 ×1.5
② melting_from_cohesive   熔点按标度上升
③ 模量 E ∝ 结合能/原子体积   → E 上升
④ ideal_strength            理论强度 = E/10，跟着上升
⑤ pugh_ductility            G/K 变了 → 可能从韧变脆
⑥ 结论：更强的键 → 更硬更耐热，但可能更脆
```

这条链是**物理自洽的**，不是编的。这比「设定这种材料很硬」可信得多，
而且它能推出作者自己没想到的副作用（更脆）。

### 场景 B：反推 —— 从想要的材料倒推需要什么物理条件

```
我要一个「熔点 3000°C、E = 5e11、仍然韧性足够」的材料
→ melting_from_cohesive  反推所需结合能
→ ideal_strength         反推 E
→ pugh_ductility         检查 G/K 会不会掉进脆性区
→ 若掉进 → 结论：需要「增体积模量而不增剪切模量」的结构，
   现实里的对应物是金属键 + 高配位 —— 于是架空的「生物合金」可据此设计
```

**这是这批公式最独特的价值：它让设定从「描述」变成「工程」。**

### 场景 C：微调 —— 改工艺不动物理

```
hall_petch  ：不换成分，只改晶粒尺寸 d → 强度可翻倍
              「这个文明的锻造水平」= 他们能达到的 d
vacancy/taylor：改热处理 → 位错密度 ρ 差 3~5 个数量级
```

## 七、一条重要提醒：这些公式的「可信度分层」

这批公式不宜统一标注可信度，因为它们性质完全不同：

| 类型 | 例子 | 该怎么标 |
|---|---|---|
| **定义级/严格** | `wiedemann_franz`（L₀ 是基本常数）、`E ∝ 势能井曲率` | `[精确]` |
| **标度律** | `melting_from_cohesive`（对数量级可靠，系数因键型而异） | `[标度]` |
| **经验判据** | `pugh_ductility`（阈值 0.57 是筛选线）、`hall_petch`（有反 HP 区） | `[量级]` |
| **量级估计** | `ideal_strength ≈ E/10`（E/5~E/15 都有人用） | `[仅方向]` |

**这一层必须如实标注**，否则会把「量级估计」当成「精确值」用 ——
那是本项目一直在打击的那类问题。
