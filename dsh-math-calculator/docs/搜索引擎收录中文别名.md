## 三、搜索结果里必须拦下的两类

**① 同形异义**

```
搜索「英石 stone 重量单位」→ 两条结果：
  · 英石（中国国家地理标志产品）  ← 广东英德特产石材，不是单位
  · 英石（英制质量单位）          ← 这才是
```

必须看摘要里的「（英制质量单位）」才能确认。**只匹配词形会收错。**

**② 公司/品牌名污染**

```
搜索「普特 pood」→ 浙江普特医疗器械有限公司
搜索「维尔斯特 verst」→ 广东维尔科技（扫地机器人）
搜索「沙绳 sazhen」→ 俄语词典条目 ✓（唯一命中）
```

企业名与单位名撞词，搜索排序还常在前面。

## 四、能力边界（诚实说明）

| 类别 | 搜索效果 |
|---|---|
| 英制（质量/长度/容积/能量） | ✅ 好，百度百科/汉典/维基都有条目 |
| 电磁/辐射/天文/数据 | ✅ 好 |
| 中国古代（铢/钧/斛/锱） | ✅ 好，且能查到进位关系 |
| **俄制/德制/日制** | ❌ **差**，结果大半是企业名或维基主页 |

俄德日制单位的中文译名**在中文互联网上几乎没有可用条目**，
只能靠音译（`普特`/`沙绳`/`维尔斯特`）——这类收录价值也低。
