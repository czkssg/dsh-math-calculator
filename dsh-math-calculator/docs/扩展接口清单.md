# 扩展接口清单

> 2026-11-20 · v3.35.0。**功能盘点**：哪些能力有扩展接口、哪些是只读、为什么。

## 一、有扩展接口的（mathEngine 服务，22 个方法）

| 功能 | 接口 | 作用域 |
|---|---|---|
| 单位 | `registerUnits` / `listUnits` / `unregisterUnits` | 命名空间（独立引擎） |
| 货币 | `registerCurrencies` / `listCurrencies` / `unregisterCurrencies` | 命名空间（内置 47 + 自定义） |
| 公式 | `registerFormulas` / `listFormulas` / `unregisterFormulas` | 命名空间（`formula()` 优先自定义） |
| 世界设定 | `worldState(set/get/list/delete)` | 命名空间（键值） |
| 数据层 | `data(put/get/query/stats)` | 当前工作区（与 `data` 工具同一份） |
| 实体类型 | `entities(register/list/unregister)` | 命名空间（供调用方参考；topology 需显式传） |
| 拓扑模型 | `models(save/load/list/delete)` | 命名空间（内存） |
| **公式链** | **`registerChains` / `listChains` / `unregisterChains` / `chain(id, {namespace})`** | 命名空间（1–20 步；`chain` 自定义优先，否则内置 `sys-*`） |
| 常数 | `constant(name)` / `constants()` | 只读（标准值） |

统一：命名空间隔离、注销只清该类、错误三档（`input` / `capability` / `internal`）。

## 二、只读、不需要扩展的

| 功能 | 理由 |
|---|---|
| `help` / 文档 | 只读参考 |
| `formulas` 检索 / 公式网 | 构建产物（`formula-web.json`），改数据要重建 |
| `units` 内置换算表 | 469 条常量数据，改动走 `registerUnits`（命名空间） |
| `solve` / `matrix` / `stats` / `optimize` 等算法 | 算法无「世界特定数据」 |
| `constants` 推演 | 派生量由旋钮公式决定，改常数走 `constants` op / 公式 `params` |
| `world-map` / `topology` 生成 | 参数化输入已足够，不需要注册表 |
| 公式链的内置 `sys-*` | 人工声明的固定路径；自定义链已开放（见上表），内置链只读 |

## 三、部分开放（说明）

- **实体类型**：`entities` 存的是「调用方自己的清单」，`topology` 不会自动读取——需要时把清单内容作为 `topology.customEntities` 显式传入；
- **数据层**：服务层 `data` 用**当前工作区**（`currentWorkspace`），跨工作区隔离由工作区机制保证；
- **常数**：`constants()` 只读标准值；要改世界里用 `constants` op（覆盖 + 派生）或公式 `params`。

## 四、压测（扩展接口）

| 项 | 结果 |
|---|---|
| 1000 次 worldState set/get | 5ms |
| 1000 次 worldState list（每条 1000 项） | 647ms |
| 10 命名空间 × 100 实体注册 | 16ms |
| 500 次 models save/load | 7ms |
| 500 次 data put（服务层） | 3.2s（6.4ms/条，写文件） |
| 50 并发 worldState | 50/50 |
| 10 命名空间 × 50 链注册 | 1.35s |
| 1000 次自定义链执行 | 5.3s（5.3ms/次，2 步） |
| 50 并发链执行 | 50/50 |
| 注销链 10 命名空间 | 1ms，注销后 capability |
