# 架空常数：公式里的常数不做死

> 用户规则（2026-11-19）：架空世界的常数可能改，所以公式里**不是乘数量都不能定死**——
> 常数一律作为**可选参数**，默认是现实值，但可以覆盖。

## 一、原则

1. **表达式里不写物理常数**：`E = mc²` 写成 `E = m * c`，`c` 是参数（默认 299792458）；
2. **默认值 = 现实值**（CODATA 2022 / IAU 2015），不改就是现实世界；
3. **覆盖即生效**：`params:{c:1e8}` 直接改这一套世界；
4. **数学系数保留**（0.5、2、π、1/3）：它们不是物理常数，改它们等于换公式；
5. **经验系数也参数化**：如瑞利判据的 1.22（改成 1.0 即理想方孔）。

## 二、本轮参数化的公式（12 条）

| 公式 | 参数（默认值） |
|---|---|
| `mass_energy`（原已有 c 参数） | c = 299792458 |

> 另有大量公式的常数本来就在参数默认值里（g、G、sigma、R、F、mu0、eps0…），
> 之前扫描确认：**表达式里已无硬编码物理常数**（宽松匹配 0 条）。

## 三、用法

```jsonc
// 现实世界
{ "operation": "formula", "formula": "photoelectric_threshold", "params": { "work_function": 4.5e-19 } }

// 架空宇宙：普朗克常数翻倍 → 阈值频率减半
{ "operation": "formula", "formula": "photoelectric_threshold",
  "params": { "work_function": 4.5e-19, "h_planck": 1.32521403e-33 } }
```

发现某公式有哪些常数：看它的 `params` 表（`formula` 结果里会列出），
或 `formulas query:"web"` 的上游里常数节点（`kind:"constant"`）。

## 四、限制

- 常数参数带 `dimension`：带单位调用时会校验（传错单位会报 `unit_mismatch`）；
- `gini` 的 `G` 是基尼符号，不是万有引力常数（展示式，不参与求值）；
- 数学系数（0.5/2/π）不参数化——改它们就是换公式，不是改世界。
