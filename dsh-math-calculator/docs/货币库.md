# 货币符号库

> 2026-11-20 · v3.33.0。**只做符号库**：中文名、国际符号、缩写。

## 一、定位（用户口径）

- 现代货币的货币库**只是用于创造货币符号方便调用**（$5/t、€3/kg、¥12/斤）；
- **不做汇率换算**，**不记录购买力**——购买力由 AI 按当时世界自行查询/设定；
- 古代/架空货币同样只给符号信息（金/银/铜比例由世界设定决定）。

| fantasy（架空通用） | 9 | 金币 g/金、银币 s/银、铜币 c/铜、铁币、信用券、信用点、能量币、晶币、以物易物 |

字段：

```jsonc
{ "code": "USD", "name": "美元", "symbol": "$", "abbrev": "美元", "kind": "modern", "note": "…" }
```

## 三、用法

```jsonc
{ "operation": "currency" }                              // 全部 47 条（按类别分组）
{ "operation": "currency", "currencyKind": "modern" }    // 只列现代货币
{ "operation": "currency", "currencyAction": "get", "currencyCode": "USD" }
{ "operation": "currency", "currencyAction": "get", "currencyCode": "人民币" }  // 中文名也认
```

**不做换算**：`currencyAction:"convert"` 会被拒绝（`unknown_argument`），并提示“购买力由 AI 自行判断”。

## 四、写作示例

| 写法 | 说明 |
|---|---|
| `$5/t` | 美元每吨 |
| `€3/kg` | 欧元每公斤 |
| `¥12/斤` | 人民币每斤 |
| `1 两银/石` | 古代银两计价（银两缩写「两」） |
| `1 金 = 10 银 = 100 铜` | 架空比例——由世界设定决定，库里只给符号 |
