# 通用气候拟合模型（2026-11-16）

> 用户要求：用地球和气候理论建立**通用拟合模型**（推广到不同条件的行星），
> 「看上去合理、有据可循」，并用地球数据矫正。

## 一、思路：不是「真实环流求解」，是「可标定的解析模型」

```
地球实测（纬度温度/降水观测）
  → 定标：解出形状指数 p（最小二乘，扫参 0.6–2.6）
  → 模型：T(φ) = T_eq − ΔT·(1 − cos^p φ)
  → 换行星参数：通量/温室/气压/自转/倾角 → 改变 T_eq 与 ΔT
  → 自检：地球参数代入，报告残差
```

## 二、标定数据（地球年均）

| 纬度 | 年均温 °C | 年降水 mm |
|---|---|---|
| 0° | 27 | 2000 |
| 15° | 25 | 1200 |
| 30° | 19 | 600 |
| 45° | 11 | 750 |
| 60° | 0 | 500 |
| 75° | -12 | 250 |
| 90° | -25 | 150 |

## 三、定标结果（实测）

```
拟合形状指数 p = 1.07（最小二乘扫参）
地球自检：平均残差 0.2 K、最大 0.6 K
残差：0°:0.0  15°:0.1  30°:0.6  45°:-0.1  60°:-0.2  75°:-0.6  90°:0.1
```

**这是「有据可循」的证据**：模型不是拍脑袋，而是用地球实际观测反推参数，
残差 0.2 K 说明「对地球是准的」——推广到其他行星时，变化来自物理量的缩放，
而不是随便调的旋钮。

## 四、推广机制

| 行星参数 | 影响 | 依据 |
|---|---|---|
| 恒星辐射 `stellarFlux` | `T_eq` 平移 `(flux^0.25 − 1) × 40` | Stefan-Boltzmann 四次方根 |
| 温室 `greenhouseK` | 每 +10 K 温室 ≈ 地表 +6 K | 地球 33 K 温室 ≈ +33 K 的线性近似 |
| 气压 `pressureAtm` | 纬向输运强 → 温差小 | 输运效率 ~ 气压 |
| 自转 `rotationHours` | 快转 → 温差小 | 科氏力/涡动输运 |
| 倾角 `obliquityDeg` | 极地年均略升 | 极地夏季日照增强 |
| 陆地占比 `landRatio` | 降水整体偏移 | 海陆热力差 |

实测：

| 条件 | 赤道 | 极地 | 梯度 |
|---|---|---|---|
| 地球（flux 1） | 27.0°C | -25.0°C | 52 K |
| 暗星（flux 0.7） | 23.6°C | -28.3°C | 52 K |
| 亮星（flux 1.4） | 30.5°C | -21.3°C | 52 K |
| 慢转（240 h） | — | — | 更大 |
| 快转（12 h） | — | — | 更小 |

## 五、降水模型

```
P(φ) = 150 + ITCZ(φ)×1850 + 极锋(φ)×350 − 副高(φ)×100 + (landRatio−0.29)×300
再到网格：− 距海衰减 + 迎风坡地形雨 − 背风坡雨影
```

干旱修正：降水 < 200 mm → 「干旱（沙漠）」（可耕率 1%）；< 450 mm → 「半干旱（草原）」（18%）。

结果：地球参数下约 50% 陆地被标为干旱/半干旱区，可耕率 17%（现实耕地约 12%，量级相符）。

## 六、精度边界

- 不做大气环流/洋流/季风；
- 降水只到「带 + 距海 + 地形」层级；
- 残差 < 1 K 是**标定集内**的拟合，不代表任何行星的预测精度；
- 定位是「看上去合理、有据可循」，不是科学预测。
## 七、极宏观大气/海洋/云（2026-11-16 追加）

> 用户要求：「温度不做大气环流求解；降水没有季风、洋流、云物理——写个粗糙的极为宏观的，不用多精细。」

三个机制，各一个式子，不做流体求解：

### ① 季风

```
季风强度 = 纬度权重 × 陆地占比 × 2      // 低纬 + 大块陆地 → 强
陆地：降水 ×(1 + 0.25×强度)   // 夏季风（海→陆）
海洋：降水 ×(1 − 0.05×强度)   // 冬季风（陆→海）
```

实测（20°、1500 mm、陆地）：**×1.145**（+14.5% 降水）。

### ② 洋流

```
信风带（0–30°）向西输送，西风带（30–60°）向东输送
沿岸温度 ±(0.8–1.5) K（低纬暖流更强）
```

实测：20° 陆地 **−1.5 K**。

### ③ 云

```
云量 = min(0.9, 降水/2500)
云致温度 = −云量×2.2 + (1−云量)×0.3    // 厚云昼遮阳，薄云夜保温
```

实测：1500 mm → 云量 0.6、**−1.2 K**；100 mm → 云量 0.04、**+0.29 K**。

### 合起来的效果

| 项 | 之前 | 现在 |
|---|---|---|
| 地球可耕率 | 17.2% | **18.7%** |
| 干旱区 | 50% | 50% |
| 温带 | 51% | 13% |
| 半干旱 | 0% | 11% |

温带与半干旱重新划分，是因为季风/云改变了降水分布（温带不再是单一霸主）。

### 边界

- 这不是环流模型，是**三个常数级修正**；
- 季风只有「全年净值」一个系数，没有季节反转；
- 洋流只算沿岸温度偏移，不算输送带；
- 云只算「降水越多云越厚」，没有反照率反馈。
## 八、简化流体（简单环流）——2026-11-16 再追加

> 用户要求：「太糙了，简单的流体模拟总要来一点吧。」

### 开源检索结论

| 库 | 结果 |
|---|---|
| shallow-water / fluid-simulation / circulation / planet-sim | npm **404**（不存在） |
| cfd 0.1.2 | 19KB 玩具 |
| meteo 0.2.3 | 太小 |

**没有可用的 JS 大气环流库** → 自己实现「定常解」：经典三圈环流 + 热成风近似。
不是 CFD，但风的方向与量级跟着物理量变（自转、温度梯度）。

### 三步

```
1. 热成风：u ∝ −(1/f)·∂T/∂y      // f = 2Ω·sinφ
2. 三圈环流：0–30° 上升、30–60° 下沉、60–90° 上升 → 经向风
3. 水汽平流：从海洋起，内陆按半衰距离衰减
```

### 地球校核（模型给出的风场）

| 纬度 | 纬向风 | 判定 |
|---|---|---|
| 0° | **−15.0 m/s** | 东风 ✓（信风） |
| 15° | −13.9 | 东风 ✓ |
| 30° | **+9.6** | 西风 ✓ |
| 45° | +9.3 | 西风 ✓ |
| 60° | **−8.3** | 东风 ✓（极地东风） |
| 75° | −8.1 | 东风 ✓ |

三圈环流：0–45° v>0（上升/向极）、30–45° v<0（下沉/向赤道）、60–75° v>0（上升）。

### 接入气候层

| 用途 | 原来 | 现在 |
|---|---|---|
| 迎风方向 | 按纬度带固定 | **取自环流 u 符号**（东风从东来、西风从西来） |
| 内陆水汽衰减 | 固定 60 mm/格 | **半衰距离来自环流**（西风带大陆宽度 × 0.25） |

### 边界

- 不是流体求解：没有质量/动量守恒，没有时间演化；
- 风场是**定常解**（只随参数变，不随天气变）；
- 三圈环流的位置是固定的（25/60°），不随倾角/自转移动；
- 自转只改变科氏参数：**快转 f 大 → 同样温度梯度下热成风更弱**（10h 西风 3.9 m/s、24h 9.3、48h 18.7）——
  这与「快转行星风更强」的真实情况存在竞争，因为真实温差也会随输运变化，本模型未耦合。
