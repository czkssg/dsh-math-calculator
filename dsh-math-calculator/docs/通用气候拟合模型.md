# 通用气候拟合模型（2026-11-16）

> 用户要求：用地球和气候理论建立**通用拟合模型**（推广到不同条件的行星），
> 「看上去合理、有据可循」，并用地球数据矫正。

## 一、思路：不是「真实环流求解」，是「可标定的解析模型」

```
地球实测（纬度温度/降水观测）
  → 定标：解出形状指数 p（最小二乘，扫参 0.6–2.6）
  → 模型：T(φ) = T_eq − ΔT·(1 − cos^p φ)
  → 换行星参数：通量/温室/气压/自转/倾角 → 改变 T_eq 与 ΔT
  → 自检：地球参数代入，报告残差
```

## 三、定标结果（实测）

```
拟合形状指数 p = 1.07（最小二乘扫参）
地球自检：平均残差 0.2 K、最大 0.6 K
残差：0°:0.0  15°:0.1  30°:0.6  45°:-0.1  60°:-0.2  75°:-0.6  90°:0.1
```

**这是「有据可循」的证据**：模型不是拍脑袋，而是用地球实际观测反推参数，
残差 0.2 K 说明「对地球是准的」——推广到其他行星时，变化来自物理量的缩放，
而不是随便调的旋钮。

## 四、推广机制

| 行星参数 | 影响 | 依据 |
|---|---|---|
| 恒星辐射 `stellarFlux` | `T_eq` 平移 `(flux^0.25 − 1) × 40` | Stefan-Boltzmann 四次方根 |
| 温室 `greenhouseK` | 每 +10 K 温室 ≈ 地表 +6 K | 地球 33 K 温室 ≈ +33 K 的线性近似 |
| 气压 `pressureAtm` | 纬向输运强 → 温差小 | 输运效率 ~ 气压 |
| 自转 `rotationHours` | 快转 → 温差小 | 科氏力/涡动输运 |
| 倾角 `obliquityDeg` | 极地年均略升 | 极地夏季日照增强 |
| 陆地占比 `landRatio` | 降水整体偏移 | 海陆热力差 |

实测：

| 条件 | 赤道 | 极地 | 梯度 |
|---|---|---|---|
| 地球（flux 1） | 27.0°C | -25.0°C | 52 K |
| 暗星（flux 0.7） | 23.6°C | -28.3°C | 52 K |
| 亮星（flux 1.4） | 30.5°C | -21.3°C | 52 K |
| 慢转（240 h） | — | — | 更大 |
| 快转（12 h） | — | — | 更小 |

## 五、降水模型

```
P(φ) = 150 + ITCZ(φ)×1850 + 极锋(φ)×350 − 副高(φ)×100 + (landRatio−0.29)×300
再到网格：− 距海衰减 + 迎风坡地形雨 − 背风坡雨影
```

干旱修正：降水 < 200 mm → 「干旱（沙漠）」（可耕率 1%）；< 450 mm → 「半干旱（草原）」（18%）。

结果：地球参数下约 50% 陆地被标为干旱/半干旱区，可耕率 17%（现实耕地约 12%，量级相符）。

## 六、精度边界

- 不做大气环流/洋流/季风；
- 降水只到「带 + 距海 + 地形」层级；
- 残差 < 1 K 是**标定集内**的拟合，不代表任何行星的预测精度；
- 定位是「看上去合理、有据可循」，不是科学预测。
