# 发布公告 3.1.0 —— 硬核推演批次

**发布**：2026-11-16 · `dsh-math-calculator@3.1.0`
**分支**：`rewrite/v3` · **标签**：`v3.1.0`

## 一句话

从「算得准」走到「推出一个世界」：天文、封闭系统、历史推演、工程校核、优化、
系统动力学全部联通，数据存储收敛为一层，并新增全球地图与地球标定的气候模型。

## 这一版能做什么

| 能力 | operation |
|---|---|
| 全球地图（地形/河流/矿产/国家，平面或球体，可编辑） | `world-map` |
| 气候层（温度/降水/季风/洋流/云/简化环流/可耕率） | `world-map` + `climate:true` |
| 完整世界编排（骨架→承载力→人口→粮食→疆域→瓶颈） | `world-build` / `world(profile:full)` |
| 跨模块对账（同一量两处实现比对） | `crosscheck` |
| 天文（历表/轨道/双星/行星系统/引力/相对论/历法/科技） | `astro` |
| 封闭系统（避难所/温室/闭环/舱室/海绵空腔） | `topology` 规则表 |
| 工程校核 16 类（建筑/舰船/太空/机械/液压/传动/热工/电气/流体） | `topology` 规则表 |
| 历史推演（冲突→纪元→分支） | `conflict` / `history` / `diverge` |
| 优化（线性/整数规划） | `optimize` |
| 系统动力学（存量/流量） | `simulate` |
| 统一数据层（记录/版本/检索/血缘/迁移） | `data` |

## 三个「不撒谎」的保证

1. **对账**：`crosscheck` 5 项自动比对——开发过程中真抓到过 t/kg、秒/天两处口径冲突；
2. **地球标定**：气候模型对地球平均残差 0.2 K；
3. **外推边界**：太阳系验证显示类地天体误差 3–5 K，金星（92 atm）低估 119 K 并明确标 `out-of-domain`。

## 已知边界

- 气候不做真实环流求解（定常解 + 常数级修正）；
- 全球地图矿产是地质带统计分布，不是矿床模型；
| 地图精度 | 720×360（0.5°）为默认，上限 1440×720 |
