# 公式信源体系（2026-11-13）

> 用户指示（2026-11-13）：**公式库的补充不去代码的开源社区，去科学的相关网站、
> 包括文献、科普等一系列权威信源收录公式，建立体系。**

这份文档回答三件事：**从哪收**（信源分级与可达性）、**怎么收**（采集规范）、
**收什么**（体系骨架与缺口）。公式本身不进这份文档，进 `src/data/formulas.json`。

---

## 一、原则

1. **公式内容以权威信源为准**，不以代码仓库里的实现为准（代码只作交叉验证）。
2. **每条公式必须有来源**：文献名/章节 + URL + 访问日期 + 许可。
3. **来源等级决定可信度标签**：标准/官方数据 → 精确；教科书 → 标度；科普 → 量级。
4. **不编造**：抓不到的页面标注「不可达/需人工核对」，不假装读过。

## 三、许可与引用

- **OpenStax**：CC BY 4.0，可引用与改编，需署名。引用格式：作者、书名、章节、URL、访问日期。
- **NIST CODATA / DLMF**：美国政府作品，可引用；DLMF 有引用格式要求。
- **Feynman Lectures**：版权归 Caltech，可引用不可转载全文。
- **科普中国**：引用需注明来源。

## 四、采集规范（每条公式的字段）

```jsonc
{
  "id": "planck_law",                       // snake_case，全库唯一
  "cat": "physics/quantum",                 // 105 类体系中的一类
  "name": "普朗克黑体辐射谱",
  "expr": "2*h*c^2/(lambda^5*(exp(h*c/(lambda*k*T))-1))",  // mathjs 可解析
  "params": { "T": {"value": 5778, "desc": "温度 K"}, ... },
  "unit": "W/(m^3·sr)",                     // 结果单位；无量纲写「无量纲」
  "desc": "含义 + 适用域 + 常见误用",        // 必须写适用域
  "keys": ["黑体", "普朗克", "planck"],
  "sources": [
    {
      "type": "textbook",
      "title": "University Physics Volume 3",
      "authors": "Moebs, Ling, Sanny",
      "publisher": "OpenStax",
      "chapter": "第 6 章",
      "url": "https://openstax.org/books/university-physics-volume-3",
      "license": "CC BY 4.0",
      "accessed": "2026-11-13"
    }
  ],
  "confidence": "exact"                     // exact | scaling | order-of-magnitude
}
```

**硬规则**：新公式 `sources` 不得为空；`expr` 必须过 mathjs parse；
展示式必须标 `executable:false`；参数 `desc` 必须带单位。

## 七、后续采集流程（每批 10–20 条）

1. **定缺口**：按第五节的体系骨架与第七节的缺口清单选领域；
2. **取来源**：优先 OpenStax/MIT OCW 章节 + CODATA 常数；抓不到的用离线文献章节；
3. **录入**：按第四节字段写进 `formulas.json`（`sources` 必填）；
4. **校验**：`formulas-static`（parse/符号/单位/sources）+ `formulas-align`；
5. **抽验**：用默认或典型参数求值，与手算/权威值比对，差异记进 desc；
6. **记录**：批次表追加到本文；未核实的标「待核」。
