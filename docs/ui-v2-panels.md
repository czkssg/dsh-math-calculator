## 四、踩到的关键坑：通配路由抢在专用路由之前

`GET /workspaces/inherit` 一直返回一个**名为 inherit 的工作区对象**。

根因：

```ts
// 通配放在前面 —— 它把 'workspaces/inherit' 当成表名 'inherit'
if (method === 'GET' && route.startsWith('workspaces/')) {
  const name = decodeURIComponent(route.slice('workspaces/'.length))  // → 'inherit'
  const data = loadWorkspace(normalizeWorkspaceName(name))            // ← 自动创建！
  return ok(data)
}
```

而 `loadWorkspace` 对缺失的表**会自动创建**，于是：
请求「读继承链」→ 新建了一张 `inherit.json` → 返回工作区对象。

**这个 bug 特别隐蔽**：请求返回 200，没有报错，只是数据不对。
是测试里比对「应该返回 links 数组」才抓出来的。

修法：把专用 GET 路由移到通配之前，并加注释警告。
