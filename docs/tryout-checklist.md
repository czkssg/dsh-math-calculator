# 试用清单

> 重启 DSH 后按这份清单走一遍，就知道插件现在能做什么了。
> 全部用对话驱动——你只需要说需求，不用记参数名。

## 重启后先看这三个地方

1. **左侧导航**：「数学工作区」入口（order=30，靠下）
2. **右侧标签页**：「本区工作台」——常数表、公式表、地点与变量、管理、开关
3. **对话**：直接说需求，AI 会调工具

## 第一轮：让它介绍自己

```
你有什么能力？
```

预期：AI 调 `operation="help"`，列出 27 个操作。

## 第二轮：建一个世界（最常用）

```
帮我建一个重力是地球 1.5 倍、一天 40 小时的世界
```

预期：
- AI 调 `world` + `derivation → pipeline`
- 告诉你这个世界的**体感**（1.5g 下人多矮、建筑能多高）
- 告诉你 P1—P5 哪层受阻

**关键验证**：它说的数字是否具体（如「建筑上限 3177 米」），而不是含糊的「重力大会有影响」。

## 第三轮：逆推（作者最需要的）

```
我想要一只 50 米高的巨兽，这世界重力最多能是多少？
```

预期：
- AI 调 `derivation → backSolve`
- 给出「重力 ≤ 0.5 g、行星质量 ≤ 0.5 地球质量」
- 并代回正向链路确认没别的层崩掉

**关键验证**：有没有告诉你「满足它要付什么代价」，而不只是「可以」或「不可以」。

## 第四轮：文明极限

```
这个世界的文明能发展出航天吗？能建多高的楼？
```

预期：
- AI 调 `derivation → civilization`
- 给出逃逸速度、化学火箭 Δv 对比、技术树锁死/开放状态

**关键验证**：高重力世界应判「化学火箭航天锁死」，并给替代方案（核热推进等）。

## 第五轮：幻想设定（重点看措辞）

```
我要加一个灵能设定：法师能持续输出 5 千瓦。帮我算算这意味着什么。
```

预期：
- AI 调 `derivation → fantasy`
- 给出**等价现实量**：相当于 49 个人力、散热需要 49 m²、温升多少
- 然后**给建议**，而不是说「不合理」

**关键验证**（重要）：AI 有没有说「这不行/不合理」？
如果有，那是我没调好——请告诉我原话，我来修。
正确的说法应该是：「按这个功率，他会烧起来——可以给他散热装置，或者设定成短时爆发」。

## 第六轮：要一份设定集

```
把这世界整理成一份设定文档给我
```

预期：
- AI 调 `derivation → whitepaper`
- 给出四部分：物理底色 / 文明极限 / 时间尺度 / 状态判定

## 第七轮：溯源（追问）

```
那个 4903 米的建筑上限是怎么算出来的？
```

预期：AI 调 `derivation → trace`，给出依赖链：

```
建筑高度上限 ← 表面重力 ← 行星质量, 行星半径
```

## 有问题怎么反馈

告诉我就行，最好带上**AI 的原话**。我按这几类排查：

| 现象 | 可能原因 |
|---|---|
| AI 说「不合理」「不能这样」 | 提示词里「不反驳」的约束没生效 |
| 数字明显不对（数量级错） | 公式或标定有问题 |
| AI 编了个数字没调工具 | 系统提示的「必须调工具」没生效 |
| 界面不显示 / 数据表不出来 | 客户端注入或工作区绑定问题 |
| 左侧没有「数学工作区」入口 | 插件没加载（重启不够或构建过期） |
