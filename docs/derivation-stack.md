# 推演栈：架空世界的分层推演框架

> 依据用户 2026-10-24 提供的完整规格实现。核心不是「多算几个数」，
> 而是把「常数一变连锁一切」组织成**可管理的一叠层**。

## 一、结构：推演栈 + 贯穿层

### 推演栈（垂直，逐层向下）

| 层 | 名称 | 核心问题 | 下游接口数 |
|---|---|---|---|
| M0 | 元协议层 | 推演到什么分辨率？给谁看？ | 3 |
| P0 | 基本层 | 常数、对称性、初条件、边界条件？ | 2 |
| P1 | 微观有效层 | 核、原子、分子、化学是否成立？ | 6 |
| P2 | 介观材料层 | 材料、流体、热力学是否可用？ | 6 |
| P3 | 宏观体感层 | 生物力学、感知、本地单位是否成立？ | 5 |
| P4 | 行星环境层 | 地质、气候、大气、海洋是否可持续？ | 4 |
| P5 | 恒星天文层 | 恒星寿命、行星形成、辐射环境？ | 4 |
| P6 | 文明叙事层 | 技术、社会、历史是否自洽？ | 5 |

### 贯穿层（水平，横切所有层）

单位与观测者 / 不确定性与版本 / 时间与历史路径 / 约束分级

## 二、三条铁律

1. **输出不是唯一答案**：任何结论带「允许 / 边缘 / 禁止 / 待定 / 叙事选择」之一，
   外加置信度与待定项。
2. **真正追踪的是无量纲比值**：同时缩放所有质量通常只是换了单位。
3. **约束分级**：硬约束 > 核心叙事锚点 > 软约束 > 细节设定。

## 三、用法：`operation="derivation"` 八个子命令

```jsonc
{"operation":"derivation","derivation":"stack"}          // 列八层与各层接口
{"operation":"derivation","derivation":"cards"}          // 列接口卡（可加 "layer":"P3"）
{"operation":"derivation","derivation":"dimensionless"}  // 四个核心无量纲量
{"operation":"derivation","derivation":"units","unitScales":{"mass":2}}  // 单位重定义检测
{"operation":"derivation","derivation":"sensitivity","sensitivityBase":9.8,"sensitivityExponent":3}
{"operation":"derivation","derivation":"phase"}          // 重力 × 生物尺寸相图
{"operation":"derivation","derivation":"checklist"}      // 13 项检查表
{"operation":"derivation","derivation":"tables"}         // 七张表骨架
```

## 四、接口卡（规格的 10 个字段全实现）

每张卡都有：名称、定义、单位、依赖、有效范围（允许/边缘）、约束类型、
置信度、敏感度、叙事影响、备注。

内置 5 个层的卡片库（P1—P5），共 18 张，例如：

| 层 | 接口变量 | 允许区间 | 约束 |
|---|---|---|---|
| P1 | 原子尺度 | 5e-11 — 3e-10 m | 硬 |
| P1 | 键能范围 | 0.5 — 10 eV | 硬 |
| P2 | 材料强度密度比 | 1e5 — 1e7 | 硬 |
| P3 | 骨骼强度体重比 | 3 — 100 | 硬 |
| P3 | 高度大气标高比 | 1e-4 — 1e-2 | 软 |
| P4 | 大气逃逸率 | 0 — 1e3 kg/s | 硬 |
| P5 | 恒星寿命 | 1e7 — 1e11 yr | 硬 |

## 五、单位重定义检测（规格特别强调的陷阱）

```
输入 {"mass": 2}  →  判定：是单位重定义（非物理变化）
理由：只缩放了一个量纲。若无量纲比值全部不变，这只是换了单位。
```

```
输入 {"length": 2, "mass": 3}  →  判定：是真实物理变化
```

## 七、敏感性与相图

**敏感性**：对 `结果 = 输入^幂` 做 ±1% 扰动，看结论被放大几倍；
超过阈值即标「微调警告」。

**相图**：重力 × 生物尺寸 → 骨骼强度体重比，输出 7×7 网格，
每格标允许/边缘/禁止，并给统计。**不追求单点答案**。

## 八、检查表（13 项，规格原文）

量纲一致 / 单位一致 / 已无量纲化 / 极限行为合理 / 守恒律未被违反 /
稳定性边界已查 / 标度律未越界 / 反馈时间尺度已分 / 观测者已声明 /
硬约束无冲突 / 叙事锚点有反推窗口 / 待定项明确 / 版本可追溯

未填项显式标 ✗ 并注明「待填」，**不假装通过**。

## 十一、与已有模块的关系

这不是重复造轮子，而是**给已有推演能力加上框架**：

| 已有 | 新增框架后 |
|---|---|
| `feasibility`（硬约束校验） | 归入 P1—P5 的接口卡区间判定 |
| `world` / `stellar` / `climate` | 作为 P4—P5 的计算内核 |
| `constants`（常数推演） | 增加 P0 的无量纲化与单位陷阱检测 |
| `quantities`（量级估算） | 作为接口卡的快速取值 |

下一步可把 `world` 的输出自动映射到 P3—P5 的接口卡，形成端到端链路。
