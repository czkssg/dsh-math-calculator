# 幻想层：叠加式，且必须付代价

> 用户选择：**叠加式**（新量作为额外输入进入判定，保留原有物理），
> 因为一个世界可能「既有正常物理，又有灵能」——两者都要算。

## 一、叠加的数学形式

不是「灵能顶替代谢」，而是：

```
有效能力 = 物理能力 + 幻想能力
幻想能量 = (需求 - 物理能力) / 效率
总代价   = 幻想能量 × 单位成本
```

实测（法师输出 5kW，效率 0.5）：

```
需求总量：  5000
物理提供：  100       ← 保留，没有被覆盖
幻想补足：  4900
合计：      5000
幻想能量：  9800      ← 效率 0.5 意味着要付 2 倍
```

**这就是叠加式与覆盖式的区别**：覆盖式会把「物理提供的 100」丢掉，
叠加式保留了它，所以数字仍然可比。

## 二、让幻想带真实的三道关

### 关 1：必须声明来源

| 来源 | 含义 |
|---|---|
| `metabolism` | 生物自身代谢 |
| `ambient-field` | 环境场（灵能海、地脉） |
| `artifact` | 器物/装置 |
| `external` | 外部注入（神赐、外文明） |

### 关 2：必须付代价

`costPerUnit = 0` 直接被拒绝定义：

```
costPerUnit = 0：不付代价的能力会让整个推演失去意义
```

### 关 3：必须有上限 + 效率合法性

效率 > 1 且来源不是 `external` → **判禁止**：

```
效率 3.00 > 1，但来源是「生物自身代谢」——这等于凭空产生能量。
要么把效率调到 <= 1，要么把来源声明为「外部注入」。
```

改成 `external` 后立刻放行。**这让「神赐」和「作弊」有了明确的区分标准**。

## 三、代价核算：让幻想数字可比较

这是「幻想带真实」的核心。不说「他很强」，而说：

```
等价人力：49 人      ← 按 100W 持续输出
等价食物：3.06e-4 kg 糖/秒
散热需求：49.00 m²   ← 按 100W/m² 散热能力
```

然后立刻暴露问题：

```
散热需要 49.00 m² 表面积，但施术者只有 1.80 m²——超出 27.2 倍，
体温会升 262.2 K。
这是「为什么强力施术者会烧起来」的物理原因。
```

**这一句就是幻想带真实的价值**：它不是禁止你写强力法师，
而是告诉你「强力法师会烧起来」——于是你会写他需要散热装置、
需要水冷、需要分段施法。故事因此变得可信。

## 四、实测四个案例

| 案例 | 判定 | 关键结论 |
|---|---|---|
| 法师 5kW，效率 0.5 | 边缘 | 需 49 m² 散热面，只有 1.8 m² → 体温升 262 K |
| 效率 3 倍，来源=代谢 | **禁止** | 等于凭空产生能量 |
| 同上但来源=外部注入 | 允许 | 来源合法即放行 |
| 无代价魔法 | 拒绝定义 | 不付代价就没有真实感 |

## 五、与 50 米巨兽的关系

顺手算了一笔账，结论有点反直觉：

```
50m 巨兽（等比放大自 3m 大象）：
  质量      2.31e7 kg
  腿部应力  9.08e6 Pa   ← 骨骼强度 130e6 Pa，还有 14.3 倍余量
  散热恶化  16.7 倍     ← 这才是真问题
```

所以「50 米巨兽站不住」的传统说法，在纯骨骼强度上其实**站得住**。
真正的硬约束是**散热**——体积按 L³ 涨、表面积按 L² 涨，产热/散热比恶化 16.7 倍。

这意味着：如果你要写 50 米巨兽，需要的不是「更强的骨骼」，
而是「更好的散热方案」（水生、低温、低代谢、或者……灵能辅助散热）。
