# 补丁8：白皮书与 Prompt 投射

> 方案原文：生成结构化的「物理与文明白皮书」长文档（供人阅读）；
> 一键转化为结构化的「AI 系统提示词」，把重力、材料极限压缩成直接可用的 Prompt。

## 一、两个产物，两个用途

| 产物 | 给谁看 | 体量 | 形式 |
|---|---|---|---|
| **白皮书** | 人 | 943 字符 | 结构化 Markdown，能直接当设定集 |
| **Prompt 卡片** | AI | 283 字符 | 压缩设定卡，可直接注入对话 |

## 二、白皮书结构（四部分）

```
# 世界物理与文明白皮书

## 一、物理底色
| 表面重力 | 9.82 m/s²（地球的 1.00 倍） |
| 一天时长 | 23.9 小时 |
| 全球均温 | 287 K |
| 海平面气压 | 1.00 atm |
| 恒星寿命 | 10.0 Gyr |

## 二、文明极限
### 能量
- 行星接收总功率：1.74e+17 W
- 卡尔达肖夫指数：0.7204
### 材料
- 建筑高度上限：4903 m
- 太空电梯材料缺口倍数：10200 倍
### 交通
- 第一宇宙速度：7910 m/s
- 化学火箭 Δv 上限：13480 m/s
### 生态与科技
- 生态承载力：65.4 亿人
- 技术开放：化学火箭航天、摩天建筑、大气飞行、燃烧/冶金
- 技术锁死：太空电梯

## 三、时间尺度
- 可居住年限：40 亿年
- 历史临界点：4.0 Gyr 湿润温室 / 6.9 Gyr 地质死寂 / 10.0 Gyr 离开主序

## 四、状态判定
- 宇宙状态：alive

**注意**：以上是物理约束，不是叙事判决。
```

## 三、Prompt 卡片（更实用）

**地球**：

```
【世界设定卡】
表面重力为地球的 1.00 倍、一天 24 小时、1.00 M☉ 的主序星 的世界。

硬参数：重力 9.82 m/s²（1.00 g）；一天 23.9 小时；均温 287 K；气压 1.00 atm；宜居带 0.95—1.67 AU

可以做：化学火箭航天、摩天建筑、大气飞行、燃烧/冶金
做不到：太空电梯
生态可承载 65.4 亿人

注意：
- 这个世界的 太空电梯 被物理锁死——若要写相关情节，需要给出替代技术或外部输入
- 可居住年限 40 亿年，之后会发生不可逆的环境转变

（以上是物理约束。怎么写成故事由你决定，不要把它们当禁令。）
```

**高重力超级地球（1.55 g）——差异立刻可见**：

```
可以做：摩天建筑、大气飞行、燃烧/冶金
做不到：化学火箭航天、太空电梯

注意：
- 这个世界的 化学火箭航天 被物理锁死——若要写相关情节，需要给出替代技术或外部输入
```

**这一句就是作者能直接拿去写的**：高重力世界飞不出行星，
所以那个文明要么发展核热推进，要么永远困在地表。

## 四、设计原则：只输出确定性事实

白皮书里**没有一句叙事**：没有「这支文明的史诗开始了」，
只有「表面重力 1.6 g，化学火箭 Δv 是逃逸速度的 0.97 倍，飞不出去」。

这是「确定性底座 + AI 开放层」的延续：

| 插件输出 | AI 输出 |
|---|---|
| 数值、判定、边界 | 叙事、描写、氛围 |

## 五、用法

```jsonc
{"operation":"derivation","derivation":"whitepaper"}                          // 白皮书
{"operation":"derivation","derivation":"whitepaper","whitepaperMode":"prompt"} // Prompt 卡片
{"operation":"derivation","derivation":"whitepaper","whitepaperMode":"prompt","world":{"planetMass":5,"planetRadius":1.8}}
```
