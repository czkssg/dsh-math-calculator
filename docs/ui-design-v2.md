# 第一部：核心约束与UI映射原则（“一区一表”强绑定）

在DSH中，“工作区（Workspace）”是用户进行项目隔离的顶层容器，“会话（Session）”依附于工作区。本插件的核心逻辑：**一个DSH工作区 ↔ 绝对绑定 ↔ 唯一一个数据表（宇宙规则库）**。

## 1.1 自动创建 (Auto-create) 流程
*   **场景**：用户新建了一个DSH工作区（如命名为“硅基文明探索”），此时该工作区为空。
*   **触发**：用户在右侧边栏点击【⚙️ 推演控制台】入口，或在左侧全局面板点击【进入当前工作区】。
*   **UI反馈**：右侧控制台不显示任何推演目录，而是弹出一个**【宇宙初始化引擎】**卡片，提示：“检测到当前工作区尚未绑定物理规则。系统将自动为您创建专属数据表《硅基文明探索》”。提供【立即生成】与【导入已有表】两个按钮。
*   **行为**：点击生成后，系统自动在后台创建该数据表，并初始化常数表、空公式库。同时，在左侧全局列表的【绑定状态】列，自动将“硅基文明探索”打上已绑定的绿勾。

## 1.2 自动切换 (Auto-switch) 流程
*   **场景**：用户在DSH左侧原生侧边栏，从“工作区A”点击切换到“工作区B”。
*   **触发**：工作区焦点发生变更。
*   **UI反馈（右侧边栏）**：右侧的【推演控制台】瞬间刷新。顶部状态栏立刻从“当前绑定：表A”变为“当前绑定：表B”。目录树、常数表、图表数据全部自动重载，**无任何数据污染**。
*   **UI反馈（左侧全局列表）**：左侧全局面板中，对应工作区“表B”所在的行自动高亮。

## 1.3 解除/重绑与克隆
*   在左侧全局面板，每张数据表有【绑定工作区】操作。用户可将工作区A的表解绑，再与其他表绑定。若强行将一张已被工作区A绑定的表，绑定到工作区B，系统要求用户确认是否【克隆并绑定】（触发A/B平行宇宙机制）或【直接替换】。

# 第二部：左侧全局入口 (Global Entry) 详细UI设计

点击DSH左侧原生侧边栏的【🌐 世界观数据工作区】，主区域（Main）展开全局面板。

## 2.1 数据表列表与工作区状态联动
*   **表头**：表名、推演级别（硬自洽/区域级）、创建时间、**绑定工作区**（显示绑定的DSH工作区名称或“未绑定”）、状态（正常/有待定项/硬约束破裂）。
*   **视觉表现**：当前正在被活跃工作区绑定的数据表，整行背景带有淡蓝色高亮，并显示【运行中】的动效标签。

## 2.2 生命周期管理与补丁功能
*   **CRUD操作**：【新建数据表】、【复制】、【重命名】、【删除】。
*   **【补丁9：数据表继承】**：选中一张表点击【创建衍生表】。系统区分出【基线表】（锁定基础常数，如精细结构常数）与【衍生表】（继承基线，仅覆写初条件）。基线表被修改时，全局面板弹窗警告所有衍生表并触发联动重算。
*   **【补丁3：A/B双盲对比】**：用户选中两张表（如“表A”与“表A-衍生”）点击对比。主区域分屏展示Diff报告：红色标记破产科技树与毁灭结语，绿色标记新生物理现象。支持一键导出对比报告。

## 2.3 全局引擎设置 (Global Settings)
*   **计算精度限制**：浮点运算位数（8-16位，默认8）。
*   **无量纲判定容差率**：输入阈值（默认1e-6）。
*   **DAG节点上限**：防卡死限制（默认500节点）。
*   **【补丁5：算力熔断预警】**：开启后，当推演耗时预估超限，强制弹窗提示降级采样。
*   **【补丁13：混沌系统拦截器】**：开启后，识别非线性敏感系统，拒绝给出单一确定数值，强制返回概率云区间。

# 第三部：右侧会话直管入口 (Session Rightbar) 详细UI设计

右侧边栏（Rightbar）是用户会话内的直接操作台。顶部Tab区新增【⚙️ 推演控制台】。

## 3.1 顶部状态栏（强绑定UI显现）
*   **左侧**：显示图标【Table】与当前绑定的数据表名称，如“《硅基文明探索》”。
*   **右侧**：【⚙️ 快速设置】按钮（可调单表私有的快慢变量解耦开关、传播容错率）、【🔍 全局搜索】（搜常数、公式、节点）、【🔄 重算当前表】按钮。
*   **未绑定状态下**：顶部显示黄色警告条“当前工作区未绑定宇宙规则”，并展示【自动创建】与【选择已有表】的引导按钮。

## 3.2 左侧分级目录树（极尽详细）
目录树分为6大折叠模块，用户点击节点，右侧直管内容区随之切换。

### 📁 目录1：基础物理法则 (Fundamental Laws)
*   **1.1 常数表 (Constant Table)**
    *   **直管区UI**：
        *   **区块A【无量纲池】**：展示α、质量比等。**【补丁：防呆】**修改时若差值小于容差率，红框拦截并弹窗“单位重定义陷阱”，提供【一键分离】按钮。
        *   **区块B【基本常数】**：c、G、ħ等。行级下拉框强制选择【显式追踪/吸收/冻结】。
        *   **区块C【对称性与粒子谱】**：粒子的增删与破缺机制开关。
        *   **区块D【有效参数输出】**：置灰只读，实时更新玻尔半径、键能范围。
*   **1.2 公式库 (Formula Library)**
    *   **直管区UI**：搜索框+卡片流。卡片分四类（无量纲、跨层、宏观标度律、传播算法）。
    *   **【补丁12：标度律防越界】**：所有标度律卡片顶部有红色Tag【适用域边界】，越界输入时公式结果处显示“❌ 越界”。点击卡片上的【绑定到DAG】可将公式投入主区画布。
*   **1.3 变更与降维清单**
    *   **直管区UI**：表格展示五类变更。包含原值、新值区间、变化时期，以及强制的【处理策略】下拉框。顶部提示“请勿无限下钻，注意接口粗粒化”。
*   **1.4 单位与观测基准**
    *   **直管区UI**：设定本地光速、跃迁等基准。顶部提供【观测者切换】下拉框（人类/本地智慧生物/二维生物）。
    *   **【补丁7：观测者过滤】**：切换后，体感参数（如骨骼承重）实时重算；不适用于该观测者的公式和文明拓扑选项自动置灰隐藏。

### 📁 目录2：物理链路引擎 (Physics Engine)
*   **2.1 跨层依赖图 (DAG Canvas)**
    *   **UI交互**：点击此项，右侧面板保留，**DSH主区域（对话框上方）展开全屏DAG画布**。
    *   **渲染**：节点边框粗细对应置信度，颜色对应硬软约束。连线带正负号、快慢变量时间轴、阈值标识（菱形）、反馈环（回环）。
    *   **右键菜单**：【前向区间传播】（越界节点红线狂闪）与【后向需求传播】（从文明极限反推）。
    *   **【补丁4：因果溯源】**：在节点上点击【溯源】按钮，主画布逆向发光，展示该节点如何从最底层物理常数一步步传导上来的面包屑路径。
*   **2.2 接口卡矩阵 (Interface Matrix)**
    *   **直管区UI**：分层手风琴（P1-P2, P2-P3等）。强制限制每层≤12个变量。每个接口卡展示10项元数据。信息不完整的强制打上黄色【待定】标签。
*   **2.3 演化时间轴**
    *   **直管区UI**：一个顶部时间滑块。
    *   **【补丁1：时间维度】**：拖动滑块，快变量（大气等）瞬间给出平衡态，慢变量（恒星、地质）动态演化。
    *   **【补丁11：蝴蝶效应锁】**：推演过程中跨越设定的“历史临界点”时，滑块变红，强制弹窗“路径已锁定，无法回退”，且下游历史走向分支切换重写。

### 📁 目录3：生命与生态物理基质 (Biological Substrate)
*   **3.1 生物物理约束**
    *   **直管区UI**：**【补丁2：生物基质】**基于当前键能自动推导生命形式（碳/硅）。输出其神经传导速度上限（思维瓶颈）与代谢散热极限（体型瓶颈）。
*   **3.2 生态热力学矩阵**
    *   **直管区UI**：**【补丁10：能量金字塔】**展示光化学转换率与食物链能量损耗。计算行星生态承载力。
    *   **联动报警**：当目录4的文明人口需求超出此承载力时，此项报告“生态崩溃，文明灭绝”红线错误。

### 📁 目录4：宏观文明推演 (Macro-Civilization)
*   **4.1 能量与热力学极限**：可用能密度、文明卡诺极限。输出是否会因废热导致母星失控的结论。
*   **4.2 材料与结构极限**：结合介观材料，输出建筑最大高度、太空电梯比强度要求、地壳承压。配有一键【溯源】。
*   **4.3 空间与交通尺度**：载具速度上限、引力逃离成本（Δv）、星际航行最小耗时。
*   **4.4 技术树与社会拓扑**：展示被物理常数锁死的科技分支（红色），放开的（绿色）。输出极限人口与城市分布拓扑。

### 📁 目录5：校验与分析引擎 (Validation & Analysis)
*   **5.1 硬约束监控**：实时的红绿灯Dashboard。
    *   **【补丁6：死寂态兜底】**：若原子无法稳定，除常数表外的所有面板灰化，弹窗定性结语（如“夸克汤宇宙”）。
*   **5.2 敏感性与相图**
    *   **UI交互**：点击后在主区域展示二维热力图（绿/黄/红）。鼠标悬浮显示状态。
    *   **微调警告**：若当前参数落在极窄区间，右上角弹黄条【微调警告】，建议提供备选叙事。
*   **5.3 待定项看板**：所有 `isPending` 状态的数据强行使显，严禁强行闭合。

### 📁 目录6：输出与归档 (Archive & Output)
*   **6.1 七张表导出**：一键打包导出项目卡、变更清单、接口卡、约束表、敏感性表、文明推演表、版本记录。
*   **6.2 13项完整性检查**：全项体检（量纲、标度律越界、观测者声明等），未通过项标红并定位。
*   **【补丁8：白皮书与AI投射】**
    *   **生成白皮书**：整合物理限制与文明拓扑，输出人类可读的结构化文档。
    *   **一键投喂（AI Prompt）**：将当前数据表的硬核规则转化为 `Lorebook / System Prompt` 文本，直接复制贴入当前DSH会话，AI立刻遵循此物理逻辑进行创作或答疑。

# 第四部：会话流与推演系统的闭环联动

*   **AI工具卡片**：在DSH聊天中，用户问“这个世界的建筑最高能建多高？” AI后台计算后，在对话流中返回一个**原生DSH工具卡片**，卡片显示“核心结论：150米。状态：受限于P2材料强度”。卡片底部有按钮【在控制台查看因果链】，点击后右侧面板自动展开【目录4.2】，并在主区DAG画布高亮溯源路径。
*   **实时涟漪提示**：用户在右侧【1.1 常数表】修改引力常数。右侧面板顶端弹出Toast提示“已触发重算”。主区画布（如果已打开）相关节点闪烁。如果硬约束破坏，【目录5.1】亮红灯。
*   **UI不割裂**：用户可以在右侧边栏翻看常数表，同时主区正在与AI进行自然语言对话，AI在后台感知常数表的变化并更新回答策略。
