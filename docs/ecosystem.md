# 目录3.2：生态热力学金字塔 + 指令集可配置化

## 一、能量是怎么一路损耗到文明的

```
恒星辐射
  ↓ 光合作用（约 1.5% 转成生物量化学能）
初级生产量 NPP（kg C/yr）
  ↓ 人类可占用（约 10%）
可用碳质量
  ↓ 除以含碳率 45% → 干有机物质量
  ↓ 乘以热值 1.8e7 J/kg → 能量
食物能量
  ↓ 每多一级肉食，再打 10% 折扣
可供养人口
```

## 二、10% 定律（实测）

| 营养级 | 剩余能量 |
|---|---|
| 生产者 | 100% |
| 初级消费者 | 10% |
| 次级消费者 | 1% |
| 三级消费者 | 0.1% |

**所以「吃素能养活更多人」不是道德说教，是热力学。** 实测：

```
全素食承载力   4.15e+11
全肉食承载力   4.15e+10    ← 正好差 10 倍
```

## 三、踩到两个单位坑（都值得记）

### 坑 1：辐射能 ≠ 碳质量

第一版直接 `辐射能 × 光合效率` 当 NPP，算出 **5.7e22 kg C/yr**——
比地球实际值高 **8 个数量级**。

原因：光合效率产出的是**化学能（J）**，要除以干物质热值（1.8e7 J/kg）才是质量。

### 坑 2：kg C ≠ 食物质量

修完坑 1 后，NPP 对了（3.17e15），但承载力只有 **8504 人**——又低了 8 个数量级。

原因：`kg C` 是**碳质量**，干有机物只含 45% 碳。要先除以 0.45 换成干重，
再乘热值。

### 修完的结果

| 指标 | 值 | 现实对比 |
|---|---|---|
| NPP | 3.17e15 kg C/yr | 地球约 1e14—1e15 ✓ |
| 承载力 | **3.4e11 人（3400 亿）** | 现实 80 亿 |

承载力的差异（40 倍）来自：浪费、分配损耗、非食物用途、肉食比例。
**量级正确，模型可用。**

## 四、第三个坑：字段名写错导致参数完全失效

`world` 输出的轨道字段是 `semiMajorAxisAU`，我写成了 `semiMajorAU`。
结果：**远轨道与近轨道算出完全相同的承载力**——远程参数静默失效。

测试里专门有一条守着（「远轨道承载力更低」），就是它抓出来的。

## 五、文明过载判定（措辞延续不反驳）

```
地球 80 亿人：可持续 —— 生态承载 3400 亿，占用 8%

假设 500 亿人：过载
  · 超出 5 倍：必须靠外部输入（进口、合成食物、或掠夺其它区域）
  · 或者这个文明本来就建立在「生态已经崩溃」之后——那也是一种设定
  · 降低人口、缩小肉食比例、提高光合效率都能缓解
```

**第三条就是关键**：不判死刑，而是把「生态崩溃」变成一个**可以写的设定**。

## 六、与文明层的衔接

`civilization` 现在多了一项极限：

```
生态承载力  3.4e11 人
  依据：初级生产量 × 人类可占用 10% × 收获效率 10%，肉食部分再打 10% 折扣
  敏感于：恒星光度 / 轨道距离 / 肉食比例 / 农业效率
```

这就是目录3.2 与目录4 的连接点：**生态给上限，文明定需求，两者相除就是可持续性。**

## 七、指令集可配置化

新增 `PlaybookConfig`，存在工作区里，用户可以改：

| 字段 | 作用 |
|---|---|
| `extraHardConstraints` | 追加自己的硬约束 |
| `extraSoftConstraints` | 追加软约束 |
| `extraNarrative` | 追加叙事选择（如「要有龙」） |
| `customWorkflow` | **整批替换**默认 11 步工作流 |
| `disabledCapabilities` | 关掉不需要的能力说明（缩短提示词） |
| `extraDuties` | 追加 AI 职责 |

实测：追加「要有龙」→ 出现在叙事选择；关掉 `world` → 能力从 12 项降到 11 项；
自定义工作流 → 整批替换成 1 步。
