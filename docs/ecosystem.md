# 目录3.2：生态热力学金字塔（重写版）

> 用户指出：**数量级太离谱**。重写后先标定地球，再推别的世界。

## 一、旧版错在哪

旧版用 `photosyntheticEfficiency = 0.015`（**1.5%**）——那是**叶片峰值效率**。

全球实际值只有约 **0.11%**，差 13 倍。因为要乘一堆折扣：

| 折扣项 | 系数 | 说明 |
|---|---|---|
| 光合有效辐射 PAR | 0.45 | 只有 400—700 nm 能被利用 |
| 陆地+海洋覆盖 | 0.30 | 沙漠、冰盖、深海透光层以下不产 |
| 季节与昼夜 | 0.50 | 夜半、冬季近乎为零 |
| 云层与反射 | 0.70 | 云遮挡与叶面反射 |
| 光呼吸与呼吸消耗 | 0.50 | 植物自己也要呼吸 |
| 叶片饱和与光抑制 | 0.60 | 强光下效率反而下降 |

**旧版结果：3400 亿人口（实况 80 亿，高 42 倍）。**

## 二、正确做法：用地球实测值标定

不猜那些折扣系数（每项都要猜，误差会累积）。改用：

```
NPP = 地球实测 NPP × (行星吸收能量 / 地球吸收能量)
```

| 常量 | 值 | 来源 |
|---|---|---|
| 地球 NPP | 1.05e14 kg C/yr | 全球实测（约 105 Pg C/yr） |
| 地球吸收能量 | 3.8e24 J/yr | 由 L☉、轨道、反照率算出 |
| 含碳率 | 0.45 | 干有机物含碳比例 |
| 热值 | 1.8e7 J/kg | 干物质能量密度 |
| 现实折扣 | 0.58 | 由地球实况反推（理论 113 亿 vs 实际 80 亿） |

## 三、标定验证（关键）

```
地球 NPP:      1.05e14 kg C/yr   ← 与实况 1.05e14 精确相等（误差 < 1e-9）
理论承载力:    112.8 亿
现实承载力:    65.4 亿           ← 实况 80 亿，0.82 倍
```

**从 42 倍偏差降到 0.82 倍。**

## 六、第三个坑（前一版就踩过，这次守住了）

`world` 输出的轨道字段是 `semiMajorAxisAU`，不是 `semiMajorAU`。
写错会让**远轨道与近轨道算出完全相同的承载力**——参数静默失效。

测试里专门有一条守着（「远轨道承载力更低」，并要求差距 > 3 倍），
这次实测 8.2 倍，说明轨道真的在起作用。
