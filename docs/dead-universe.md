# 补丁6：宇宙死寂态兜底

> 方案原文：「若常数导致原子无法稳定，右侧除常数表外的所有面板全部灰化锁定，
> 输出定性结语（如『宇宙退化为夸克汤』）。」

## 一、关键设计：死寂不是错误，是设定结果

延续你的定位（插件圆世界观，不反驳），这里的措辞刻意避开了评判：

| 不说 | 而说 |
|---|---|
| 你这个设定错了 | 按当前参数，这个宇宙里长不出常规物质 |
| 必须改 | 若你想要物质世界，往这个方向调 |
| 禁止这样写 | 死寂宇宙本身可以是一个设定 |

测试里专门守着这一条：输出**不含「错误」「禁止」「必须」**，
且必须包含「不是说设定错了」和「也是一种写法」。

## 二、判定顺序（从最底层往上）

| # | 检查项 | 判据 | 死寂等级 |
|---|---|---|---|
| ① | 化学键窗口 | 键能过弱（热扰动即断）/ 过强（无选择性） | 弱=死寂 |
| ② | 溶剂窗口 | 地表均温 < 冰点 / > 沸点 | 死寂 |
| ③ | 恒星寿命 | 主序寿命 < 0.1 Gyr | 边缘 |
| ④ | 核稳定性 | α > 3 倍现实（重核无法束缚） | 死寂 |

## 三、每条原因给四样东西

1. **物理依据** —— 为什么致命
2. **定性结语** —— 一句能直接放进小说的话
3. **挽救方向** —— 想保留物质世界该怎么调
4. **灰化标志** —— 是否建议锁死下游面板

### 实测：远轨道冻结

```
【致命原因】
  · 全球冻结（180 K，冰点 273 K）
    物理依据：地表均温低于溶剂冰点，没有液态介质
    定性结语：海洋是一整块冰，化学反应只能以极慢的固相扩散进行。
    若想要物质世界：提高温室效应、拉近轨道、或提高恒星光度

【下游面板建议】灰化锁定——生命、生态、文明部分在此宇宙中无对象。

注：这不是说设定错了。死寂宇宙本身可以是一个设定：
    「这个世界只有等离子体，文明以电磁形式存在」也是一种写法。
    若你想要的其实是普通物质世界，按每条的「若想要物质世界」调即可。
```

## 四、定性结语库（可直接抄进小说）

| 原因 | 结语 |
|---|---|
| 化学键过弱 | 这个宇宙里分子一形成就被热运动打散，只有单个原子在飘。 |
| 化学键过强 | 原子只会紧紧抱住彼此，没有任何反应能改写它们。 |
| 全球冻结 | 海洋是一整块冰，化学反应只能以极慢的固相扩散进行。 |
| 全球沸腾 | 海洋被蒸干，剩下一层高压蒸汽与干裂的岩石。 |
| 恒星寿命过短 | 这个世界的太阳在行星冷却之前就烧完了。 |
| 核不稳定 | 这个宇宙里只造得出氢和氦，没有碳，也就没有化学。 |

这些句子是给作者用的素材，不是给插件的判决书。
