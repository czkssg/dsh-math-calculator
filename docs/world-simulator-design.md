# 第一部：产品定位与宏观架构设计

## 1.1 产品定位
本系统是一个部署在DSH中的、剥离一切感性叙事与具体人物的**硬核科研级世界模拟器**。它只关注：物理常数的微调如何引发多尺度的连锁反应，以及该物理规则将如何锁死或放开一个宏观文明的技术路径与热力学极限。

## 1.2 界面层级与视图流转（业务视角）
系统仅在DSH左侧原生导航区注册一个唯一入口：**【世界观数据工作区】**。点击后，主区域按以下三个层级流转：
*   **层级一：全局数据管理面板**。管理所有世界观数据表（创建、复制、继承、删除、平行宇宙对比）。
*   **层级二：单表推演工作区**。点击某张表进入。工作区内部采用经典的“左侧分级目录树 + 右侧直管内容区”布局。不同数据表之间数据严格隔离。
*   **层级三：内容直管区**。点击左侧目录树的不同节点，右侧呈现对应的常数表单、因果依赖网络、宏观文明图表或校验报警面板。

# 第二部：全局系统（插件级）设置与管理

此层级的数据与设置，作用于所有数据表，属于宇宙创世的“母机”参数。

## 2.1 数据表生命周期管理（CRUD与继承）
*   **创建/删除/重命名/复制**：常规数据表操作。复制操作会连同常数、公式、推演记录完美克隆。
*   **【高价值补丁：数据表继承机制】**：支持建立【基线表】（仅含P0-P2基础物理常数与公式）与【衍生表】。衍生表只读继承基线表的物理基石，允许覆写初条件。若修改基线表常数，所有衍生表自动接收更新并重算文明分支。
*   **【高价值补丁：A/B双盲对比（Diff视图）】**：选择两张数据表（如“原始宇宙”与“扰动宇宙”）并排对比。系统输出Diff报告：红色标出因常数变动导致破产的科技树，绿色标出新生的物理现象与极限人口差异。

## 2.2 全局引擎精度与安全设置
*   **计算精度限制**：设定浮点运算保留位数（默认8位，最高16位）。
*   **无量纲判定容差率**：判定“单位重定义”与“真实物理变化”的差异阈值（如1e-6）。
*   **推演算力熔断预警**：若判定某一高精度全域切片计算耗时超限，强制弹窗警告，并提供降级计算（自适应网格采样）选项。
*   **DAG节点上限**：限制单表依赖图最大节点数（如500），防止无限下钻。
*   **【高价值补丁：混沌系统拦截器】**：当系统评估某非线性系统（如大气涡流、三体轨道）的Lyapunov指数超限时，停止给出确定数值，强制输出概率云区间，防止算力雪崩与结果失真。

# 第三部：单表推演工作区（分级目录与核心模块）

左侧目录树严格遵循“物理规则→因果传导→生命基质→文明输出”的推演逻辑，分为六大一级目录。

## 📁 目录1：基础物理法则 (Fundamental Laws)
**定位**：一切推演的起点，定义宇宙底色。

### 📄 1.1 常数表 (Constant Table)
右侧直管区呈现四大区块：
*   **区块A：无量纲参数池**。输入精细结构常数α、质子电子质量比等。**防呆机制**：若用户修改后，系统检测其差异小于全局容差率，判定为“纯单位缩放”，弹出【单位重定义陷阱】警告并阻断修改，提供一键分离。
*   **区块B：基本常数设定**。输入c、G、ħ等。每个常数修改必须绑定处理策略：【显式追踪】、【有效参数吸收】、【冻结为边界条件】。
*   **区块C：对称性与粒子谱**。设定破缺机制与基础粒子。
*   **区块D：有效参数输出**。系统自动计算玻尔半径、键能范围，作为下游输入（只读）。

### 📄 1.2 公式库 (Formula Library)
*   **业务**：展示无量纲化、跨层转换、宏观标度律等公式卡片。
*   **防呆**：所有标度律卡片强制高亮【适用域边界】。下游参数越界时，公式拒绝计算并抛错（防标度律越界）。

### 📄 1.3 变更与降维清单
*   **业务**：记录常数、对称性、粒子谱、初条件、历史路径的五类变更。强制选择处理策略，限制无限下钻。

### 📄 1.4 单位与观测基准
*   **业务**：设定本地基准（光速/跃迁等）。**【高价值补丁：观测者物理过滤】**——切换观测者（人类/本地/二维生物等）不仅改变标签，更自动禁用不适用的公式与文明拓扑选项，并重算体感参数（人择选择效应）。

## 📁 目录2：物理链路引擎 (Physics Engine)
**定位**：展现常数如何层层传导至宏观环境。

### 📄 2.1 跨层依赖图 (DAG Canvas)
*   **业务**：可视化网络图。节点带置信度与硬/软约束标识。连线带正负影响、快慢变量时间尺度、阈值与反馈环。支持右键触发**前向区间传播**（求交集）与**后向需求传播**（极限反推）。越界节点红线闪烁。
*   **【高价值补丁：因果溯源】**：点击任一宏观节点，逆向高亮其底层依赖路径（面包屑导航），解决节点爆炸时的迷失问题。

### 📄 2.2 接口卡矩阵 (Interface Matrix)
*   **业务**：分层（P1→P2...）展示变量包。每层严格限制≤12个变量，每个含10项元数据（含置信度）。信息不足强制标记为【待定】。

### 📄 2.3 演化时间轴（动态推演）
*   **【高价值补丁：时间维度】**：拖拽时间滑块。快变量（如大气环流）代数求平衡态，慢变量（如恒星演化、地质衰减）动态更新。
*   **【高价值补丁：路径依赖与蝴蝶效应锁】**：时间轴设“历史临界点”。若参数微调跨越临界点，锁定后续路径（如早期微扰导致走向地下城而非太空），重写历史走向。

## 📁 目录3：生命与生态物理基质 (Biological Substrate)
**定位**：剔除人物，但必须定义文明的物理承载物。

### 📄 3.1 生物物理约束
*   **【高价值补丁：生物基质限制】**：系统基于键能与原子半径，输出生命最可能的形式（碳基/硅基等）。强制推演其神经传导速度（思维上限）、代谢率与散热方式（体型上限）。

### 📄 3.2 生态热力学矩阵
*   **【高价值补丁：能量金字塔】**：计算光化学效率、食物链热力学损耗。输出行星生态承载力。若未来文明需求超过底座，报错“生态崩溃，文明灭绝”。

## 📁 目录4：宏观文明推演 (Macro-Civilization)
**定位**：纯物理规则锁死或放开的文明极限（无故事）。

### 📄 4.1 能量与热力学极限
*   可用能密度、文明卡诺极限、散热天花板（会不会因废热自毁）。

### 📄 4.2 材料与结构极限
*   基于介观材料屈服强度，计算建筑极限高度、太空电梯可行性。

### 📄 4.3 空间与交通尺度
*   载具速度上限、引力逃离成本（Δv）、星际航行最小耗时。

### 📄 4.4 技术树与社会拓扑
*   展示被锁死（红）或放开（绿）的科技分支。输出极限人口承载力与城市拓扑分布。

## 📁 目录5：校验与分析引擎 (Validation & Analysis)
**定位**：系统底线的守门员。

*   **📄 5.1 硬约束监控**：原子稳定性、碳氧窗口、恒星寿命、大气逃逸阈值的实时红绿灯。
    *   **【高价值补丁：宇宙死寂态兜底】**：若常数导致原子无法稳定，右侧除常数表外的所有面板全部灰化锁定，输出定性结语（如“宇宙退化为夸克汤”）。
*   **📄 5.2 敏感性与相图**：二维热力图（绿/黄/红）。极窄区间触发【微调警告】。
*   **📄 5.3 待定项看板**：显式列出 `isPending` 的数据，**严禁强行闭合**。

## 📁 目录6：输出与归档 (Archive & Output)
*   **📄 6.1 固定七张表导出**：项目卡、变更清单、接口卡、约束表、敏感性表、文明推演表、版本记录。
*   **📄 6.2 13项完整性检查**：量纲、守恒律、标度律越界、观测者声明等全量核对。
*   **📄 6.3 版本树**：历史推演快照与回滚。
*   **【高价值补丁：白皮书与AI投射】**：
    *   生成结构化的**【物理与文明白皮书】**长文档（供人阅读）。
    *   一键转化为结构化的**【AI系统提示词（Lorebook/System Prompt）】**。将重力、材料极限压缩成直接可用的Prompt，无缝衔接AI创作。

# 第四部：底层引擎逻辑与状态流转（AI业务处理规范）

AI在后台执行时，必须遵循以下严格规则：

1.  **单位剥离与校验**：拦截无效单位缩放，提取真实物理变动。
2.  **区间与需求求解**：正推求交集，逆推求允许窗口，无交集则硬冲突报错。
3.  **冲突仲裁机制**：优先级 = 硬约束 > 核心推演需求 > 软约束 > 细节。冲突不可调和时，禁止伪造，强制输出待定。
4.  **下钻终止判定**：新增节点不再影响硬约束和文明顶层结论时，自动触发停止。
5.  **强制不闭合原则**：对于置信度低或混沌系统拦截器拦截的参数，必须标记为“待定项/概率云”，绝不允许AI自适应脑补数字。
