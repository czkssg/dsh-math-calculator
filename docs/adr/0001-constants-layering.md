# ADR-0001：常数分层与推演起点（dimensionless-first）

- 状态：提议（待确认）
- 日期：2026-10-22
- 决策者：用户 + agent

## 背景

用户指出：架空世界改了物理常数后，现有推演仍大量依赖地球标定的经验公式，因此结论不可信。

审计（2026-10-22，统计各模块中与地球相关的注释/字面量）：

| 模块 | 地球相关行数 | 主要地球标定值 |
|---|---|---|
| `world.ts` | 51 | 花岗岩抗压 1.3e8 Pa、岩石密度 2700、气温直减率 6.5 K/km、反照率 0.306、温室 33 K |
| `climate.ts` | 31 | 海洋热惯性 0.45、大气输运阻尼、季节振幅标定 |
| `feasibility.ts` | 32 | 生物体型/建筑高度上限等经验阈值 |
| `moons.ts` | 7 | 潮汐锁定 0.5 Gyr 标定、洛希流体系数 2.44、间距判据 3.5 |
| `sky.ts` | 1 | 瑞利光学厚度 τ₅₅₀=0.10、全天星数 9100、满月照度 0.25 lux |

更根本的问题：`constants-graph.ts` 现有 20 个「基础旋钮」——c、G、h、kB、e、mₑ、mₚ、N_A、ε₀——**绝大多数是有量纲常数**。单独改它们（保持无量纲比值不变）只是换了一套单位，宇宙的现象不变。现有模型却让改 c 直接改变公式结果，这在物理上是错的，只是「感觉变了」。

真正决定物理的是**无量纲常数**：

- α ≈ 1/137.036（电磁耦合）
- μ = mₚ/mₑ ≈ 1836.15（质子电子质量比）
- α_s ≈ 0.118（强耦合）
- α_G = G·mₚ²/(ħc) ≈ 5.9×10⁻³⁹（引力相对强度）
- 以及宇宙学参数（Λ、密度参数）

## 决策

1. **推演起点改为无量纲常数集。** 有量纲常数降级为「单位定义」，改它们不产生新物理，只换单位。
2. **三层模型，每层标注可信度：**
   - **L1 第一性原理**：由 α/μ 等严格推出（玻尔半径、里德伯能量、化学键能量级、简并压）。
   - **L2 标度律 + 适用域**：能给出正确缩放方向与量级，但有适用范围（恒星结构、材料强度、潮汐锁定时间）。
   - **L3 设定自由**：不可推导，必须由作者给（有几颗卫星、地质历史、是否宜居）。
3. **适用域门禁**：任何 L2 经验公式必须声明有效范围（如「α 偏离现实 < 1%」）。超出范围时**拒绝输出数值**并说明失效原因，绝不静默外推。
4. **我们的宇宙是回归锚**：所有常数取现实值时，输出必须与当前版本一致（现有 1117 项测试不得回归）。

## 后果

- 新增 `constants-core` 模块：无量纲常数 → 尺度阶梯（原子 → 分子 → 材料 → 行星 → 恒星）。
- `constants-graph` 每个节点新增 `kind: 'dimensionful' | 'dimensionless' | 'derived'`。
- `world / terrain / sky / moons` 的输入从「地球标定值」改为「派生尺度」，并加 domain 检查。
- 这是**大改**：预计触及 6–8 个模块、需要新增 3 个测试套件。

## 未决问题（需用户拍板）

1. 改 c 而 α 不变时，模型应该回答「完全没变」还是「看起来变了」？
2. 常数偏离现实超过阈值后，允许模型**拒绝给数值**吗？
3. 恒星结构与化学窗口做到什么粒度（从 α 推恒星寿命与元素丰度 ≈ 再写一个插件的工作量）？

## 分阶段计划

| 阶段 | 内容 | 验收 |
|---|---|---|
| S1 | 常数分类（有量纲/无量纲/派生）+ 适用域字段；不改变现有行为 | 1117 项全绿，新增常数分类测试 |
| S2 | 尺度阶梯：α/μ → 原子、材料、行星半径；替换 world/terrain 中的地球硬编码 | 我们的宇宙复现地球值（美国标准锚点），改 α 时原子尺度按 1/α 变化 |
| S3 | 恒星结构标度 + 化学窗口（L2，给量级与适用域） | 能回答「α 改 10% 后恒星寿命与宜居带如何移动」，并标注置信度 |

S3 之外的「宇宙从零」不属于本插件的可交付范围：它需要核反应网络 + 不透明度表 + 恒星演化程序，属于独立科研级工程。
