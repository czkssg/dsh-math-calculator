## 四、本次实现的三项细节

### 补丁13：混沌拦截器

不问「结果是多少」，而问「这个结果在多久之内还有意义」：

```
Lyapunov 指数 1.000 > 0：初值误差每 1.00 个特征时间放大 e 倍。
超过 11.5 个特征时间后，任何数值结果都不再可信。

t=0.0   区间 [1.000, 1.000]
t=9.9   区间 [0.981, 1.019]
t=14.8  不可预测（误差已超过 100%）
```

关键设计：误差超过 100% 之后**不再输出数字**，直接说「不可预测」。
这比输出 1e9 这种数字诚实得多。

### 补丁9：数据表继承

```
衍生表只读继承基线的 constants + formulaTable
基线改动 → syncInheritance() → 所有衍生表跟着更新
衍生表自己的 variables/terrains 保持不变
```

实测：基线 c 从 1e8 改成 5e7，衍生表同步为 5e7，且自己的变量 `own=42` 仍在。

### 补丁3：A/B 对比

两张表的常数、公式覆盖数逐项对比，输出差异清单。
