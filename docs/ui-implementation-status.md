# UI v2 实现对照

> 对照 [ui-design-v2.md](./ui-design-v2.md)（一区一表强绑定方案）。
> **本次覆盖了旧 UI**：右侧从「单页工作台」改成「推演控制台 = 六大目录树 + 内容区」。

## 一、核心变更

| 项 | 旧 | 新 |
|---|---|---|
| 右侧布局 | 单页：开关+常数+公式+地点+变量 全堆一页 | **左侧 6 大目录树 + 右侧内容区** |
| 目录粒度 | 3 个 Section | **18 个节点**（6 组 × 2—4 项） |
| 绑定状态 | 无显示 | 列表带「运行中 / 已绑定」徽标 + 绑定到哪个工作区 |
| 推演结果 | 只能靠对话 | **界面里就能看**（/derive 路由） |

## 二、六大目录树（18 节点）

```
1 基础物理法则
  1.1 常数表        1.2 公式库
  1.3 变更清单      1.4 单位与观测基准
2 物理链路引擎
  2.1 分层推演      2.2 接口卡矩阵      2.3 演化时间轴
3 生命与生态基质
  3.1 生物物理约束  3.2 生态热力学
4 宏观文明推演
  4.1 能量与热力学  4.2 材料与结构
  4.3 空间与交通    4.4 技术树
5 校验与分析
  5.1 硬约束监控    5.2 敏感性与相图    5.3 待定项看板
6 输出与归档
  6.1 七张表导出    6.2 完整性检查      6.3 白皮书与 AI 投射
```

## 三、关键设计：只有 1.x 是可编辑的

```
1.1—1.4  可编辑表单（常数、公式、变更、观测者）
2.x—6.x  只读推演结果（由后端算）
```

**为什么这样分**：保证「一个工作区 = 一份数据」。
用户能改的永远只有常数与公式；推演结果由后端算，界面不维护第二份真相。

## 四、新路由 `/derive`

界面按目录请求某块内容时统一走这一条：

```jsonc
POST /derive {"sub":"pipeline"}
POST /derive {"sub":"civilization"}
POST /derive {"sub":"whitepaper"}
```

**为什么用 POST 不用 GET**：子命令参数（world、anchor…）是结构化的，
塞进 query string 既难读又容易超长。

**为什么只加一条路由**：六大目录背后全是 `opDerivation` 的子命令，本来就有统一入口。
加目录时只改前端，不用每次加一条后端路由。

实测 8 个子命令全部返回 200：

| 子命令 | 返回长度 |
|---|---|
| pipeline | 970 字符 |
| cards | 2724 字符 |
| civilization | 1884 字符 |
| dead | 281 字符 |
| timeline | 979 字符 |
| whitepaper | 943 字符 |
| sensitivity | 141 字符 |
| checklist | 238 字符 |

## 五、强绑定可见性

列表现在显示三类徽标：

| 徽标 | 含义 |
|---|---|
| 运行中 | 当前活跃工作区绑定的表 |
| 已绑定 | 已被某个宿主工作区绑定的表 |
| 未绑定 | 还没绑定的表 |

并在每行附上「绑定 工作区名」，用户切换工作区前就能看到。

后端 `/workspaces` 为此新增 `boundWorkspace` 字段：

```json
{ "name": "5", "boundWorkspace": "5" }
```

**表名 == 绑定工作区名**，这是「一区一表」的物理保证。

## 六、踩到的两个坑

### 坑 1：组件插错作用域

第一次把 `const DerivationPane = makeDerivationPane(react)` 插进了 `createLeftPanel`，
结果右侧报 `Cannot find name 'DerivationPane'`。
用「找到右栏的 kit 解构行再插」的方式修好。

### 坑 2：写死了颜色

我写了 `rgba(64,128,255,0.14)` 和 `#4080ff`，被 `client-ui.mjs` 的令牌测试抓住。
改用 `T.accentSoft` / `T.accent` / `T.layer2` / `T.radius`。
**项目硬约束：零硬编码颜色**，测试守着这条。

### 坑 3（测试层面）：依赖了别人的副作用

`ui-v2.mjs` 原本假设「列表非空」，但 `api.mjs` 跑完会清理测试表，
全量跑时列表是空的 → 测试失败。改成自己造一张探测表，验完删掉。
