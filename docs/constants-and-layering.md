# 常数表与全局/工作区分层

> 用户三点要求：① 常数表/公式表应放工作区侧栏而非全局管理；② 要有「重置为默认值」；
> ③ 常数太少、物理量不够基本（度量衡应靠更基本的概念定义）。

## 一、全局管理 vs 工作区侧栏（学社区插件的分层）

社区插件（dsh-memory / dsh-context / better-sidebar）的共识：
**全局面板管「有哪些」，侧栏管「这一个里面有什么」**。

| 位置 | 管什么 | 现在的内容 |
|---|---|---|
| **左栏 · 全局管理** | 跨工作区的、与具体世界无关的 | 工作区列表（新建/切换/删除/清空）、存储统计、插件设置 |
| **右栏 · 本工作区** | 这一个工作区自己的数据 | **常数表**、**公式表**、地点、变量、提示档位 |

之前常数表、公式表错放在左栏，等于「全局配置」，但它们是**每个工作区各有一份**的数据
（A 世界的光速改了，不该影响 B 世界）。现在已移回右栏。

## 二、重置为默认值

提供两级：

| 按钮 | 位置 | 作用 |
|---|---|---|
| **重置**（单条） | 每一行常数右侧 | 该项恢复成现实宇宙的值 |
| **全部重置为默认值** | 常数表标题下方 | 清空本区所有常数覆盖 |

实现：单条走 `POST /workspaces/reset-constant`，全部走 `POST /workspaces/reset`。
「重置」按钮在有改动时才可点（`disabled={!changed}`），改过的行会带「已改」徽标。

## 三、常数表扩充：从 34 → 43

### 缺的是什么

用户说「度量衡很多是依靠更基本的概念定义的」——这正是指 **SI 2019 的定义常数**。
现代 SI 不再用实物基准，而是**固定 7 个常数的数值**来定义全部基本单位：

| 基本单位 | 定义常数 | 之前 |
|---|---|---|
| 秒 (s) | Δν_Cs 铯-133 跃迁频率 | ❌ **整个缺失** |
| 米 (m) | c 光速 | ✅ |
| 千克 (kg) | h 普朗克常数 | ✅ |
| 安培 (A) | e 元电荷 | ✅ |
| 开尔文 (K) | kB 玻尔兹曼常数 | ✅ |
| 摩尔 (mol) | NA 阿伏伽德罗常数 | ✅ |
| 坎德拉 (cd) | K_cd 光视效能 | ❌ **整个缺失** |

之前整张表**没有「秒」和「坎德拉」的定义根基**。现在补齐，并给 5 个已有的也加上
`siDefines` 标注，于是界面上能单独分出「SI 定义常数」一组，用户一眼看到
「这个单位是被哪个常数定义的」。

### 还补了微观基本量

| 新常数 | 含义 |
|---|---|
| `u` | 原子质量单位（碳-12 的 1/12）—— 化学与天体物理的通用质量尺 |
| `mPlanck` | 普朗克质量 = √(ħc/G) —— 量子引力介入的边界 |
| `lPlanck` | 普朗克长度 —— 能描述的最小长度 |
| `tPlanck` | 普朗克时间 —— 最短可测时间 |
| `re` | 经典电子半径 —— 电磁相互作用的特征长度 |
| `F` | 法拉第常数 = e·NA —— 电解/电池/生物电的换算桥 |
| `alphaG` | 引力耦合常数 —— 比电磁力小 10⁴² 倍，量化「引力为何可忽略」 |

全部 9 个新常数的派生公式都经过数值验证（与标准值偏差 < 0.1%）。

## 四、界面结构

```
右栏「本区」
├─ 常数表 (43)              [全部重置为默认值]
│   ├─ SI 定义常数 —— 定义了秒/米/千克/安培/开尔文/摩尔/坎德拉
│   │    c  [定义metre]     299792458     [保存][重置]
│   │    h  [定义kilogram]
│   │    ...
│   └─ 其它可调量
│        day / AU / Rearth / Mearth / ...
├─ 公式改动
├─ 地点 / 变量
└─ 添加变量 / 添加地点 / 停用公式
```
